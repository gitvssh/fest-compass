# ADR-0004: 한국관광공사 데이터랩 자료를 공개 화면에 계속 쓴다

## Context and Problem Statement

ADR-0003으로 데이터랩 웹사이트에서 내려받은 자료를 쓰던 화면(연도별 방문 흐름, 문화관광축제 방문 규모, 개최지 방문 구성,
임실 방문자 특성, 지역 연간 추세)을 뺐다. 사용자는 같은 날 곧바로 되돌리라고 했다. 이 프로젝트는 한국관광공사 공모전 참가작이고,
한국관광공사 자료를 쓰는 것이 목표다. ‘데이터랩’을 처음 듣는 용어라 다른 기관의 사이트로 착각했다고 밝혔다
(“이 프로젝트가 한국관광공사의 공모전에 참여하는 프로젝트라 한국관광공사의 데이터를 사용하는게 목표야”,
“연도별 방문흐름은 꼭 필요한거아니야? 저건 내리면안되는건데 롤백해줘. 공공데이터이고 공모전이고, 공무원을 위한거라 괜찮을거야”).

## Considered Options

1. ADR-0003을 유지한다.
2. 연도별 방문 흐름만 되살린다.
3. ADR-0003의 제거 전체를 되돌린다.

## Decision Outcome

선택: 3. 다섯 화면이 같은 한국관광공사 데이터랩 자료와 같은 판단 근거를 쓰므로 함께 되살린다. ADR-0003을 대체한다.

Y-statement: 한국관광공사 공모전의 목적(공사 자료 활용)과 공무원 대상 공공 기획 도구라는 성격에 맞추어, 공사 데이터랩 자료로 만든
화면을 그대로 공개하고 출처를 화면마다 밝힌다. 그 대가로 공공누리 표시가 없는 자료의 재이용 조건을 공사와 따로 확인하지 않은 채 둔다.

## Consequences

- 화면·자료·생성 스크립트·시험은 ADR-0003 이전(`c5ed391`)과 같다. 출처 표시(데이터랩 원문 연결·내려받은 날)는 그대로 둔다.
- 데이터랩 축제 화면과 내려받은 CSV에는 공공누리 표시가 없다([검토](../research/2026-10-datalab-download-automation.md)).
  공모전 이후 일반 서비스로 이어 갈 때는 한국관광공사에 재이용 범위를 확인한다.
- 내려받기 자동화는 계속 하지 않는다(데이터랩 공지·로그인). 더 받을 때는 사람이 공식 버튼으로 받는다.

## Confirmation

- 공개 화면에서 `/compare/annual`·`/compare/scale`이 열리고, 임실N치즈축제 방문 흐름에 방문자 특성·개최지 방문 구성이, 임실군 새 축제 방문 흐름에 연간 추세가 보인다.
- 해당 화면 시험(`annual-trend-e2e`, `visitor-profile-e2e`, `edition-profile-e2e`, `visitor-context-e2e`, `festival-discovery-e2e`)이 공식 실행 목록에 있다.
