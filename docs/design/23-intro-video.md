# 홈 1분 소개 영상

2026-10-03 사용자 승인에 따라 공모전용으로 만든 소개 영상을 웹사이트에 게시한다.
목표는 처음 온 사람(심사위원·처음 접한 담당자)이 1분 안에 제품의 두 흐름과 주요 기능을 이해하고,
다시 오는 담당자의 업무는 방해하지 않는 것이다.

## 결정

| 선택지 | 판단 |
|---|---|
| 첫 방문 시 전면 창 자동 재생 | 채택하지 않음. 업무 시작을 막고, 소리 있는 자동 재생은 브라우저가 차단하며, 첫 화면에 동의 창과 겹치고, 5초 넘는 자동 움직임은 멈춤 수단이 필요하다. |
| 홈 상시 진입점 + 첫 방문 비차단 안내 + 누를 때 재생 | **채택.** 서버 렌더에 진입점을 포함해 화면 밀림이 없고, 안내는 닫을 수 있으며, 재생은 사용자 조작이므로 소리와 함께 시작한다. |
| 외부 동영상 서비스 삽입 | 채택하지 않음. 외부 쿠키·추적이 생겨 개인정보 안내와 보안 정책을 바꿔야 한다. 같은 출처의 정적 파일로 제공한다. |

## 화면 구성

1. **상시 진입점(모든 방문자):** 홈 제목 오른쪽(좁은 화면은 제목 아래)에 포스터 썸네일과 `1분 소개 영상 / pickDday 둘러보기` 버튼.
2. **첫 방문 안내(첫 방문만, 홈에서만):** 동의 창이 닫힌 채 2초가 지나면 화면 아래 모서리에 `pickDday가 처음이신가요?`와 [닫기] [영상 보기].
   - 초점을 빼앗지 않고 본문을 막지 않는다. 휴대폰에서는 한 줄 막대(높이 80px 이하)로 줄여 첫 화면의 주 행동을 가리지 않는다.
   - 재생 또는 닫기 후에는 다시 띄우지 않는다. 깊은 링크로 들어온 업무 화면에는 띄우지 않는다.
3. **재생 창:** 네이티브 모달 대화상자. 제목·닫기, 컨트롤이 있는 영상, 기본으로 켜진 한국어 자막, `영상 내용 글로 보기` 대본.
   - ESC·닫기·바깥 클릭으로 닫고 영상은 멈추며 초점은 진입점으로 돌아간다.
   - 끝나면 `기존 축제 찾기` `지역부터 살펴보기` `다시 보기`를 보여 실제 기능으로 바로 잇는다.
4. **공유 링크:** `/?intro=play`는 첫 방문 여부와 관계없이 재생 창을 연다. 주소에서 이 값만 지워 새로고침 때 다시 열리지 않게 한다. 제출 서류·발표·QR에 사용한다.

## 저장·개인정보

- 이 브라우저의 `localStorage`에 `fest-compass.intro-video.v1` = `played` 또는 `dismissed` 하나만 저장한다. 서버·선택 분석으로 보내지 않는다.
- 저장 공간을 읽을 수 없으면 안내를 매번 반복하지 않도록 `본 것`으로 처리한다.
- 동의 창은 열림 여부만 읽고(그림자 DOM의 `dialog[open]`), 동의 결정은 읽거나 저장하지 않는다.
- 개인정보·분석 안내에 이 저장 항목을 추가했다.

## 영상 자산

- `public/media/intro/`: H.264 1080p 웹용(약 8.7MB, faststart), 포스터, 한국어 WebVTT 자막.
- 재생 전에는 영상 파일을 내려받지 않는다(`preload="none"`). 같은 출처라 기존 보안 정책(CSP `default-src 'self'`)을 바꾸지 않는다.
- 웹용은 공모전 제출본과 한 장면만 다르다. 제작 과정 설명에 가까운 `단위 테스트·브라우저 검증` 카드를
  사용자 관점의 `공식 자료 자동 갱신 · 전국 축제 일정·방문 매일 새로 반영`으로 바꿨다(매일 최근 90일 갱신, [자료 수집](../ops/festival-sources.md)).
- 자막과 화면 대본은 같은 문장이며 단위 시험이 일치를 검사한다.
- 영상 속 수치(논산 관광자원 68곳, 강릉 180곳 등)는 2026-10-02 공개 화면 기준이다. 자료가 갱신되면 화면과 달라질 수 있다.
