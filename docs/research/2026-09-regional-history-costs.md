수집은 기존 공공데이터 자격을 재사용했다. 새 자격 발급이나 모델 학습은 수행하지 않았다. 전국 방문 전수 공개가 아니라 선택한 두 지역의 보강이다.

## 한국관광공사 방문 자료

[한국관광 데이터랩 서비스](https://www.data.go.kr/data/15101972/openapi.do)의 `locgoRegnVisitrDDList`를 2023-01-01~2025-12-31에 월별 조회했다. 총 108회, 월별 전체 페이지·전체 행 수·행 식별자 중복을 확인했다. 날짜마다 지역 코드·지역명·현지인/외지인/외국인 유형 3개를 검증한 뒤 외지인 유형 2만 시각화 입력으로 추출했다.

실제 응답은 공주 44150·임실 52750이었다. 2023년 자료도 이번 응답에서는 52750으로 반환됐다. 임실 과거 코드 45750의 대응은 기존 후보 코드 계약과 시험으로 유지하며, 이번 수집에서 45750을 관측한 것으로 표현하지 않는다. 현재 조회 단위 52/750에 연결하되 원문 코드 목록을 보관한다. 별칭 두 개가 같은 날 동시에 반환되면 중복 유형 오류로 남기고 합산하지 않는다.

실제 시작일 표본: 공주 2024-09-28 130,382명, 임실 2023-10-06 27,762명·2024-10-03 50,526명·2025-10-08 109,833.5명. 통신 기반 지역 방문 추정치이며 입장객 수·행사 효과·날짜 합계의 고유 방문객 수가 아니다. 이번에 받은 개정 가능 자료이며 과거 당시 공개본이 아니다.

기계 판독 자료와 페이지 해시·원문 코드·날짜별 품질은 `apps/web/data/regional-history-expanded.json`, 재현 수집기는 `apps/web/scripts/collect-regional-history.ts`다. 호출 한도 150회·캐시 체크섬·실패 요청 차감·단일 수집 잠금을 적용했다. 미확보 날짜는 null이며 기존 논산 예측 입력과 분리한다.

## 공주시 축제 원가회계

[공주시 지방재정공시 페이지](https://www.gongju.go.kr/kr/sub02_19_03.do)의 2024회계연도 자료 경로에서 [행사·축제별 원가회계정보 PDF](https://www.gongju.go.kr/thumbnail/fileInfo/FI_202509011058264660.pdf)를 내려받았다. 현재 HTML의 과거 연도 부분은 주석으로 남아 있어 경로 존재와 실제 PDF 접근 성공을 별도로 확인했다. PDF 6쪽(인쇄 283쪽)을 렌더링해 표의 열·행·단위를 육안 대조했다.

| 정의 | 원문(천원) | 표시(원) |
|---|---:|---:|
| 예산액 | 4,637,800 | 4,637,800,000 |
| 집행액 | 4,614,321 | 4,614,321,000 |
| 총원가 | 4,159,338 | 4,159,338,000 |

총원가는 보험료 21,700·기타행사운영비 2,612,869·홍보및광고비 314,769·행사관련시설비 200,000·임차료 1,010,000천원과 원문 0 항목의 합계다. 행사직접비·시설장비비 소계는 다시 더하지 않는다. 비용 구성의 분모가 검증돼도 집행액과 총원가의 차이 원인이 검증된 것은 아니다. 원문의 일반 차이 안내를 이번 차이의 원인으로 단정하지 않는다.

공주시 관광과 사업이며 부여 지역 전체와 합치지 않는다. 부가세 기준·집행액과 총원가 차이의 구체적 원인·사업 효과의 측정 방법은 미확인이다. 효과 표를 검증된 축제 경제효과로 옮기지 않는다. 파일명 날짜는 게시일 증거로 사용하지 않는다.
