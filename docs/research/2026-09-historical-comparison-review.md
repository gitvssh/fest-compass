# 과거 축제 비교 자료 점검

## 결론과 확인 범위

2026-09-08 사용자 요청에 따른 점검이다. v2의 축제명·방문 곡선·가격은 가상 시안이었고 일반 과거 회차 검색에 연결되지 않았다.
v3에는 출처가 있는 표본을 넣되, 자료의 존재·현재 재조회·과거 당시 공개 여부·같은 기준 비교 가능 여부를 별도로 표시한다.
이번 작업은 문서·시안 보완이다. 전국 자료 수집·일반 과거 검색·기획 저장 기능의 구현 완료가 아니다.

같은 대화의 직전 검토에서 2026-09-08 13:51 KST부터 수행한 읽기 전용 조회 결과다. 키를 제외한 요청 조건과 관찰만 남긴다.

모두 HTTP 200·제공처 성공 코드 0000이었다. 조회 성공과 과거 회차 완전성은 별개다.
[관광정보 API](https://www.data.go.kr/data/15101578/openapi.do)는 최신 관광정보를 제공한다. 위 실측과 설명을 함께 볼 때 contentId의 현재 상세만으로 연도별 기록을 복원할 수 있다고 가정하면 안 된다.
2025 논산 개최일 3/27~30은 [공식 공고](https://www.nonsan.go.kr/cntf/html/sub05/0503.html?dlgt=N&file_id=184487&mode=D&no=2a5451006dff034d8a709772015d9b8d) 등 별도 회차 출처로 확인했다.

현재 앱의 `apps/web/lib/kto/client.ts` 축제 기간 검색은 20건·첫 페이지로 고정돼 있다. 전국 분포·총 건수를 표시하려면 페이지 전수 조회와 회차 중복 정리가 필요하다.
일별 통계 수집과 축제 일정 검색은 서로 다른 경로다. 일반 관광자원 조회에 페이지 순회 기반이 있다고 축제 검색도 완전하다고 판단하지 않는다.

## v3에 실제로 그리는 값

### 논산 개최 전후 지역 방문 추세

2023년 3/8~12, 2024년 3/21~24, 2025년 3/27~30 회차의 시작일을 각각 D0으로 둔다.
각 시작일의 D-7~D+7 일별 외지인 값 15개, 총 45개를 기존 KTO 보관본에서 그대로 추출한다.
원래 날짜·회차·집계 단위·수집 시각·원천 파일 SHA-256은 [시각화 고정 자료](evidence/2026-09-visualization-fixture.json)에 남긴다.
상대 날짜 선그래프와 실제 날짜 표를 함께 제공한다. 2023년 5일·2024/2025년 4일이라는 개최 일수 차이를 표시한다.
같은 날을 여러 지자체로 확장하거나 행사장 입장객·효과·일별 순관광객으로 바꾸지 않는다.

### 원주 계획·집행과 재원 구성

[SRC-MUN-03](2026-09-municipal-festival-sources.md)의 2022년 제21회 치악산복숭아 축제 **지원사업** 정산 검사서에서 확인했다.
계획 35,000,000원은 보조금 30,000,000원+자부담 5,000,000원이다.
집행 35,118,200원은 보조금 30,000,000원+자부담 5,118,200원이다.
같은 문서·지원사업 안의 계획과 집행을 원 단위 막대와 재원별 표로 보여주고 집행 재원 구성을 도넛으로 표시한다.
이는 전체 축제의 모든 부서 원가나 확정 예산 대비 효율 순위가 아니다. 잔액·이자의 원문 '-'는 미확인으로 유지한다.
2022-08-10~08-31은 문서상 사업기간이며 축제 개최기간으로 사용하지 않는다. 검사일 2022-09-30·게시일 2023-01-20·확인일 2026-09-08을 구분한다.

## 남은 개발과 표시 기준

자료 상태는 회차×지표 단위로 관리한다. 실제 값을 재조회한 표본을 제외한 다른 날짜까지 '재조회 일치'로 표시하지 않는다.
원문만 있는 예산은 '원문 확인·연결 필요', 확인하지 않은 항목은 '미확보'다. 방문·일정·비용 각각의 상태가 다를 수 있다.
전국 지도에서 미확보를 0으로 칠하지 않고, 현재 상세가 바뀌어도 보관한 회차·근거는 유지해야 한다.
차트별 금지 조건과 저장·출력은 [시각화 설계](../sdlc/2-design/data-visualization.md)를 따른다.
