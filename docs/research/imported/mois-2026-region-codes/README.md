인천의 옛 중구 28110은 제물포구·영종구로 나뉘고, 옛 동구 28140은 제물포구 일부가 된다. 옛 서구 28260은 서해구·검단구로 나뉜다. 세 코드는 일대일 연결에서 제외한다. 현재 구의 공식 방문 수치가 있는 날짜부터 표시하고 과거 인원을 배분·합산하지 않는다. 기존 2025년 지도 경계를 새 경계로 바꾸는 근거로도 사용하지 않는다.

DataLab 공식 일별 API 실조회에서 2023-01-01은 261개 코드, 2025-09-01~02는 264개 코드, 2026-08-01은 현재 269개 코드가 나왔다. 2026-09-01은 정상 빈 응답이다. 관측 공백은 0이 아니다. 보관·갱신 때 현재 코드와 검토한 코드 변경만 연결하며 수원시와 장안구처럼 시·구가 함께 있어도 서로 합산하지 않는다.
