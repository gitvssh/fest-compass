# 데이터랩 문화관광축제 92곳 — 소유자 공식 내려받기 보관

이 디렉터리는 프로젝트 소유자가 2026-10-04 밤 ~ 2026-10-05 새벽(한국시간, 내려받은 사람의 기록)에 한국관광 데이터랩
축제 화면의 공식 내려받기 단추로 받은 **문화관광축제 92곳 전부**를 바이트 그대로 보관한다. `original/` 아래 파일은 고치지 않는다.
분류·해시·겹침 검사 결과는 이 README와 [`manifest.json`](./manifest.json)에만 둔다.

## 원본

| 항목 | 값 |
|---|---|
| 공식 제공처 | 한국관광 데이터랩 축제 데이터 https://datalab.visitkorea.or.kr/datalab/portal/fes/getFesDataForm.do |
| 범위 | 축제 선택 목록 10쪽의 92개 축제, 축제마다 고를 수 있는 전체 연도(2018-2025 56곳, 2018-2023 27곳, 2018-2024 3곳, 2024-2025 6곳) |
| 받은 사람 | 프로젝트 소유자(로그인 회원). 내려받기는 자동화하지 않는다([검토](../../2026-10-datalab-download-automation.md)) |
| 받은 파일 | 공식 ZIP 92개, 그 안의 CSV 367개(세종축제 3개, 나머지 4개씩), 내려받기 목록(`다운로드목록.csv`)과 안내(`읽어주세요.txt`) |

## 보관 구조

- `original/zip/<공식 파일 이름>.zip` — 공식 ZIP 그대로. 소유자 폴더에서는 `<축제명>_<기간>.zip`으로 이름만 바뀌어 있었고, 공식 이름은
  `다운로드목록.csv`의 `원본다운로드파일` 열에서 되살렸다. SHA-256은 목록의 `원본SHA256`과 같다.
- `original/data/<공식 파일 이름>/<ZIP 항목>.csv` — ZIP 항목을 바이트 그대로 푼 사본. ZIP 안 `성:연령별 내국인 방문자`의 콜론은 Windows에서
  쓸 수 없어 이 사본의 이름만 처음 가져오기([hkjin-plan-03](../hkjin-plan-03/README.md))와 같은 `성-연령별`로 썼다. 내용은 ZIP 항목과 같다.
- `original/다운로드목록.csv`, `original/읽어주세요.txt` — 소유자의 내려받기 기록. 보관용이다.

## 검증 방식

`apps/web/scripts/datalab-owner-import.mjs`가 목록을 기록하고, 축제 생성 단계마다 다시 확인한다. `manifest.json`은 손으로 고치지 않는다 —
검증은 파일에서 목록을 다시 만들어 저장된 JSON과 한 글자까지 같아야 통과한다.

1. 내려받기 목록의 92행마다 공식 ZIP의 SHA-256, 기간, CSV 수, 표마다의 행 수가 같다.
2. ZIP을 직접 풀어(크기·CRC-32 확인) 각 항목이 풀어 둔 CSV와 바이트까지 같다. 항목 이름의 내려받은 시각·축제명이 ZIP과 같다.
3. `original/` 아래에 목록에 없는 파일이 없다.
4. 처음 가져오기에도 있던 26곳은 표 104개를 처음 가져오기와 견준다. 101개는 바이트까지 같고, 3개(수원화성문화제·인천펜타포트음악축제·화성뱃놀이축제의
   `목적지 검색순위`)는 같은 순위 안의 행 순서만 다르다(행 묶음과 순위 순서가 같음). 이 겹침 104개는 `preserved-only`이며, 앱은 그 26곳을
   처음 가져오기 그대로 쓴다.

## 앱에서 쓰는 범위

처음 가져오기에 없던 66곳의 표 263개를 쓴다(`use: consumed`, 세종축제는 `목적지 검색순위` 없음). 축제와 ID의 대응은
`apps/web/data/datalab-festival-ids.json`(v2) 검토표다. 생성 결과와 검토 기준은 [설계29](../../../design/29-datalab-festivals-92.md),
실행 기록은 [검수51](../../../validation/51-datalab-festivals-92.md)이다.

- 관광 소비액은 공식 단추에서도 '데이터 제공사와의 계약 상 다운로드가 불가능합니다'로 막혀 이 묶음에 없다.
- 2020·2021년은 데이터랩이 코로나19 기간으로 분석에서 뺀다. 축제마다 고를 수 있는 연도와 빠진 연도가 다르다.
- 주요 지표 원문 두 값이 정의(그해 최댓값 = 1)를 넘는다: 원주다이내믹댄싱카니발·횡성한우축제 2023년 축제기간 내비게이션 검색량(1.215, 1.177).
  그해 비교는 화면에서 빼고 이유를 적는다.
- 지역 표(시군구 관광소비·방문자)는 이 묶음에 없다. 처음 가져오기의 지역 26곳 중 2곳(대구 중구·평창군)에 새 축제가 열려 같은 조건으로 이었다.
