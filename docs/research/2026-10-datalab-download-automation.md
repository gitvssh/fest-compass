# 데이터랩 축제 방문 추이 내려받기 자동화 검토

2026-10-04 사용자 요청: 축제별 연도 방문 추이 파일을 받는 반복 작업을 자동화할 수 있는지 확인. 공개 페이지·약관·자료 목록만 각 한 번 읽었고,
축제 목록·내려받기 주소는 호출하지 않았다.

## 결론

- **웹 화면 자동 내려받기는 권하지 않는다.** 화면 공지는 “공식 제공되는 다운로드 이외의 방법에 의한 무단 수집”을 금지한다. 공식 버튼을 프로그램으로
  반복 누르는 것이 이에 해당하는지는 문서만으로 가릴 수 없다. 내려받기는 로그인이 필요하고 약관 위반은 회원 자격 제한 사유다.
  남은 축제는 약 60곳(화면 목록 86~92곳 중 보유 26곳)이라 사람 손으로 축제당 한 번씩 누르면 1~2시간 일이다.
- **같은 자료(축제 × 연도 × 현지인/외지인/외국인)를 주는 공식 API나 일괄 파일은 찾지 못했다.**
- **재이용 조건이 더 큰 쟁점이다.** 축제 화면과 CSV에는 공공누리 표시가 없고 “Copyright 한국관광공사. All Rights Reserved.”만 있다.
  공사 저작권 정책은 공공누리가 없는 자료를 쓰려면 담당자와 사전 협의하라고 한다. 지금 공개 중인 `/compare/annual`·`/compare/scale`의 26곳 자료도 해당된다.
- **권하는 길:** ① 한국관광공사에 재이용 허락과 문화관광축제 전체 자료의 일괄 제공을 서면 문의(데이터랩 고객문의 또는 공공데이터포털 제공신청 — 10일 안에 회신 의무).
  ② 회신 전까지 추가 자료는 사람이 공식 버튼으로 내려받고, 받은 파일을 한 번에 검사·반영하는 가져오기 도구는 우리가 만든다.

## 남은 확인

- 공식 버튼을 스크립트로 반복 실행하는 것의 허용 여부, 공개 서비스에서의 재이용 범위(통신사 원천 조건 포함) — 공사 회신으로만 확정된다.
- 문체부 지역축제 정보 파일의 열 구성은 내려받아 보지 않았다(방문객 수 정의·출처 열 확인 필요).
