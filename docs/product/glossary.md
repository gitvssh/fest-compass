# fest-compass — 용어집 (유비쿼터스 언어)

| 용어 | 정의 | 비고 |
|---|---|---|
| FEST Compass | 축제 근거·가정·운영안·결정·실측을 연결하는 제품 | 프로젝트 slug는 `fest-compass` |
| 근거 | 출처, 기준일, 집계 단위, 제한 해석을 함께 보존한 데이터 스냅샷 | 결측은 0이 아님 |
| 가정 | 근거에서 직접 도출되지 않은 기획 입력 | 버전과 작성 근거를 기록 |
| 실측 | 행사 중 또는 종료 후 확인된 측정값 | 총계와 시간·구역 단위를 구분 |
| 담당 지역 | 기획안을 작성하는 지자체 | 탐색 중인 다른 지역과 구분 |
| 탐색 지역 | 현재 지도·목록·차트 조회 범위 | 변경해도 기획 담당 지역은 자동 변경하지 않음 |
| 관광자원 | 기획에 참고할 관광시설·장소·지역 자산 | 좌표가 없어도 목록 조회 가능 |
| 축제 | 여러 차례 개최될 수 있는 행사 자체 | 이름만으로 동일 축제 판단 금지 |
| 개최회차 | 특정 기간에 개최되거나 등록된 축제 1회 | 과거·현재 비교의 기본 단위 |
| 현재 등록 일정 | 조회 시점에 확인한 행사 일정 | 현장 실시간 운영 상태가 아님 |
| 기획 근거 | 선택 당시 값과 조회 조건·출처를 보관한 자료 | 이후 원천 갱신과 별개로 보존 |
| 아이템 | 축제에서 제공할 구체적인 체험·공연·먹거리 등 | 주제와 구분해 준비·비용 항목에 연결 |
| 기획 후보 | 주제·아이템·대상·장소·시기·준비가 묶인 대안 | 적어도 두 후보를 비교 |
| 확인 합계 | 산정 가능한 예산 항목만 더한 금액 | 미산정 항목이 있으면 확정 총액 아님 |
| 미산정 | 수량·단가·기준이 없어 금액을 정할 수 없음 | 명시적 0원과 구분 |
| 기획안 보관본 | 선택 당시 후보·자료·비용·이유를 고정한 개인 기록 | 공식 승인 아님. 수정은 새 버전 |
