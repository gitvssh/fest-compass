# TS-FC-003 · 필요한 자료를 기획 근거로 보관한다

| 항목 | 내용 |
|---|---|
| 근거 | [UC-FC-003@v1](../../1-analysis/usecases/UC-FC-003.md) |
| 대상 환경 | 구현 후 격리된 로컬 브라우저 + 고정 자료 응답 |
| 실행 상태 | 미실행. 신규 기능과 실행 명세 개발 필요 |

## 데이터와 사전 조건

가상 지표값 100을 담은 뒤 원천 값을 120으로 갱신한다. 동일 원천·조건·시점을 재선택하고, 한 기획안이 이미 이 근거를 참조한 상태를 만든다.
가상 데이터만 사용한다. 실제 API 자격·외부 기관 연락·공유 운영 자료 변경은 필요하지 않다.

## 실행할 과제와 기대 결과

기존 근거는 100, 신규 버전은 120이며 별도 식별자를 가진다. 초안에서 제외한 후에도 기존 보관본에서 100과 출처를 읽을 수 있어야 한다.

| 순서 | 사용자 과제 | 판정할 인수 기준 |
|---|---|---|
| 1 | 기획 근거에 담기를 누르고 저장될 지역·기간·출처를 확인한다. | AC1 |
| 2 | 근거 목록에서 자료를 선택해 적용할 후보와 판단 항목을 지정한다. | AC2 |
| 3 | 새 자료가 있으면 기존 사본을 보면서 새 버전으로 추가한다. | AC3 |
| 4 | 불필요한 근거를 초안에서 제외하고 이미 보관한 기획안의 근거는 유지한다. | AC3 |

## 실패·복구 확인

같은 원천·조건·시점 중복은 기존 근거로 안내한다. 다른 버전은 별도로 보관한다. 원문 링크가 끊겨도 당시 값과 출처 정보는 남는다. 보관본에서 사용한 근거는 초안 삭제로 지워지지 않는다.
실패 입력을 한 뒤 기존 보관본과 다른 회차가 유지되는지 확인한다.

## 실행 증거와 정리

현재 Run은 없다. 개발 후 실행 파일과 결과를 specs·보고서 경로로 연결한다.
새 인수 기준은 기존 운영 E2E 결과로 통과 처리하지 않는다.
독립 브라우저 저장·고정 응답만 사용하고 종료 시 테스트 컨텍스트를 닫는다.
