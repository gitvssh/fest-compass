# TS-FC-019 · 관광자원 사진·이용정보

[설계22](../../../design/22-tourism-media.md)의 공통 확장이다. 실행 결과는 [검수44](../../../validation/44-tourism-media.md)에 기록한다.

| 기준 | 확인할 결과 | 수단 |
|---|---|---|
| TM1 | 대표사진은 허용된 이미지 주소와 사진별1/3유형만 전달. 주소 위장·인증정보·스크립트·미확인 이용조건은 표시되지 않음 | 단위·실제 API |
| TM2 | 공통정보의 id/type/region 검증 유지. 상세사진 id·소개정보 id/type 검증. 타 장소 자료를 섞지 않고 HTML은 정제된 텍스트/안전한 링크만 표시 | 단위 |
| TM3 | 소개 없음에도 사진/이용정보 표시. 사진·이용정보의 빈 결과와 실패 구별. 부분 실패·재조회 실패에 다른 확인 자료 보존, 현재 장소별 재시도 | 단위·통제 headless |
| TM4 | 기존·새 축제·관광지도 목록·상세 연결, 네 관광자원 유형 공통 경험. 사진 탐색·빠른 장소 변경·함께 보기·기준점·조회조건 보존 | 통제/실제 headless |
| TM5 | 전체 사진 비율·출처/이용조건, 키보드 이전/다음·닫기 복귀,1440/1920px 및390px/200% 조작·가로 넘침 확인. 사진 없음에 큰 빈 자리 없음 | headless·직접 시각 검수 |
| TM6 | 실제 원천·공개 화면 성공을 통제 응답과 구분, API 키 노출/업무자료 쓰기 없음. 프로젝트 원본·D 사본과 링크·이미지 확인 | 실제 API·운영 전후·전달 검사 |
