# TS-FC-018 · PC 중심 조사·기획 경험

[설계21](../../../design/21-desktop-research-experience.md)과
[기획 기준](../../../product/planning-principles.md#2026-09-27-pc-중심-조사비교기획-경험)에 따른 공통 화면·UC-FC-009·010 보강이다.
PC 번호는 이 시나리오 안에서만 쓴다. **이 문서는 인수 기준이며 실행 통과·배포 완료 기록이 아니다.**
기존 데이터·주소·상태 계약은 TS-FC-009·010·015·016·017을 유지한다.

## 증거와 판정

- `desktop-experience-e2e.mjs`는 메뉴·모드 경계·홈 위계의 측정 가능한 부분과 실제 브라우저 확대를 확인한다.
  서로 다른 이미지 파일을 썼다는 사실만으로 두 개념이 잘 구별된다고 판정하지 않는다. 주 담당자가 실제 화면을 직접 본다.
- `tourism-resources-e2e.mjs`와 기존 두 흐름의 시험은 많은 자원·밀집·실패·복구 등 통제한 조건의 회귀 근거다.
  통제 응답의 성공을 실제 제공처 상태나 공개 서비스 성공으로 기록하지 않는다.
- `resource-experience-live.mjs` 등의 실제 자료 검수는 실행한 환경·날짜·대상 지역·조회 조건을 함께 남긴다.
  공개 확인 전에는 로컬 결과를 배포 완료로 표시하지 않는다.
- CSS zoom·deviceScaleFactor 변경은 실제 브라우저200% 확대의 대체 증거가 아니다. 자동 검사와 화면 직접 검수 결과를 구분한다.
- 목표·흐름, 위계, 문구 경계, 상태·복구, 접근성·반응형, 필요한 고지를 각각 `충족 / 수정 필요 / 미평가 / 해당 없음`으로 기록한다.
  실무자 관찰·모든 보조기술 인증·기존 기능 전부의 재설계 완료로 확대하지 않는다.
