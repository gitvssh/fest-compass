# TS-FC-015 · 고른 축제 모두의 공통 분석 흐름

[기능 상세 §12](../../2-design/functional-spec.md#12-고른-축제-모두의-공통-분석-흐름)와
[통합 설계 18](../../../design/18-unified-festival-analysis.md)의 UC-FC-009 보강이다. UF 번호는 이 시나리오 안에서만 쓴다.
