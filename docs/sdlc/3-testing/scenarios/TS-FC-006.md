# TS-FC-006 · 근거가 연결된 기획안을 보관하고 출력한다

| 항목 | 내용 |
|---|---|
| 근거 | [UC-FC-006@v3](../../1-analysis/usecases/UC-FC-006.md) |
| 대상 환경 | 구현 후 격리된 로컬 브라우저 + 고정 자료 응답 |
| 실행 상태 | 미실행. 신규 기능과 실행 명세 개발 필요 |

## 데이터와 사전 조건

후보 A/B, 자료값 100, 예산 500000원과 미산정 1건으로 v1을 보관한다. 초안 값을 120과 600000원으로 바꾸어 v2를 만든다.
가상 데이터만 사용한다. 실제 API 자격·외부 기관 연락·공유 운영 자료 변경은 필요하지 않다.

## 실행할 과제와 기대 결과

v1은 100/500000원, v2는 120/600000원을 유지한다. 인쇄 미리보기에서 근거·미산정·버전·선택 이유가 보이고 한 후보만 있는 초안은 비교 완료로 저장되지 않는다.

| 순서 | 사용자 과제 | 판정할 인수 기준 |
|---|---|---|
| 1 | 두 후보와 이유를 작성해 주제·장소·근거·비용·제약을 포함한 보관본을 읽는다. | AC1 |
| 2 | 100/500000원의 P1 보관 후 초안을 120/600000원으로 바꿔 P1이 그대로인지 확인한다. | AC2 |
| 3 | 미산정 비용이 있는 출력에서 출처·생성일·버전·미확정 표시와 공식 승인 표시 부재를 확인한다. | AC3 |

## 공개 사례 반영 추가 과제

| 인수 기준 | 고정 입력·행동·기대 결과 |
|---|---|
| AC4 | 보관 P1의 사업설명 자료와 준비 목록을 각각 인쇄한다. 사업설명에는 목적/사업연도/수행 관계/재원/산출/증감, 준비 목록에는 선행 과제/담당/기한/검토 상태가 나오며 둘 다 P1·기준일·출처·미확인을 표시한다. 화면에서 접힌 항목도 해당 출력물에는 포함한다. |
| AC5 | P1에 예산 미확정·장소 확인 필요를 남겨 보관한 뒤 P2에서 확인 메모를 추가한다. P1의 사업설명/준비 목록은 원래 상태다. 두 후보와 이유가 있으면 미확인 사항이 있어도 표시된 보관본을 만들 수 있다. |

추가 과제의 수치는 시험용 고정 입력이다. 실제 사례의 해석 범위는 [조사 출처](../../../research/2026-09-municipal-festival-sources.md)를 따른다. 현재 모두 미실행이다.

## 실패·복구 확인

후보 한 개 또는 선택 이유 없음은 비교 기획안 보관을 막고 초안 저장을 허용한다. 근거 없는 필드는 미확인으로 출력한다. 예산 미확정은 문서 상태로 명시한다.
실패 입력을 한 뒤 기존 보관본과 다른 회차가 유지되는지 확인한다.

## 실행 증거와 정리

현재 Run은 없다. 개발 후 실행 파일과 결과를 specs·보고서 경로로 연결한다.
새 인수 기준은 기존 운영 E2E 결과로 통과 처리하지 않는다.
독립 브라우저 저장·고정 응답만 사용하고 종료 시 테스트 컨텍스트를 닫는다.
