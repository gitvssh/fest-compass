# TS-FC-005 · 준비 내역과 항목별 예산을 비교한다

| 항목 | 내용 |
|---|---|
| 근거 | [UC-FC-005@v3](../../1-analysis/usecases/UC-FC-005.md) |
| 대상 환경 | 격리된 로컬 public-readonly 운영 빌드 + 개인 브라우저 + 고정 입력 |
| 실행 상태 | AC1~9 자동 검증 통과. 정형 Spec/Run·실무자 관찰 후속 |

## 데이터와 사전 조건

프로그램 2×100000원, 시설 1×300000원, 홍보 단가 null, 한도 450000원을 둔다. 홍보를 0으로 바꾸고 다시 null로 바꾼다. 수량 1.5와 단가 1001원으로 반올림 사례도 둔다.
예산 계산·기관·분류·확인은 가상 입력이다. 연결 자료는 실제 논산 방문 표본·원주 지원사업 비용 사본을 사용한다. 실제 API 자격·외부 기관 연락·공유 운영 자료 변경은 필요하지 않다.

## 실행할 과제와 기대 결과

확인 합계 500000원, 초과 50000원, 미산정 1건을 확인한다. 명시적 0원 입력 후만 미산정이 사라져야 한다. 1.5×1001원은 1502원이며 음수는 거부한다.

| 순서 | 사용자 과제 | 판정할 인수 기준 |
|---|---|---|
| 1 | 프로그램·시설을 산출하고 1.5×1001의 항목 금액 1502원과 표시 합계를 확인한다. | AC1 |
| 2 | 홍보 단가 null→0→null로 바꿔 미산정 수와 총액 미확정 표시를 확인한다. | AC2 |
| 3 | 같은 기준의 소계 500000원/한도 450000원과 VAT 혼재를 각각 시험해 최소 초과액과 비교 보류를 구분한다. | AC3 |

## 공개 사례 반영 추가 과제

| 인수 기준 | 고정 입력·행동·기대 결과 |
|---|---|
| AC4 | 확인 재원 300000원·예정 재원 200000원, 지출 확인 합계 500000원·미산정 1항목을 둔다. 확보액은 300000원이며 합계 1000000원이나 재원 충족 완료를 표시하지 않는다. 부족액을 제시한다면 최소 200000원이며 미산정 포함임을 표시한다. |
| AC5 | 시설 1식 300000원에 2일 포함이면 300000원, 일별 임차 3대×2일×50000원이면 300000원이다. 같은 계약의 요구 500000원·계약 480000원·지급 300000원 기록을 각각 보존하며 이 세 값을 합계하지 않는다. |
| AC6 | 동일 VAT·범위에서 이전 프로그램 1회 100000원+시설 300000원과 현재 프로그램 2회+시설 300000원을 비교한다. +100000원과 수량 변경 이유가 남는다. 부서 범위를 미확인으로 바꾸면 차액은 보류한다. |
| AC7 | 2026년 임시시설 관련 원문 분류를 보존한 근거에서 2027년 초안을 만든다. 과거 라벨을 유지하고 새 분류는 재확인 대상으로 남긴다. 검증되지 않은 코드·세율·법정 기한을 자동 입력하지 않는다. |

추가 과제의 수치는 시험용 고정 입력이다. 실제 사례의 해석 범위는 [조사 출처](../../../research/2026-09-municipal-festival-sources.md)를 따른다. AC1~9의 단위·headless 검증을 실행했다. 아래 실행 증거를 따른다.

## 실패·복구 확인

음수·유효하지 않은 숫자는 저장을 거부하며 입력을 유지한다. 수량/단가 결측은 총액 미확정이다. 세금 기준 혼재는 확정 총액 표시를 막고 기준 통일을 안내한다. 인력·셔틀 증가만으로 안전 효과를 산출하지 않는다.
실패 입력을 한 뒤 기존 보관본과 다른 회차가 유지되는지 확인한다.

## 실행 증거와 정리

실행 파일은 `apps/web/lib/planning/budget.test.ts`(14개)와 `apps/web/scripts/budget-e2e.mjs`(23개)다.
[검증 기록과 AC별 증거](../../../validation/23-planning-budget.md)에 결과를 연결한다. `specs: []`는 정형 Spec/Run이 아직 없음을 유지한다.
기존 포함 단위 168개와 전체 브라우저 회귀도 통과했다. 실제 담당자 관찰은 미실시다.
독립 브라우저 저장·고정 응답만 사용하고 종료 시 테스트 컨텍스트를 닫는다.
