## 데이터와 사전 조건

축제 F-A의 2025·2026 회차와 이름이 같은 F-B의 2026 회차를 둔다. F-A 예산은 총사업비, F-B는 지원금이다. F-A 2025 입장 건수와 F-B 지역 방문 통계는 다른 지표로 둔다.
기존 반례는 가상 데이터, v3 그래프 값 대조는 출처가 있는 고정 표본을 사용한다. 실제 API 자격·외부 기관 연락·공유 운영 자료 변경은 필요하지 않다.

## 실행할 과제와 기대 결과

세 회차의 키가 서로 다른지, 총사업비/지원금 차이가 계산되지 않는지, 취소 회차가 개최 완료처럼 보이지 않는지 확인한다. 저장 조건을 바꿔 재조회해도 담아둔 비교 근거는 이전 값을 유지해야 한다.

| 순서 | 사용자 과제 | 판정할 인수 기준 |
|---|---|---|
| 1 | 동명 축제와 한 축제의 두 회차·취소/변경·확인일을 각각 식별한다. | AC1 |
| 2 | 입장/지역 방문, 총사업비/지원금이 섞인 비교에서 순위·증감·합계가 없는지 확인한다. | AC2 |
| 3 | 두 회차를 담고 검색 조건을 바꿔도 선택 ID·조건·당시 값·출처가 유지되는지 확인한다. | AC3 |
| 4 | 예산·날짜 없는 회차를 비교에 남기고 미확인 안내를 확인한다. | AC4 |

## 공개 사례 반영 추가 과제

| 인수 기준 | 고정 입력·행동·기대 결과 |
|---|---|
| AC5 | 가상 전체 행사 요구액 120000천원과 일부 무대 용역 기초금액 110000000원을 입력한다. 원 단위로 읽더라도 10000000원 차이를 계산하지 않으며 전체/부분·요구/입찰 차이를 함께 표시한다. |
| AC6 | 동일 정의·VAT 포함·같은 부서 범위의 회차별 400000원과 500000원은 명목 차액 +100000원이다. 한 값의 VAT 또는 부서 범위를 미확인으로 바꾸면 차액이 사라진다. 연도 차이는 표시하고 물가 보정 효과를 주장하지 않는다. |

추가 과제의 수치는 시험용 고정 입력이다. 실제 사례의 해석 범위는 [조사 출처](../../../research/2026-09-municipal-festival-sources.md)를 따른다. 현재 모두 미실행이다.

## 실패·복구 확인

기간 누락 회차는 '일정 미확인'으로 별도 표시한다. 같은 이름만으로 회차를 합치지 않는다. 좌표 결측은 거리 계산에서 제외하되 지역 검색에서 유지한다. 자료 정의 차이는 비교 불가 사유로 남긴다.
실패 입력을 한 뒤 기존 보관본과 다른 회차가 유지되는지 확인한다.

## 실행 증거와 정리

현재 Run은 없다. 개발 후 실행 파일과 결과를 specs·보고서 경로로 연결한다.
새 인수 기준은 기존 운영 E2E 결과로 통과 처리하지 않는다.
독립 브라우저 저장·고정 응답만 사용하고 종료 시 테스트 컨텍스트를 닫는다.
