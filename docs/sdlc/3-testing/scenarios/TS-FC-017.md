# TS-FC-017 · 관광자원 시각화와 목적 카드

[설계20](../../../design/20-resource-experience.md)에 따른 UC-FC-009·010 보강이다.
구현·실제 자료를 연결한 로컬 실행 검수 완료, 공개 배포 대기. [결과42](../../../validation/42-resource-experience.md)를 따른다. 이전 자료·주소·상태 계약의 시험은 TS-FC-016을 유지한다.

| 기준 | 확인할 결과 | 수단 |
|---|---|---|
| VE1 | 두 흐름 유형·건수·목록·지도·상세 연결. 번호 일치와 좌표 없는 장소 목록 유지 | headless·직접 화면 검수 |
| VE2 | 밀집·동일 좌표 장소를 군집 목록에서 실제 포인터로 각각 선택. 격자 경계 버튼 겹침 없음 | 순수 함수·650건 통제 시험·공식 자료 |
| VE3 | Enter/Space·Tab·Escape·닫기 초점 복귀, 같은 상세 재선택 초점, 모바일 숨긴 목록 초점 방지 | headless |
| VE4 | 8,000행 ID/번호 누락·중복 없음, 군집 계산 비용 확인. 확대/이동이 기준점·조건을 바꾸지 않음 | 단위·headless |
| VE5 | 320/390/1440px·200% 확대, 긴 이름·빈 결과·실패/재시도, 출처/직선거리/지도 귀속 유지 | 통제 응답·실제 브라우저 확대·직접 검수 |
| VE6 | 두 목적 이미지 최적화 응답·표시·빈 alt·기존 CTA 유지, 공개 화면과 D 검토 사본 전달 | 빌드·공개 headless·사본 검사 |

VE1~VE5와 VE6의 이미지·CTA는 로컬 실행으로 확인했다. 최종 관광자원 회귀48개 항목과 강릉·제주 실제 응답,
실제 Chrome 탭 확대200%를 확인했다. VE6의 공개 배포 후 확인은 저장소 용량 문제로 남아 있다.

CSS zoom을 쓰는 통제 시험과 실제 브라우저 zoom 검사는 별도 기록한다.
이미지 원본과 프롬프트는 설계20에 보존한다. 앱 전체 디자인 완료·실무자 관찰·모든 보조기술 인증으로 확대하지 않는다.
