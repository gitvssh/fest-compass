# TS-FC-014 · 임실 두 회차 방문자 특성 비교

[기능 상세 §11](../../2-design/functional-spec.md#11-두-회차-방문자-특성-비교)의 UC-FC-009 보강이다.
EP 번호는 이 시나리오 안에서만 쓴다. 상태는 모두 **대기**이며 실행 결과는
[검증 기록39](../../../validation/39-edition-profile-comparison.md)에 남긴다. 2025년 한 회차 기준은 [TS-FC-013](TS-FC-013.md)에 그대로 둔다.

| 기준 | 확인할 결과 | 수단 | 상태 |
|---|---|---|---|
| EP1 | 2023·2024년 각 원응답 5개의 바이트·해시·요청 조건이 매니페스트와 일치. 2025년 원본과 기존 CSV 불변. 정의 스크립트(`festival.js`·`festival_chart.js`) 해시가 2025년 수집과 같음 | 수집 재현·생성 검사 | 대기 |
| EP2 | 회차마다 연도·축제 ID·개최일·일수(2023 4일, 2024 4일, 2025 5일)·성수면 52750340이 고정 설정과 일치해야 채택. 한 회차를 변형하면 그 회차만 빠지고 다른 회차는 유지 | 변형 자료 단위 시험 | 대기 |
| EP3 | 적용 회차 중 확인 자료 하나 → 기존 한 회차 표시(제목·차트·표·출처·연결)와 동일. 둘 → 오래된 해 → 최근 해 비교, 제목 `방문자 특성 · 2024년과 2025년`. 없음 → 영역 없음. 선택하지 않은 회차·늦은 이전 응답의 값 없음 | 서버 단위·headless | 대기 |
| EP4 | 두 해 16칸이 원문과 일치. 같은 축, 모든 막대에 연도 글자와 값. 수치 표의 %p는 반올림 정수 차 ÷ 10(예: 2024→2025 70세 이상 남성 4.4 → 4.6 = `+0.2%p`) | 비교 함수 단위 시험·표 대조 | 대기 |
| EP5 | 목적지 행 = 두 해 합집합, 최근 순위 순서 뒤에 이전에만 있는 장소. 원문 ID로만 결합하고 최근 이름 사용. 2024→2025 외지인 기대: 성수산왕의숲자연휴양림 5→3 `2위 상승`, 상이암 4→5 `1위 하락`, 소충사 —→7 `—`, 수월제 7→— `—` | 비교 함수 단위 시험·headless | 대기 |
| EP6 | 관광자원 연결: 2023·2024 두 곳, 2025 세 곳. 비교 시 최근 해 연결 사용, 연결 없는 행은 버튼만 없음. 상세 이동·실패 후 재시도·돌아왔을 때 초점 복귀 유지 | 통제 응답 headless | 대기 |
| EP7 | 방문 구성에 두 회차가 보일 때 표시된 한 자리 값으로 하루 평균 변화와 외지인 비율 %p를 요약. 기존 막대·기간 합계 표·링크 불변. 원인·입장객 표현 없음 | 단위·headless | 대기 |
| EP8 | 키보드로 구분 전환·수치 표·출처 창 열고 닫기, 닫은 뒤 초점 복귀. 320/390/1440px 페이지 가로 넘침 없음. 색 없이도 연도·증감 문자로 구별 | headless·직접 화면 검수 | 대기 |
| EP9 | 공개 응답·화면에 원본 경로·해시·조회 인원·검색 건수·내부 규칙 문구·안내 배너 없음(공개 장소 ID만 허용). 앱 쓰기 요청·페이지 오류 0 | 응답·화면·요청 검사 | 대기 |
| EP10 | 공개 주소에서 2024·2025 비교와 2025 한 회차 표시가 위 기준대로 보임 | 배포 후 공개 확인 | 대기 |
| EP11 | 2023·2024·2025 세 회차 적용 시 세 회차 선택이 유지되고, 방문자 특성은 확인된 최근 두 회차(2024·2025)를 오름차순으로 비교해 제목 `방문자 특성 · 2024년과 2025년`. 방문 구성은 세 행을 그대로 두고 요약만 값이 있는 최근 두 회차로 계산하며 제목에 그 두 연도. 한 회차 검증 실패 시 남은 확인 회차로 규칙 적용. 제한 안내 배너 없음(짧은 `최근 두 회차` 표시는 허용). 위쪽 회차 선택에서 두 회차를 고르면 그 두 회차를 비교 | 서버 단위·headless | 대기 |

세 회차 적용 시 표시 규칙은 [기능 상세 §11 표 2·5](../../2-design/functional-spec.md#11-두-회차-방문자-특성-비교)를 따르며 EP11로 검증한다. 가상 비율·순위를 실제 자료처럼 쓰지 않는다. 실제 보관본 시험과 통제 응답 시험은 구분해 기록한다.
축제별 거주지·실제 이동 경로·최종 시각 디자인·실무자 관찰·정형 API/Spec/Run 연결은 이 시나리오의 완료로 세지 않는다.
