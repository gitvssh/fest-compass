# TS-FC-022 · 축제 유형으로 찾기와 문화관광축제 방문 규모

[설계25](../../../design/25-festival-discovery.md) 1단계의 인수 기준이다. 실행 결과는 [검수47](../../../validation/47-festival-discovery.md)에 기록한다.
자동 시험은 `lib/existing/festival-types.test.ts`, `lib/existing/festival-marks.test.ts`, `lib/festival-sources/intro.test.ts`, `lib/datalab/scale.test.ts`, `scripts/festival-discovery-e2e.mjs`다.
v2(2단계)에서 D1의 `전체`는 아래 M5로 바뀌었다: 처음 화면에서는 어느 칩도 눌려 있지 않고, 눌린 칩을 다시 누르면 조건이 풀린다.

| 기준 | 확인할 결과 | 수단 |
|---|---|---|
| D1 | 검색 상자 아래 `축제 유형` 칩 일곱 개(전체·문화관광·문화예술·지역특산물·전통역사·생태자연·기타). 누르면 바로 적용되고 초점은 칩에 남으며 주소에 유형이 남는다. 입력 중인 이름은 함께 적용된다. 지역을 반만 고르면 검색 단추와 같은 안내만 보이고 검색하지 않는다. `전체`는 유형만 지우며 다른 조건이 없으면 처음 화면으로 돌아간다 | headless |
| D2 | 서버는 유형을 등록 분류 세 단계(EV·EV01·EV0103 형식)로 요청한다. 이름·지역 검색에도 같은 조건이 붙는다. 요청한 분류와 다른 행·분류 없는 행·쪽 누락·총건수 변동·중복이 있으면 목록 전체를 실패로 보인다. 지역 확인이 안 된 행은 빼고 센다. 잘못된 유형 값은 요청 오류다 | 단위 |
| D3 | 유형만 고르면 그해 그 유형의 전국 등록 축제를 날짜순으로 보이고, 40건을 넘으면 `축제 더 보기 (N건 남음)`으로 나눠 연다. 칩 옆 `○○축제 N건 보기`는 결과 제목으로 초점을 옮긴다. 0건이면 `○○축제 0건`과 다시 찾기 안내 | headless |
| D4 | 결과 카드·축제 머리에 등록 분류 표식(축제 여섯 분류는 아이콘, 공연·행사는 이름만). 고른 유형과 같은 표식은 카드에서 되풀이하지 않는다. 과거 기록 축제는 그 유형으로 돌아온 등록과 검토된 연결이 있을 때만 함께 보인다 | 단위·headless |
| D5 | 검색 출처 팝업에 유형과 `한국관광공사가 등록 정보에 붙인 분류`를 밝힌다. 화면에 분류 코드·내부 용어가 없다. 390px에서 가로 넘침 없이 칩 옆 안내가 첫 화면 안에 보인다. 기존 축제 목록 첫 줄은 1440×1000 첫 화면 안에 남는다 | headless |
| S1 | `/compare/scale` 기본은 최신 연도(2025)·일평균 순. 순서·값·개최일수·세 집단 비율이 내려받은 원문 파일에서 다시 계산한 값과 같다. 그해 자료 없는 축제는 `자료 없음`으로 따로 적는다 | 단위·headless |
| S2 | 순위 기준 `기간 합계`·`외지인 비율`·`현지인 비율`, 연도 바꾸기. 비율 기준은 100% 막대. 주소 `?year=&sort=`가 남고 알 수 없는 값은 최신 연도·일평균으로 돌아간다 | 단위·headless |
| S3 | 한쪽이 60% 이상이면 `외지인 중심`·`현지인 중심`, 아니면 `고르게`. 범례에 각 표시의 기획 의미(관광 연계·숙박 / 교통편·프로그램 / 둘 다)를 한 줄로 보인다 | 단위·headless |
| S4 | 위 세 칸: 하루 방문 최다·외지인 비율 최고·현지인 비율 최고(그해). 축제 이름은 연도별 방문 흐름으로 연결된다 | headless |
| S5 | `기준` 팝업: 행정동 이동통신 추정(입장객 아님)·일평균 정의와 긴 축제 주의·외국인 0 원문·60% 표시 기준·26곳 한정과 2020~21 없음·원문 링크. Esc로 닫히고 초점이 돌아온다 | headless |
| S6 | 입구: 홈·축제 비교·연도별 방문 흐름·축제 검색 유형 줄. 390px에서 연도 여섯 개가 한 줄, 가로 넘침 없음. 쓰기 요청·브라우저 오류 없음 | headless |

| M1 | 표시는 소개 글(프로그램·부대행사·이용 연령·이용 요금)에 낱말이 있을 때만: 체험, 어린이·가족(정해진 낱말 목록, 비슷한 낱말 제외), 무료/무료·일부 유료(요금 글만). 각 표시는 근거 글 조각을 가진다. HTML·문자 참조는 평문으로, 숫자 안 쉼표는 자르지 않는다 | 단위 |
| M2 | 수집: 등록 일정 조회 뒤 하루 한 번, 처음 200회·이후 40회, 순서(다가오는 미확인 → 지난 미확인 → 바뀐 등록 → 오래된 다가오는 축제 → 공연·행사), 지역 미확인 행 제외. 그날 시도한 등록은 다시 부르지 않고 소개 글 시도 기록은 별도 파일. 호출 한도·접근 오류는 즉시, 같은 오류 세 번이면 멈추고 이미 읽은 것은 저장. 파일에 키가 없다 | 단위 |
| M3 | 검색 결과의 각 등록에 저장된 표시(없으면 확인 전), 축제 조회는 그때 읽은 소개 글로 표시(날짜가 없어도). 저장소를 못 읽으면 표시 없이 목록은 정상, 고정 분류의 오류 기록 | 단위 |
| M4 | `소개 글로 거르기` 칩에 목록 안 표시 수, 고르면 서버에 다시 묻지 않고 모두 가진 축제만(그리고), 초점 유지, 주소 `mark=`로 유지·직접 진입. 확인 전 축제 수를 밝히고 거를 때 뺀다. 없으면 안내와 `거르기 지우기` | headless |
| M5 | `전체`: 이름·지역 없이 누르면 그해 모든 축제(여섯 분류, 공연·행사 행이 오면 목록 실패) 전국 목록. 이름·지역이 있으면 유형 조건 없음. 처음 화면은 눌린 칩 없음, 눌린 칩을 다시 누르면 조건 해제 | 단위·headless |
| M6 | 결과 카드에 표시 알약, 축제 머리에 표시와 `소개 글 근거` 팝업(근거 글·확인 시각·주최 측 안내 확인 문구·출처). Esc로 닫히고 초점 복귀. 화면에 내부 용어 없음 | headless |

실제 공급처의 분류 정확도(공급처가 붙인 값의 타당성), 화면 낭독기 실사용과 실제 사용자 관찰은 이 시험의 범위가 아니다(검수47에 미평가로 남긴다).
