# TS-FC-025 · 관광지 붐빔 예측과 함께 찾는 곳

[설계28](../../../design/28-kto-spot-signals.md)의 인수 기준이다. 실행 결과는 [검수50](../../../validation/50-kto-spot-signals.md)에 기록한다.
자동 시험은 `lib/kto-signals/signals.test.ts`(단위), `scripts/kto-signals-e2e.mjs`(화면)다.

| 기준 | 확인할 결과 | 수단 |
|---|---|---|
| K1 | 두 주소는 GET만 받고 정확한 지역 쌍(과 선택 달 YYYY-MM)만 허용한다. 응답에 인증키·공급처 오류 문구가 없고, 디스크·DB에 쓰지 않으며 같은 조건은 메모리에서 답한다(붐빔 1시간, 함께 찾는 곳 12시간) | 단위 |
| K2 | 전남·광주의 바뀐 시군구는 이전 코드부터 묻고, 구는 시 전체로 물어 그 사실을 보인다. 다른 지역·날짜 형식·값이 섞인 응답과 쪽마다 총건수가 바뀌는 응답은 쓰지 않는다 | 단위 |
| K3 | 붐빔 예측 카드: 두 칸 요약, 날마다 평균 막대, 30일 평균 높은 순 8곳과 모두 보기, 날짜별 표, 기준 팝업(관광지끼리 방문자 수 비교 아님·축제 방문객 예측 아님) | 단위, headless(검증용 FIXTURE) |
| K4 | 함께 찾는 곳 카드: 최신 달(비면 한 달 앞), 고를 수 있는 열두 달과 `달 보기`, 중심 관광지, 유형 거르기, 상위 10과 모두 보기, 다른 시군구 표시, 기준 팝업. 목록 밖 달은 잘못된 요청 | 단위, headless |
| K5 | 인증키가 없거나 공급처가 실패하면 `지금은 … 불러올 수 없어요`와 다시 불러오기, 자료가 없으면 지역·달 안내. 다른 화면 내용은 그대로다 | 단위, headless |
| K6 | 두 카드는 새 축제·기존 축제의 관광자원 화면에 있고 개최 시기 화면에는 없다. 390px에서 가로 넘침이 없고 넓은 표는 자기 영역에서 움직인다 | headless |
