# TS-FC-012 · 임실 방문 구성과 연간 추세

[기능 상세 §9](../../2-design/functional-spec.md#9-방문-구성과-지역-연간-추세)를 검증한다.
UC-FC-009·010의 방문 흐름 보강이며 아래 VC 번호는 이 시나리오 안에서만 사용한다.
실행 결과·공개 확인은 [검증 기록37](../../../validation/37-visitor-context.md)이 정본이다.

|---|---|---|
| VC1 | 원본 304개 CSV·5개 문서의 바이트 보존. 임실 지역 추이 1개만 추가 소비하며 26개 축제 수치는 바뀌지 않음 | 원본 해시·결정적 재생성·manifest 분류 시험 |
| VC2 | 임실군 2018~2025년 각 3구분. 과학적 표기와 원문 전체 보존, 0≠빈 값. 구분 누락·중복·잘못된 지역·합계·해시는 거부 | 생성·해석 단위 시험 |
| VC3 | 명시된 임실 축제·지역·회차 연결만 제공. 취소·날짜 없음·개최일수 불일치 제외. 창 기간을 바꿔도 원래 개최기간 구성 유지 | 연결·서비스 단위 및 실제 보관본 headless |

검증한 것으로 확대하지 않는다. API/Spec/Run 형식 연결·최종 시각 디자인·실무자 관찰은 별도다.
