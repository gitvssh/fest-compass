# TS-FC-007 · 운영 결과를 비교하고 다음 회차에 재사용한다

| 항목 | 내용 |
|---|---|
| 근거 | [UC-FC-007@v3](../../1-analysis/usecases/UC-FC-007.md) |
| 대상 환경 | 구현 후 격리된 로컬 브라우저 + 고정 자료 응답 |
| 실행 상태 | 미실행. 신규 기능과 실행 명세 개발 필요 |

## 데이터와 사전 조건

전체 입장 건수 계획 100과 지역 방문자 실측 120을 먼저 입력하고, 같은 입장 건수 실측 120으로 바꾼다. 계획 0 사례와 다음 회차 복사를 별도로 수행한다.
가상 데이터만 사용한다. 실제 API 자격·외부 기관 연락·공유 운영 자료 변경은 필요하지 않다.

## 실행할 과제와 기대 결과

다른 지표 100/120의 증감은 없고 같은 정의에서만 +20을 표시한다. 계획 0은 비율 없음이다. 복사 후 원본 회차는 그대로이고 새 회차의 일정·결정·실측은 비어 있어야 한다.

| 순서 | 사용자 과제 | 판정할 인수 기준 |
|---|---|---|
| 1 | 다른 지표 100/120, 같은 입장 건수 100/120, 계획 0을 각각 비교해 차이·비율 보류 조건을 확인한다. | AC1 |
| 2 | 개인 과거 회차와 공공 사례를 함께 검색하고 개인 출처와 외부 쓰기 요청 부재를 확인한다. | AC2 |
| 3 | 새 회차를 복사하고 원본 보존·일정/결정/실측 초기화·근거/견적 재확인을 확인한다. | AC3 |

## 공개 사례 반영 추가 과제

| 인수 기준 | 고정 입력·행동·기대 결과 |
|---|---|
| AC4 | 재원별 계획 보조금 30000000원/자부담 5000000원, 실제 30000000원/5118200원을 입력한다. 합계 35000000원→35118200원, 자부담 +118200원·보조금 증감 0원을 확인한다. 잔액·이자 원문 '-'는 미확인이며 0원·정산 완료를 추론하지 않는다. 반납액은 별도 미확인이다. |
| AC5 | 임차 비용에 계약/견적 참조만 넣고 수량·설치 위치 확인은 미확인으로 둔다. 준비된 자료와 확인 필요가 별개로 보이고 지급액을 정산 검토액으로 자동 복제하지 않는다. 차액이나 환수액을 자동 판정하지 않는다. |
| AC6 | 홍보 부족→안내 개선→차기 홍보비 확인 과제를 연결한 뒤 복사한다. 원본과 교훈 참조는 유지되고 새 과제는 기한 재입력·검토 미확인, 예산 분류와 견적은 재확인 상태다. 새 실제 사용액·결정·행사 날짜는 비어 있다. |

| AC7 | 기획 P1·결과 R1(실제 사용 35118200원·잔액/이자 미확인)으로 출력하고 R2에서 금액을 36000000원으로 수정한다. 기존 출력은 P1/R1·35118200원·단계·출처·미확인을 유지하고 새 출력에서만 R2를 선택한다. 결과가 없는 기획안에는 결과 생성 경로를 안내한다. |

추가 과제의 수치는 시험용 고정 입력이다. 실제 사례의 해석 범위는 [조사 출처](../../../research/2026-09-municipal-festival-sources.md)를 따른다. 현재 모두 미실행이다.

## 실패·복구 확인

지표 정의가 다르거나 계획이 0이면 비율 비교를 보류한다. 개인 기록은 다른 사용자의 공개 검색에 나타나지 않는다. 복사한 이전 자료는 최신으로 표시하지 않는다.
실패 입력을 한 뒤 기존 보관본과 다른 회차가 유지되는지 확인한다.

## 실행 증거와 정리

현재 Run은 없다. 개발 후 실행 파일과 결과를 specs·보고서 경로로 연결한다.
새 인수 기준은 기존 운영 E2E 결과로 통과 처리하지 않는다.
독립 브라우저 저장·고정 응답만 사용하고 종료 시 테스트 컨텍스트를 닫는다.
