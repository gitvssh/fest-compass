# TS-FC-013 · 임실 방문자 특성과 관광자원 연결

[기능 상세 §10](../../2-design/functional-spec.md#10-방문자-특성과-관광자원-연결)의 UC-FC-009 보강이다.
VP 번호는 이 시나리오 안에서만 사용한다. 실제 결과는 [검증 기록38](../../../validation/38-visitor-profile.md)에 남긴다.

| 기준 | 확인할 결과 | 수단 |
|---|---|---|
| VP1 | 공식 공개 UI에서 선택한 축제·2025년과 다섯 원본의 요청·바이트·해시가 일치. 기존 보관 CSV 불변 | 수집 재현·생성 검사 |
| VP2 | 다른 기간·ID·지역·개최일, 변형 원본·잘못된 비율/순위/장소 연결 거부 | 변형 자료 단위 시험 |
| VP3 | 임실 2025년 적용 회차에만 표시. 2024년만 선택·타 지역·늦은 이전 응답에는 생략, 차트 구간과 독립 | 서버·headless |
| VP4 | 8개 연령대의 남녀 비율이 원문과 일치. 분모는 내국인 전체, N 표시를 결측으로 바꾸지 않음 | 원문 직접 대조·표/차트 검사 |
| VP5 | 외지인·현지인·전체 각 7개 목적지. 원문 순위/식별자 유지, 세 곳만 관광자원 연결 | 원문·연결표·headless |
| VP6 | 현재 목록의 같은 지역/유형/식별자만 선택. 명시적 링크 우선, 실패 후 재시도·사라진 장소·잘못된 주소·늦은 응답 처리 | 통제 응답을 명시한 headless |
| VP7 | 뒤로가기 회차 유지, 상세 초점, 출처 창 키보드 닫기, 320/390/1440px 전체 가로 넘침 없음 | headless·직접 화면 검수 |
| VP8 | 비공개 인원·검색 건수·원본 경로·해시·내부 메모가 새 DTO/고객 문구에 없음. 앱 쓰기·페이지 오류 0 | 응답·화면·요청 검사 |

가상 방문자 비율을 실제 자료로 보여주지 않는다. 실제 보관본 시험과 현재 자원 조회 실패·누락을 재현한 통제 응답은 구분한다.
축제별 거주지·실제 이동 경로·전국 데이터 확보·최종 시각 디자인·실무자 관찰·정형 API/Spec/Run 연결은 완료로 세지 않는다.
