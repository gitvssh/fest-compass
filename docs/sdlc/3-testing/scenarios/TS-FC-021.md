# TS-FC-021 · 축제 기획 길잡이(묶음 1)와 팝업·초점 정제

[설계24](../../../design/24-planning-guide.md) §13의 인수 기준을 묶음 1 범위로 확정했다. G7(요청형 길잡이 패널)은 묶음 2라 제외한다.
실행 결과는 [검수46](../../../validation/46-planning-guide.md)에 기록한다. 자동 시험은 `scripts/planning-guide-e2e.mjs`와 `lib/guide/guide.test.ts`다.

| 기준 | 확인할 결과 | 수단 |
|---|---|---|
| G1 | 홈 카드마다 얻는 것 한 줄과 `축제 준비 전체 과정 보기` 띠. 두 시작 화면에 목표·네 할 일(순서, 번호 없음)·`처음이라면 이 순서로 · 순서는 자유`·판단은 담당자가·끝에 얻는 것. 흐름 지도에 누를 단계가 없고, 기존 축제 목록 첫 줄이 1440×900 첫 화면에 남는다 | headless |
| G2 | 탭 이름은 `할 일 · 자료 이름`이며 번호·방문 표시가 없다. 주소 이동·`aria-current`·이동 후 제목 초점이 지금과 같다. 모든 자료 화면 아래 `이어서`가 권장 순서의 다음 할 일로 가고 나머지 할 일도 한 번에 간다. 마지막 모아 보기는 축제 준비 전체 과정으로 잇는다 | headless |
| G3 | 자료 화면마다 안내 띠 하나: 목표·이 자료로 알 수 없는 것·평문 질문 2개 이하, 조작 요소 없음. 기존 방문 화면 부제는 대상·단위·기준만 두고 입장객 경고를 되풀이하지 않는다. 회차 카드에 개최 전·개최기간·종료 후 일평균(관측값, 묶음 자료에서 다시 계산한 값과 일치) | 단위·headless |
| G4 | 회차 기록이 하나이거나 없는 축제는 안내 띠에 범위 한 줄. 모아 보기의 방문 자료 실패는 그 영역만 경고·다시 불러오기, 나머지는 유지. 고른 것이 없으면 각 영역에 빈 상태와 해당 할 일 연결 | headless |
| G5 | 모아 보기는 입력 없이 이 탭에서 고른 것만 모은다(방문 흐름은 주소 조건, 장소·후보 기간·메모는 탭 기억). 새로 고침·주소 직접 진입 시 방문 흐름은 남고 나머지는 빈 상태가 된다. 지역·단위·기준·출처·수집 시각과 `개인 검토 자료이며 공식 문서가 아니에요`. 인쇄본은 메모 글을 싣고 탭·안내·버튼을 빼며 출력일을 붙인다. 완료 체크·평가 문장 없음 | 단위·headless |
| G6 | `/guide`: 그림(장식, 대체 글 없음), 일곱 단계 바로가기, 단계마다 하는 일·확인할 질문·협의할 곳·원문(공식 https 게시 페이지, 새 탭). 금액·기한·인원 기준 숫자 없음 | 단위·headless |
| G8 | 화면 문구에 추천·적합·최적·입장객 추정·수요·참가 규모·완료·적법·점수·내부 절차 용어가 없다 | 단위·headless |
| G9 | 390px·720px(1440px의 200%)에서 홈·두 시작 화면·자료 화면·두 모아 보기·`/guide` 가로 넘침 없음. 키보드로 탭·이어서·모아 보기·인쇄 단추를 쓴다 | headless |
| DS1 | 모달은 한 표면(아이콘 머리글·`닫기` 둥근 단추·흐린 배경)을 쓰고 Esc·닫기·배경 누름으로 닫히며 여는 단추로 초점이 돌아온다. 휴대폰은 아래에서 올라오는 시트 | headless |
| DS2 | 초점: 조작 요소 2px 고리·2px 간격, 입력칸은 테두리 안쪽 빛, 라벨 안 확인란·선택지는 라벨 전체 고리, 메뉴 항목은 안쪽 고리 | headless |

LCP·전송량 비교와 화면 낭독기 실제 사용, 실제 사용자 관찰은 이 시험의 범위가 아니다(검수46에 미평가로 남긴다).
