# 검수와 인수 검증

## 현재 판정

문서·와이어프레임은 검수 초안이다. M1 지도·개인 근거의 첫 구현을 자동 검증했고
TS-FC-001/003의 해당 범위에 [검증 결과](../../validation/20-region-explorer.md)를 연결했다.
M2 비교의 단위 8개·신규 headless 흐름 21개와 공개 동선을 확인하고 TS-FC-002의 부분 실행 범위에 [결과](../../validation/21-festival-comparison.md)를 연결했다.
M3의 근거·후보·장소/준비·불변 보관을 구현하고 TS-FC-003/004 해당 범위를 [검증 기록](../../validation/22-planning-options.md)에 연결했다. M4 단위 14개·headless 흐름 23개에서 TS-FC-005 AC1~9를 검증했고 [결과](../../validation/23-planning-budget.md)를 연결했다. M5 단위 7개·headless 흐름 14개와 PDF에서 TS-FC-006의 자동 검증을 추가했다([결과](../../validation/24-planning-proposal.md)). 각 TS의 전체 인수·실무자 관찰은 남아 있다.
이 문서의 시나리오 작성은 제품 시험 통과가 아니다.
기존 앱 시험·공개 개인 작업 검증은 [MVP 검증 이력](../../validation/15-mvp-journey.md)의 대상 코드에만 유효하다.

## D0 문서·화면 검수

- 기획안 산출물의 각 항목이 SRS·UC·화면으로 이어지는지 확인한다.
- 원본 Excalidraw 참조·Mermaid 문법·SVG 재생성 일치·사이트 문서 링크를 검사한다.
- 화면에 출처·지역·기간·단위·결측과 실제 표본/가상 입력 구분가 있는지 눈으로 확인한다.
- traceboard는 FR→UC→AC→TS와 화면을 연결한다. 실행 기록 없음과 미평가는 그대로 표시한다.
- 실제 담당자에게 아래 과제를 관찰하기 전까지 실무 적합성 검증은 미실시다.

## 실제 담당자 과제

'우리 지역의 올해 기획안 두 개를 비교하고, 아이템·장소·시기·예산 선택을 자료로 설명한다.'
시안에서는 예상 행동과 부족한 정보를 말하게 하고, 구현 후에는 무도움 완주 시간을 잰다.
15분 내 완주는 목표 초안이며 달성 실적이 아니다.
정보 수요 순서, 자료를 담는 이유, 추가로 필요한 비용·장소 정보, 지표 오해 여부를 기록한다.
참여자 모집·외부 연락은 별도 요청 없이 실행하지 않는다.

## 실행 연결 원칙

새 TS는 구현 후 실행 파일과 결과를 연결한다. 현재 specs는 비어 있으며 가짜 Run을 만들지 않는다.
API가 확정되지 않은 기획 단계에서 존재하지 않는 엔드포인트를 만들어 연결하지 않는다.
현재 서버 액션·개인 브라우저 저장을 고려해 실행 경로를 정하고 필요한 계약만 후속으로 추가한다.

## v2 공개 사례 반례

UC·TS v2는 부분 용역과 전체 비용 비교 보류, 재원 예정/확정 분리, 기간 중복 산출 방지,
예산 단계별 보존, 연도별 분류 재확인, 전년 증감 사유, 자료 존재와 검토 상태 분리,
보조금/자부담 증감, '-'의 미확인 보존, 다음 회차 초기화를 추가한다.
출력은 사업설명·준비 목록의 동일 기획 버전 및 결과 출력의 기획/결과 버전 쌍을 검증한다.
신규 관계를 포함한 파일 복원 실패·과제 순환도 확인한다. M1~M3의 해당 범위는 각 검증 기록을 따르며 예산·기획안은 M4/M5 검증 기록을 따르며 결과 신규 실행은 미실행이다.

담당자 검수에서는 지역 지도부터 예산 요구 설명까지의 정보량, 부분 용역비 비교 오해,
예정 재원의 해석, 보완 요청 후 새 버전 작성, 전회차 홍보 개선의 차기 예산 연결을 관찰한다.
예산안·계약·정산 전 과정을 연결한 추가 공개 문서 확보와 실제 실무자 관찰은 후속 증거이며,
이번 문서·시안 검증을 그 실적으로 보고하지 않는다.

## v3 전국·그래프 검증

일반 진입 전국 지도, 시도→시군구와 상위 복귀, 위치 권한 없이 목록 탐색, 페이지 일부 실패와 미확보 지역 표시를 검사한다.
보관한 실제 논산 표본은 원천 해시·45개 값·날짜·회차를 대조한다. 고정 가상 반례와 실제 표본의 목적을 구분한다.
과거 검색 누락과 현재 상세 갱신이 과거 회차를 덮지 않는지, 선의 누락 구간과 공통 축·수치 표, 파이 분모·미산정·총액 0을 검사한다.
키보드 날짜/항목 선택→근거 저장→출력에서 값·출처·누락이 유지되는지 확인한다.

브라우저 자동 검증은 사용자 요청에 따라 **headless**로 실행한다. `--headed`, UI 모드, 디버그 창을 사용하지 않는다.
문서 사이트 표시·정적 SVG 검사는 제품의 상호작용 인수 TS 통과로 환산하지 않는다. TS-FC-001~004의 해당 구현 범위는 검증 기록을 따르고 나머지 신규 TS는 미실행이다.
