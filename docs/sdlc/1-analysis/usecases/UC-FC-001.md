# UC-FC-001 · 우리 지역의 관광자원과 방문 추세를 조회한다

| 항목 | 내용 |
|---|---|
| 액터 | 지자체 축제 담당자 |
| 목적 | 자기 지역의 자원과 방문 추세를 확인해 추가 조사할 축제·장소를 찾는다. |
| 구현 상태 | M1 첫 기능 구현·검증. 전체 기획 연결·실무 관찰은 후속 |

## 사전 조건

확인된 자료 보유 목록을 읽을 수 있다. 지도 공급자가 준비되지 않은 경우 목록 탐색은 가능하다.

## 기본 흐름

1. 전국에서 시도→시군구와 기획 연도를 선택한다. 상위 경로로 돌아갈 수 있고 시스템이 지역명과 자료 보유 범위를 제시한다.
2. 통계 기간·행사 기간·자료 종류를 지정한다. 지도·목록·차트가 같은 조건으로 바뀐다.
3. 지도를 이동한 후 이 영역 조회를 선택하면 공간 필터가 표시된다.
4. 자원이나 지표를 선택해 상세와 출처를 보고 기획 근거에 담는다.

## 대안·예외 흐름

좌표 없음은 목록에 유지한다. 미수집 지역에서는 이전 지역 숫자를 제거하고 자료 부족을 표시한다. 일부 API 오류는 해당 자료만 재시도하며 늦은 이전 응답은 무시한다.

## 공개 사례를 반영한 상세 흐름

1. 지역 지도를 열면: 자료 탐색과 근거 담기가 가능하고 장소 사용 가능 여부는 별도 확인 상태로 보인다.

판정에 필요한 필드와 계산은 [자료 정의](../data-contract.md)를 따른다. 외부 기관의 결재·계약·정산 검토를 이 앱에서 처리한 것으로 표시하지 않는다.

## 수용 기준

- [ ] AC1: Given 논산을 보고 있는 상태에서 When 자료가 없는 다른 시군구로 바꾸면 Then 모든 영역의 지역명이 바뀌고 논산 수치는 새 지역의 값으로 남지 않는다.
- [ ] AC2: Given 같은 조건의 자료가 있을 때 When 기간 또는 유형을 바꾸면 Then 지도·목록·차트의 조회 조건이 일치하고 이전 응답이 최신 선택을 덮지 않는다.
- [ ] AC3: Given 좌표 없는 자원과 API 일부 오류가 있을 때 When 조회하면 Then 자원은 목록에 남고 오류와 결측은 0과 구분된다.
- [ ] AC4: Given 자원·지역 통계를 선택했을 때 When 상세를 열면 Then 공간·시간·단위·출처를 확인하고 지역 통계가 행사장 혼잡으로 표시되지 않는다.

- [ ] AC5: Given 예산·사업 부서가 아직 입력되지 않았을 때 When 지역 지도를 열면 Then 자료 탐색과 근거 담기가 가능하고 장소 사용 가능 여부는 별도 확인 상태로 보인다.

- [ ] AC6: Given 첫 방문 또는 일반 재방문일 때 When 지도를 열면 Then 위치·담당 지역 입력 없이 전국과 제주·도서 지역을 보고 시도→시군구 및 상위 경로로 이동하며 우리 지역 복귀는 명시적 버튼으로 수행한다.
- [ ] AC7: Given 일부 지역·페이지 자료만 있을 때 When 전국 현황을 보면 Then 미확보와 0·부분 조회를 구분하고 시군구 합을 전국 고유 방문객이나 첫 페이지를 전체 축제 수로 표시하지 않는다.
