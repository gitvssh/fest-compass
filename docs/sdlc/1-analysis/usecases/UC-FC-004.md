# UC-FC-004 · 아이템·장소·시기가 다른 기획 대안을 구성한다

| 항목 | 내용 |
|---|---|
| 액터 | 지자체 축제 담당자 |
| 목적 | 지역 강점과 비교 사례를 축제 기획 대안으로 바꾼다. |
| 구현 상태 | M3 첫 기능 구현·자동 검증. 완성 기획안·실무자 관찰은 후속 |

## 사전 조건

근거 목록이 있거나 자료 부족을 확인했다. 기획 담당 지역을 정했다.

## 기본 흐름

1. 주제·아이템·대상·장소·기간을 입력해 후보 A를 만든다.
2. 내용을 조정해 후보 B를 만들고 달라진 항목을 확인한다.
3. 아이템·장소·시기별로 근거를 연결하고 미확인 제약과 담당자 가정을 적는다.
4. 후보별 준비 내역과 비용을 입력하러 이동한다.

## 대안·예외 흐름

자료가 없으면 담당자 가정으로 기록할 수 있으나 실측 근거로 표시하지 않는다. 다른 지역 사례 선택이 담당 지역을 바꾸지 않는다. 장소 사용 가능 여부가 없으면 미확인으로 남긴다.

## 공개 사례를 반영한 상세 흐름

1. 사업 정보를 입력하면: 회계연도·부서·목적·신규/계속과 복수 수행 관계를 함께 남기며 재단을 보조사업으로 자동 분류하지 않는다.
2. 설치·행사·철거 일정을 작성하면: 기간별 사용 가능·시설 조건·확인 담당과 미확인 사항이 구분되고 기간 변경 시 관련 준비·견적은 재확인 대상으로 남는다.
3. 참조를 추가하거나 해당 없음을 선택하면: 첨부만으로 완료되지 않고 확인 상태·담당·기한·의존 관계 및 해당 없음 사유를 남긴다.

판정에 필요한 필드와 계산은 [자료 정의](../data-contract.md)를 따른다. 외부 기관의 결재·계약·정산 검토를 이 앱에서 처리한 것으로 표시하지 않는다.

## 수용 기준

- [ ] AC1: Given 작성 중인 후보가 있을 때 When 다른 아이템·장소·시기의 두 번째 후보를 만들면 Then 두 후보를 같은 항목으로 비교하고 차이를 확인할 수 있다.
- [ ] AC2: Given 후보의 선택 이유를 적을 때 When 근거 또는 가정을 연결하면 Then 자료 출처와 담당자 판단이 구분되고 미확인 제약이 남는다.
- [ ] AC3: Given 다른 지역을 탐색하거나 보관 후 수정할 때 When 새 후보를 만들면 Then 담당 지역과 이전 보관본을 자동 변경하지 않는다.

- [ ] AC4: Given 재단이 수행하고 일부 업무를 용역으로 맡기는 기획일 때 When 사업 정보를 입력하면 Then 회계연도·부서·목적·신규/계속과 복수 수행 관계를 함께 남기며 재단을 보조사업으로 자동 분류하지 않는다.
- [ ] AC5: Given 장소의 관광정보만 있고 대관 확인은 없을 때 When 설치·행사·철거 일정을 작성하면 Then 기간별 사용 가능·시설 조건·확인 담당과 미확인 사항이 구분되고 기간 변경 시 관련 준비·견적은 재확인 대상으로 남는다.
- [ ] AC6: Given 선행 업무와 검토할 자료가 있는 준비 과제일 때 When 참조를 추가하거나 해당 없음을 선택하면 Then 첨부만으로 완료되지 않고 확인 상태·담당·기한·의존 관계 및 해당 없음 사유를 남긴다.

- [ ] AC7: Given 관광자원을 담은 근거가 있을 때 When 미리보기를 확인하고 장소 입력을 적용하면 Then 이름·주소와 출처 사본을 함께 연결하고 담당 지역·보관본은 유지하며 장소 변경 후 관련 확인은 재검토한다.
