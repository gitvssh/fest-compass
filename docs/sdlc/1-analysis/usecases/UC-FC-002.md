# UC-FC-002 · 주변 행사와 과거 개최회차를 같은 기준으로 비교한다

| 항목 | 내용 |
|---|---|
| 액터 | 지자체 축제 담당자 |
| 목적 | 참고 사례와 일정 중복을 확인하고 비교할 수 없는 자료를 알아본다. |
| 구현 상태 | 개발 필요. active는 유효한 요구이며 구현 완료가 아님 |

## 사전 조건

지역 선택이 있거나 회차 링크로 진입했다. 공공 자료와 개인 과거 기록을 구분할 수 있다.

## 기본 흐름

1. 주변 지역과 개최기간·주제를 지정한다.
2. 검색 결과에서 축제와 회차, 확인일·취소/변경 표시를 확인한다.
3. 회차 두 개를 선택해 같은 단위의 지표를 비교한다.
4. 비교 조건과 참고할 사례를 근거에 담고 후보 기획으로 이동한다.

## 대안·예외 흐름

기간 누락 회차는 '일정 미확인'으로 별도 표시한다. 같은 이름만으로 회차를 합치지 않는다. 좌표 결측은 거리 계산에서 제외하되 지역 검색에서 유지한다. 자료 정의 차이는 비교 불가 사유로 남긴다.

## 공개 사례를 반영한 상세 흐름

1. 비용을 비교하면: 문서 단계·포함 범위·연도·원단위·세금 기준을 표시하고 차액·순위를 계산하지 않는다.
2. 연도 또는 세금·부서 포함 범위가 미확인이면: 금액은 남기고 비교 보류 사유를 보여준다.

판정에 필요한 필드와 계산은 [자료 정의](../data-contract.md)를 따른다. 외부 기관의 결재·계약·정산 검토를 이 앱에서 처리한 것으로 표시하지 않는다.

## 수용 기준

- [ ] AC1: Given 이름이 같은 서로 다른 축제와 한 축제의 두 회차가 있을 때 When 검색하면 Then 축제 ID와 회차 ID로 구분하고 취소/변경과 확인일을 볼 수 있다.
- [ ] AC2: Given 입장 건수와 지역 방문자 또는 총사업비와 지원금이 섞였을 때 When 비교하면 Then 동일 지표로 순위·증감·합계를 계산하지 않고 이유를 표시한다.
- [ ] AC3: Given 회차 두 개를 비교 중일 때 When 근거로 담으면 Then 선택 ID·검색 조건·당시 값·출처가 함께 남는다.
- [ ] AC4: Given 한 회차에 예산 또는 날짜가 없을 때 When 비교하면 Then 후보를 유지하고 미확인 항목을 표시하며 빈 결과를 행사 없음으로 단정하지 않는다.

- [ ] AC5: Given 전체 행사 요구액과 일부 무대 용역 기초금액이 있을 때 When 비용을 비교하면 Then 문서 단계·포함 범위·연도·원단위·세금 기준을 표시하고 차액·순위를 계산하지 않는다.
- [ ] AC6: Given 같은 범위의 두 회차 비용이 있을 때 When 연도 또는 세금·부서 포함 범위가 미확인이면 Then 금액은 남기고 비교 보류 사유를 보여준다.

- [ ] AC7: Given 현재 축제 상세와 과거 회차 원문이 다를 때 When 과거를 검색하면 Then 회차별 일정·출처·확인일을 유지하고 현재 상세로 덮지 않으며 검색 누락을 미개최로 단정하지 않는다.
- [ ] AC8: Given 같은 지표의 과거 값과 결측이 있을 때 When 그래프로 비교하면 Then 공통 축·단위와 실제 날짜·상대 날짜 기준·개최 일수를 표시하고 결측 선을 잇지 않으며 수치 표와 값이 일치한다.
- [ ] AC9: Given 회차별 확보 지표가 다를 때 When 비교하면 Then 확보 현황과 비교 보류 사유를 보여주고 가용 지표는 유지하며 키보드로 선택한 점·기간을 당시 값·출처와 함께 담는다.
