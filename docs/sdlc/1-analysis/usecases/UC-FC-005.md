# UC-FC-005 · 준비 내역과 항목별 예산을 비교한다

| 항목 | 내용 |
|---|---|
| 액터 | 지자체 축제 담당자 |
| 목적 | 기획 후보별 필요한 준비와 비용을 설명한다. |
| 구현 상태 | 개발 필요. active는 유효한 요구이며 구현 완료가 아님 |

## 사전 조건

기획 후보가 있고 단가의 출처 또는 가정임을 적을 수 있다.

## 기본 흐름

1. 후보별 항목·수량·단가·세금 기준·출처를 입력한다.
2. 확인 합계와 미산정 항목 수를 확인한다.
3. 예산 한도를 입력하고 후보별 초과액과 다른 비용 항목을 비교한다.
4. 운영 제약을 확인해 선택 이유와 함께 기획안으로 넘긴다.

## 대안·예외 흐름

음수·유효하지 않은 숫자는 저장을 거부하며 입력을 유지한다. 수량/단가 결측은 총액 미확정이다. 세금 기준 혼재는 확정 총액 표시를 막고 기준 통일을 안내한다. 인력·셔틀 증가만으로 안전 효과를 산출하지 않는다.

## 공개 사례를 반영한 상세 흐름

1. 합계를 보면: 재원 확정/예정과 지출을 별도로 표시하고 서로 더하거나 예정 재원을 확보액으로 계산하지 않는다.
2. 일괄 견적과 일별 단가를 계산하면: 기간을 중복 곱하지 않고 단계별 금액 기록을 덮어쓰지 않는다.
3. 현재 산출과 비교하면: 기준 버전·수량/단가/기간/범위 변경 사유와 관련 부서 포함 여부를 표시하고 정의가 다르면 차액을 보류한다.
4. 분류를 고르면: 적용 연도·지침 출처·검토 상태를 기록하고 과거 분류를 자동 변경하거나 새 분류 확정으로 복사하지 않는다.

판정에 필요한 필드와 계산은 [자료 정의](../data-contract.md)를 따른다. 외부 기관의 결재·계약·정산 검토를 이 앱에서 처리한 것으로 표시하지 않는다.
