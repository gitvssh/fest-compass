# UC-FC-005 · 준비 내역과 항목별 예산을 비교한다

| 항목 | 내용 |
|---|---|
| 액터 | 지자체 축제 담당자 |
| 목적 | 기획 후보별 필요한 준비와 비용을 설명한다. |
| 구현 상태 | 개발 필요. active는 유효한 요구이며 구현 완료가 아님 |

## 사전 조건

기획 후보가 있고 단가의 출처 또는 가정임을 적을 수 있다.

## 기본 흐름

1. 후보별 항목·수량·단가·세금 기준·출처를 입력한다.
2. 확인 합계와 미산정 항목 수를 확인한다.
3. 예산 한도를 입력하고 후보별 초과액과 다른 비용 항목을 비교한다.
4. 운영 제약을 확인해 선택 이유와 함께 기획안으로 넘긴다.

## 대안·예외 흐름

음수·유효하지 않은 숫자는 저장을 거부하며 입력을 유지한다. 수량/단가 결측은 총액 미확정이다. 세금 기준 혼재는 확정 총액 표시를 막고 기준 통일을 안내한다. 인력·셔틀 증가만으로 안전 효과를 산출하지 않는다.

## 수용 기준

- [ ] AC1: Given 수량·단가가 유효할 때 When 비용을 계산하면 Then 항목별 원 단위 반올림 결과의 합과 표시 합계가 일치한다.
- [ ] AC2: Given 단가가 빈 항목과 0원 항목이 있을 때 When 합계를 보면 Then 미산정과 명시적 0원이 구분되고 미산정 상태에서 확정 총액으로 표시하지 않는다.
- [ ] AC3: Given 확인 합계가 한도를 넘거나 세금 기준이 섞였을 때 When 비교하면 Then 초과액과 기준 불일치를 표시하고 근거 없는 안전 효과를 제시하지 않는다.
