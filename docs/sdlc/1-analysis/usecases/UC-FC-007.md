# UC-FC-007 · 운영 결과를 비교하고 다음 회차에 재사용한다

| 항목 | 내용 |
|---|---|
| 액터 | 지자체 축제 담당자 |
| 목적 | 이번 기획의 결과를 같은 기준으로 평가해 다음 행사 준비를 줄인다. |
| 구현 상태 | 개발 필요. active는 유효한 요구이며 구현 완료가 아님 |

## 사전 조건

기획안 보관본과 실제 결과 또는 결측 사유가 있다.

## 기본 흐름

1. 기준 기획안 버전을 선택하고 현장 조치·실측·실제 비용·교훈을 기록한다.
2. 같은 정의의 계획 대비 결과를 확인한다.
3. 개인 과거 회차로 검색해 다른 사례와 비교한다.
4. 다음 회차 초안을 만들고 날짜·근거·견적을 재확인한다.

## 대안·예외 흐름

지표 정의가 다르거나 계획이 0이면 비율 비교를 보류한다. 개인 기록은 다른 사용자의 공개 검색에 나타나지 않는다. 복사한 이전 자료는 최신으로 표시하지 않는다.

## 수용 기준

- [ ] AC1: Given 계획과 실측의 지표·단위가 다르거나 계획이 0일 때 When 결과를 비교하면 Then 정의 차이 또는 비율 미산정 사유가 보인다.
- [ ] AC2: Given 개인 과거 회차를 검색했을 때 When 공공 사례와 함께 보면 Then 개인 기록 출처가 구분되고 외부 공개 전송 없이 조회된다.
- [ ] AC3: Given 다음 회차로 복사할 때 When 새 초안을 열면 Then 원본을 보존하고 일정·실측·결정은 새로 입력하며 복사한 근거·견적은 재확인 표시가 있다.

## 사후 상태와 검증

사용자가 선택한 기록이 개인 저장 경계 안에 남고 이전 보관본은 유지된다.
