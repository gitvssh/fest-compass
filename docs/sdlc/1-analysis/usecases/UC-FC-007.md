# UC-FC-007 · 운영 결과를 비교하고 다음 회차에 재사용한다

| 항목 | 내용 |
|---|---|
| 액터 | 지자체 축제 담당자 |
| 목적 | 이번 기획의 결과를 같은 기준으로 평가해 다음 행사 준비를 줄인다. |
| 구현 상태 | 첫 구현·자동 검증. 공개 게시 상태는 M6 검증 기록 참조, 실무자 인수 미실시 |

## 사전 조건

기획안 보관본과 실제 결과 또는 결측 사유가 있다.

## 기본 흐름

1. 기준 기획안 버전을 선택하고 현장 조치·실측·실제 비용·교훈을 기록한다.
2. 같은 정의의 계획 대비 결과를 확인한다.
3. 개인 과거 회차로 검색해 다른 사례와 비교한다.
4. 기준 기획안과 결과 버전을 선택해 결과·개선 자료를 출력한다.
5. 다음 회차 초안을 만들고 날짜·근거·견적을 재확인한다.

## 대안·예외 흐름

지표 정의가 다르거나 계획이 0이면 비율 비교를 보류한다. 개인 기록은 다른 사용자의 공개 검색에 나타나지 않는다. 복사한 이전 자료는 최신으로 표시하지 않는다.

## 공개 사례를 반영한 상세 흐름

1. 결과를 비교하면: 보조금·자부담·합계를 구분하고 잔액·반납·이자는 미확인과 0을 별도로 표시한다.
2. 비용 및 증빙 상태를 확인하면: 증빙 종류·범위·확인 상태를 구분하고 링크 존재만으로 지출 적정성이나 정산 완료를 판정하지 않는다.
3. 다음 회차 초안을 만들면: 문제·조치·차기 예산/준비 과제 연결은 근거로 남고 날짜·실측·외부 검토 완료 상태는 초기화된다.

판정에 필요한 필드와 계산은 [자료 정의](../data-contract.md)를 따른다. 외부 기관의 결재·계약·정산 검토를 이 앱에서 처리한 것으로 표시하지 않는다.
