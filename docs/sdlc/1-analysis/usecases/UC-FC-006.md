# UC-FC-006 · 근거가 연결된 기획안을 보관하고 출력한다

[M5 구현](../../2-design/proposal-implementation.md)과 [검증 결과](../../../validation/24-planning-proposal.md)를 연결했다. 아래 인수 기준은 유지한다.

| 항목 | 내용 |
|---|---|
| 액터 | 지자체 축제 담당자 |
| 목적 | 왜 이 아이템·장소·시기·예산인지 설명 가능한 자료를 남긴다. |
| 구현 상태 | 첫 기능 사용 가능. AC1~6 자동 검증·출력 검수 완료, 실제 담당자 관찰 미실시 |

## 사전 조건

두 후보가 있고 선택 이유를 작성했다. 미산정·미확인 사항은 누락 없이 표시된다.

## 기본 흐름

1. 선택 후보와 대안을 검토하고 선택·제외 이유를 작성한다.
2. 당시 자료·비용·제약을 포함한 기획안 보관본을 만든다.
3. 기획안을 인쇄 또는 PDF로 보관한다.
4. 변경이 필요하면 새 버전 초안을 만든다.

## 대안·예외 흐름

후보 한 개 또는 선택 이유 없음은 비교 기획안 보관을 막고 초안 저장을 허용한다. 근거 없는 필드는 미확인으로 출력한다. 예산 미확정은 문서 상태로 명시한다.

## 공개 사례를 반영한 상세 흐름

1. 사업설명 자료나 준비 목록을 출력하면: 같은 보관 버전의 기준일·단계·담당·기한·미확인·출처를 포함한다.
2. 기존 출력본을 열면: 이전 확인 상태가 유지되고 새 상태는 새 버전에만 반영된다.

판정에 필요한 필드와 계산은 [자료 정의](../data-contract.md)를 따른다. 외부 기관의 결재·계약·정산 검토를 이 앱에서 처리한 것으로 표시하지 않는다.
