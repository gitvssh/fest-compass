# UC-FC-006 · 근거가 연결된 기획안을 보관하고 출력한다

| 항목 | 내용 |
|---|---|
| 액터 | 지자체 축제 담당자 |
| 목적 | 왜 이 아이템·장소·시기·예산인지 설명 가능한 자료를 남긴다. |
| 구현 상태 | 개발 필요. active는 유효한 요구이며 구현 완료가 아님 |

## 사전 조건

두 후보가 있고 선택 이유를 작성했다. 미산정·미확인 사항은 누락 없이 표시된다.

## 기본 흐름

1. 선택 후보와 대안을 검토하고 선택·제외 이유를 작성한다.
2. 당시 자료·비용·제약을 포함한 기획안 보관본을 만든다.
3. 기획안을 인쇄 또는 PDF로 보관한다.
4. 변경이 필요하면 새 버전 초안을 만든다.

## 대안·예외 흐름

후보 한 개 또는 선택 이유 없음은 비교 기획안 보관을 막고 초안 저장을 허용한다. 근거 없는 필드는 미확인으로 출력한다. 예산 미확정은 문서 상태로 명시한다.

## 수용 기준

- [ ] AC1: Given 두 후보와 선택 이유가 있을 때 When 기획안을 보관하면 Then 주제·대상·장소·기간·대안·근거·비용·제약을 함께 읽을 수 있다.
- [ ] AC2: Given 기획안 보관 뒤 원천 자료와 후보 비용이 바뀌었을 때 When 기존 보관본을 열면 Then 당시 값과 조회 조건·선택 이유가 유지된다.
- [ ] AC3: Given 인쇄할 기획안에 미산정 비용이 있을 때 When 출력하면 Then 미산정·출처·생성 시점·버전이 남고 공식 승인으로 표시되지 않는다.

## 사후 상태와 검증

사용자가 선택한 기록이 개인 저장 경계 안에 남고 이전 보관본은 유지된다.
