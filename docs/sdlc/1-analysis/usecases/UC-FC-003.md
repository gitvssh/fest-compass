# UC-FC-003 · 필요한 자료를 기획 근거로 보관한다

| 항목 | 내용 |
|---|---|
| 액터 | 지자체 축제 담당자 |
| 목적 | 선택한 자료가 어떤 기획 판단에 쓰이는지 관리한다. |
| 구현 상태 | 개발 필요. active는 유효한 요구이며 구현 완료가 아님 |

## 사전 조건

지도 상세·비교 결과·개인 과거 기록 중 하나를 선택했다.

## 기본 흐름

1. 기획 근거에 담기를 누르고 저장될 지역·기간·출처를 확인한다.
2. 근거 목록에서 자료를 선택해 적용할 후보와 판단 항목을 지정한다.
3. 새 자료가 있으면 기존 사본을 보면서 새 버전으로 추가한다.
4. 불필요한 근거를 초안에서 제외하고 이미 보관한 기획안의 근거는 유지한다.

## 대안·예외 흐름

같은 원천·조건·시점 중복은 기존 근거로 안내한다. 다른 버전은 별도로 보관한다. 원문 링크가 끊겨도 당시 값과 출처 정보는 남는다. 보관본에서 사용한 근거는 초안 삭제로 지워지지 않는다.

## 수용 기준

- [ ] AC1: Given 근거를 담은 뒤 원천 값이 바뀌었을 때 When 보관 근거를 열면 Then 선택 당시 값과 조회 조건이 유지된다.
- [ ] AC2: Given 같은 원천·조건·시점의 자료가 이미 있을 때 When 다시 담으면 Then 중복을 안내하고 후보 연결을 잃지 않는다.
- [ ] AC3: Given 보관 기획안이 참조한 근거가 있을 때 When 초안에서 제외하면 Then 기존 기획안의 근거 사본은 보존된다.

## 사후 상태와 검증

사용자가 선택한 기록이 개인 저장 경계 안에 남고 이전 보관본은 유지된다.
검증: [TS-FC-003](../../3-testing/scenarios/TS-FC-003.md). 미실행이며 실행 API·명세는 구현 단계에서 연결한다.
