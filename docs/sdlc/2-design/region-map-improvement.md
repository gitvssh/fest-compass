# 전국·지역 지도 개선

## 문제와 이번 범위

M1~M6 첫 흐름을 연결한 다음, 사용자가 지적한 지도 품질을 우선 개선한다.
기존 육지 윤곽 지도에는 도로·주변 장소가 없고 버튼으로만 이동해 실제 관광자원의 위치 관계를 파악하기 어렵다.
이번 범위는 `/regions`의 배경지도·드래그/터치/키보드 이동·선택 연동·명시적 공간 필터다.
사업·예산 입력 없이 전국에서 시작하고, 시도→시군구 목록·공공데이터 출처·근거 보관은 유지한다.

## 요구사항과 화면

1. 전국은 제주와 울릉도·독도를 포함하는 초기 범위로 시작한다. 저장한 우리 지역은 명시적 바로가기다.
2. 시도 표식은 선택용 위치이며 행정경계를 뜻하지 않는다. 기존 관광공사 코드·명칭을 보존하고 배경지도의 경계를 최신 법정 경계로 인증하지 않는다.
3. 실제 도로 배경 위에서 드래그·터치 확대·키보드·확대/축소 버튼으로 이동한다. 페이지 스크롤을 지도 휠 확대가 가로채지 않는다.
4. 조회된 좌표를 모두 볼 수 있게 맞추고, 같은 위치 또는 가까운 표식은 묶는다. 묶음은 포함 자료를 펼치며 목록과 같은 번호를 유지한다. 좌표 없는 자료는 목록에 남긴다.
5. 목록·지도 선택은 같은 상세와 선택 표시를 사용한다. 항목 선택·메모 편집 때문에 지도가 전국으로 돌아가지 않는다.
6. 지도 이동은 조회 조건을 즉시 바꾸지 않는다. `이 영역의 자료 보기`를 눌러 이미 조회한 목록을 좁히며 적용한 범위를 표시한다. 새 공공 API 호출이나 시군구 방문 통계의 공간 세분화로 표현하지 않는다.
7. `조회 자료에 맞추기`와 `공간 필터 해제`로 되돌린다. 근거에는 적용한 경위도 범위를 그대로 보관한다.
8. 배경 오류 시 안내와 간단 지도 전환을 제공한다. 지도 없이도 지역 목록·상세·근거 보관을 사용할 수 있다.

화면은 기존 지역 경로→시도/시군구 선택→지도 도구/배경→조회 조건·자원 목록→지역 방문 추세→선택 자료·근거 순서다.
지도 하단에는 출처와 장소 확인 한계를 상시 표시하고, 모바일에서도 도구·출처가 가려지지 않게 한다.
시도 이름이 겹치면 가까운 빈 위치로 옮기고 원래 선택용 위치에 연결선을 남긴다. 자료 선택은 지도 팝업과 상세를 함께 바꾸며, 상세로 스크롤하는 동작은 지도 아래 별도 버튼으로 제공한다.

## 제공자·데이터 경계

- Leaflet 1.9.4를 앱에 포함한다. [공식 문서](https://leafletjs.com/reference.html)의 공개 API를 사용하며 CDN 스크립트는 추가하지 않는다.
- 기본 배경은 `https://tile.openstreetmap.org/{z}/{x}/{y}.png`. [OSMF 사용 정책](https://operations.osmfoundation.org/policies/tiles/)을 2026-09-09 확인했다.
- 현재 화면의 이미지 요청만 허용하고 브라우저 기본 캐시와 origin Referer를 유지한다. 대량 수집·오프라인 저장·예측 이동 선취득·서버 프록시는 제공하지 않는다. 지도 위에 OpenStreetMap 저작자 표시를 남긴다.
- 지도 제공자에게 브라우저 IP·요청 지도 영역·사이트 origin이 전달된다. 기획 메모·이름·예산·선택 자료 원문을 보내지 않는다. 이는 선택 분석과 구분되는 지도 표시 요청이며 개인정보 안내에 설명한다.
- [정식 경계 원본·지역 코드 대조](region-boundary-contract.md)에서 2025년 원본을 확보했다. 공식 연계·형상 검증과 화면 연결, 전국 과거 방문 이력·비용 자료 확장은 후속이다. 도로 지도만으로 장소 사용 가능 여부·안전·공식 행정구역을 확정하지 않는다.

## 검증 계획

headless 자동화는 OSMF 서버에 지도 이동 요청을 보내지 않고 시험용 이미지 응답을 사용한다. 실제 제공자 가용성을 이 시험으로 주장하지 않는다.
전국 복귀·시도/시군구·표식 묶음/선택·드래그/키보드·휠 스크롤·명시적 공간 필터·근거 범위 보존·좌표 누락·배경 실패·390px·출처·개인정보 요청 경계를 검사한다.
기존 지역 14개와 근거·기획 흐름 회귀, 타입/빌드·필수 배포 검사 뒤 공개 앱과 Traceboard 검수본에 반영한다.

## 직접 검수할 행동

1. [관광지도](https://kto.damecasol.com/regions)에서 전국→시도→시군구로 이동한다.
2. 자료 묶음을 펼쳐 하나를 고른 뒤 상세·출처를 확인한다.
3. 지도를 이동하고 `이 영역의 자료 보기`를 눌러 목록과 붉은 점선 범위를 확인한다.
4. 이유를 적어 근거로 담은 뒤 후보 기획에서 해당 근거를 선택한다.
5. `간단 지도`로 바꿔 외부 배경 없이도 지역·자료 탐색이 가능한지 확인한다.

실행 결과와 자동 시험의 가상 배경 화면은 [26번 검증 기록](../../validation/26-region-map.md)을 따른다.
