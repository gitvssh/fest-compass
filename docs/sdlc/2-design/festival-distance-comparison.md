# 기준 행사에서 가까운 축제 비교

## 사용자 행동

1. 현재 등록 행사에서 지역 최대 3곳과 기획 기간을 조회한다.
2. 좌표가 확보된 행사를 거리 기준으로 고른다. 조회한 자료를 가까운 순으로 정렬하고 필요하면 10·30·50·100km 반경을 고른다.
3. 일정 그림과 거리 막대·수치로 주변 행사를 살펴본다. 기준 행사도 0km 항목으로 포함한다.
4. 필요한 회차를 비교에 추가해 기획 근거로 담는다. 이후 기준이나 조회 조건을 바꿔도 선택 당시 기준 행사·좌표·반경·출처와 거리를 재확인한다.

## 자료·표현 계약

- 기존 지역 조회의 한국관광공사 등록 경도·위도를 그대로 사용한다. 범위는 경도 124~132·위도 32~39이며 결측·범위 밖 값은 거리 미확인이다. 과거 회차에 현재 좌표를 소급 적용하지 않는다.
- 거리는 반지름 6,371km 구면의 Haversine 계산(`haversine-v1`)이다. 소수점 한 자리의 **대략적인 직선거리**이며 도로 이동거리·시간·교통 영향이나 행사장 경계를 의미하지 않는다. 같은 좌표도 동일 행사장 사용을 증명하지 않는다.
- 반경 판정·정렬은 반올림 전 값으로 하고 경계를 포함한다. 좌표 미확인 자료는 결과 뒤에 유지하며 반경 안이라고 판정하지 않는다. 반경 밖으로 확인된 자료 수와 미확인 수를 따로 표시한다.
- 거리 조건 변경은 이미 조회한 자료에만 적용하며 추가 API 호출·위치 권한 요청·지오코딩을 하지 않는다. 전국 반경 전수 검색이나 자동 주변 지자체 추천은 후속이다. 조회 실패 지역은 기존 실패 표시를 유지한다.
- 기준은 조회 결과의 실제 등록 항목 중에서 고른다. 이후 재조회로 목록이 바뀌어도 기준 사본은 유지하고 기준을 확인한 시각·출처를 표시한다. 해제·과거 모드 전환은 거리 조건을 지운다.
- 거리 그림은 최대 20건이고 전체 목록은 유지한다. 수치·미확인 상태를 문자로 함께 제공하며 모바일·인쇄에도 남긴다.
- 기존 v1 비교 근거에 선택적 좌표와 거리 조건을 추가한다. 이전 파일은 그대로 읽으며 새 파일의 잘못된 좌표·반경·계산 방법·출처는 거부한다. 기획 후보·보관 기획안에서도 당시 조건으로 표시한다.

## 인수 범위

좌표와 경계 계산, 0km·미확인·반경 밖 구분, 거리순·반경 변경의 추가 호출 없음, 선택 후 기준 변경과 파일 보관/기획 연결의 원래 값 보존, 이전 파일 호환, 과거 전환·늦은 응답·모바일 390px를 검사한다. 가상 응답 회귀 시험과 실제 공개 자료 검수를 구분한다.

실행 결과는 [30번 검증 기록](../../validation/30-festival-distance.md)에 남긴다.
