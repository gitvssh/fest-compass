# 공주·임실 방문 이력과 공주 축제 비용 확대

## 사용자 흐름과 자료 범위

전국 지도에서 공주시·임실군을 선택하고 2023~2025년 중 최대 366일을 조회해 일별 외지인 방문 추세를 본다. 확보 기간을 바로 여는 버튼을 제공한다. 과거 축제 비교에서는 기존 공주 2024·임실 2023~2025 회차에 개최일 전후 15일의 실제 방문 이력을 연결한다. 다른 지역은 별도 통계 모집단이므로 기존 비교 제한을 유지하며 같은 지역 회차끼리 비교한다.

공주 2024 백제문화제 원가회계 PDF의 예산액·집행액·총원가를 서로 다른 항목으로 표시한다. 원가 세부 항목은 중복 소계 없이 도넛과 수치 표로 보여준다. 재원 구성과 지출 항목 구성을 구분한다. 자료를 담으면 기존 기획 근거·출력에서 당시 값과 원문이 유지된다.

## 방문 자료 계약

- 기존 승인된 API 자격으로 운영자 수집을 실행한다. 2023-01-01~2025-12-31, 월별 전체 페이지를 확인하고 최대 150회 요청에서 중단한다. 실패 요청도 차감하며 캐시로 재개한다. 브라우저 조회가 새 외부 수집을 실행하지 않는다.
- 공주 44150, 임실 45750/52750은 지역명·날짜·방문자 유형 3개를 함께 검사한다. 임실의 원문 코드를 보관하며 앱 조회 52/750에 대응한다. 동명 다른 코드·별칭 중복·타 지역·페이지 누락·중복 값은 오류로 남긴다.
- 날짜 결측은 null이며 숫자 0과 구분한다. 지역 방문 추정치를 축제 입장객·고유 방문객·축제 효과로 해석하지 않는다. 자료 개정 시 현재 확보본이라는 점을 명시하고 당시 공개본으로 표현하지 않는다.
- 기존 논산 학습·발행·겨울 시험 입력은 유지한다. 새 두 지역을 예측 모델에 자동 적용하지 않는다.

## 비용 자료 계약

공주시 2024회계연도 행사·축제별 원가회계정보 PDF 6쪽(인쇄 283쪽): 예산 4,637,800천원, 집행 4,614,321천원, 총원가 4,159,338천원. 천원을 원으로 1,000배 변환한다. 공주 지역 사업이며 부여 합계가 아니다. 부가세 기준과 집행액/총원가 차이의 구체적 원인은 미확인으로 남긴다.

원가 항목은 보험료·기타행사운영비·홍보및광고비·행사관련시설비·임차료 및 원문 0 항목이다. 원문의 행사직접비/시설장비비 소계를 다시 더하지 않는다. 예산·집행·원가를 더해 총비용으로 만들지 않는다. 막대는 서로 다른 정의의 기재 금액을 보여주고, 도넛 분모는 총원가다.

## 검증

지역별 조회 격리·코드 별칭·전 페이지 검증·중복/결측·실제 표본과 원문 해시, 비용 원단위 변환·중복 없는 합계, 근거 저장/파일/기획 출력과 headless 모바일을 확인한다. 자동 검증과 실제 담당자 인수는 구분한다. [32번 검증 기록](../../validation/32-regional-history-costs.md).
