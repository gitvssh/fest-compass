# 사용자 흐름

아래 화면은 [화면설계서](screens.md)의 구현 전 시안이다. 기존 운영 원장과 혼동하지 않는다.

## 지역에서 올해 기획안으로

```mermaid
flowchart LR
  N["SCR-FC-001 남한 전국지도"] --> P["같은 화면: 시도 선택"]
  P --> A["같은 화면: 시군구·관광자료"]
  A -->|상위 경로로 복귀| N
  A -->|주변·과거 조회| B["SCR-FC-002 그래프 중심 축제 비교"]
  A -->|자료 담기| C["SCR-FC-003 기획 근거"]
  B -->|사례 담기| C
  C -->|선택 근거 연결| D["SCR-FC-004 기획 후보"]
  D -->|두 후보 준비 규모| E["SCR-FC-005 예산·준비"]
  E -->|선택 이유와 미확인 사항| F["SCR-FC-006 기획안"]
  F -->|행사 종료 후| G["SCR-FC-007 결과·다음 회차"]
  G -->|개인 과거 사례| B
  G -->|새 기획에 재확인| D
  D -->|추가 조사| A
```

## 자료가 부족하거나 지역을 바꾸는 경우

```mermaid
flowchart TD
  A["SCR-FC-001 지역·기간 변경"] --> B{"자료 상태"}
  B -->|정상 또는 일부 누락| C["지도·목록·차트 같은 조건 적용"]
  B -->|미수집 또는 오류| D["자료 없음·재시도·목록 탐색"]
  C --> E["출처·단위 확인"]
  D --> E
  E -->|가용 자료만 선택| F["SCR-FC-003 근거 담기"]
  F --> G["SCR-FC-004 담당 지역과 관련성 확인"]
  G -->|다른 지역 참고 사례| H["기획안의 지역은 유지"]
```

## 보관 당시 자료와 수정안

```mermaid
stateDiagram-v2
  [*] --> Draft: 후보·근거 입력
  Draft --> Ready: 두 후보와 비교 근거 확인
  Ready --> Snapshot: 선택 이유를 남겨 기획안 보관
  Snapshot --> Draft: 새 버전으로 수정
  Snapshot --> Outcome: 동일 정의의 실측 기록
  Outcome --> Next: 다음 회차 초안 복사
  Next --> Draft: 일정·근거·견적 재확인
```

SCR-FC-006의 보관본은 기존 값을 덮지 않는다. SCR-FC-007에서 기준 보관본을 명시한다.
입력 중 자료가 갱신돼도 보관본은 유지하며, 새 버전을 만들 때만 새 자료 선택을 허용한다.
위 '보관'은 개인 결정 기록이며 조직의 공식 승인 상태가 아니다.

## v2: 예산·준비 확인과 결과 출력

```mermaid
flowchart TD
  A["SCR-FC-004 사업 정보·장소·두 후보"] --> B["SCR-FC-005 재원과 지출을 별도 입력"]
  B --> C{"비교 기준이 같은가"}
  C -->|예| D["기준 버전 대비 증감 이유"]
  C -->|다름·미확인| E["금액은 보존·차액 계산 보류"]
  D --> F["담당·기한·선행 과제·확인 필요"]
  E --> F
  F --> G["SCR-FC-006 같은 기획 버전으로 사업설명·준비 목록 출력"]
  G --> H["외부 기관의 예산·계약·집행·검토"]
  H --> I["SCR-FC-007 재원별 실제 사용·증빙 확인·개선"]
  I --> J["기획과 결과 버전을 고정해 결과 자료 출력"]
  I --> K["다음 회차 초안: 실적·날짜·확인 완료 초기화"]
  K --> A
```

외부 기관 단계는 이 앱의 실행 기능이 아니다. 없는 단계는 미확인으로 남기며 같은 금액을 다음 단계로 자동 옮기지 않는다.
장소·기간·업무 범위 변경 시 관련 준비·견적을 재확인한다. 보관한 확인 기록은 이전 적용 기간과 함께 남는다.

## v3: 같은 기준의 그래프에서 근거로

```mermaid
flowchart TD
  A["SCR-FC-002 회차와 지표 선택"] --> B["연도별 자료 확보 현황"]
  B --> C{"같은 정의·비교 범위인가"}
  C -->|예| D["선·막대·일정 그래프"]
  C -->|미확인·불일치| E["원문 카드·비교 보류 사유"]
  D --> F["값·날짜 구간 선택 또는 수치 표"]
  E --> F
  F --> G["출처·집계·단위·당시 값 확인"]
  G --> H["SCR-FC-003 선택 구간을 근거로 보관"]
  H --> I["SCR-FC-004 시기·장소·아이템 판단에 연결"]
```

비용 구성비는 전체 분모와 항목을 확인한 경우만 표시한다. 차트 선택은 표의 항목·날짜 입력으로도 가능하며 담기 전까지 개인 기록을 만들지 않는다.
