# 사용자 흐름

아래 화면은 [화면설계서](screens.md)의 구현 전 시안이다. 기존 운영 원장과 혼동하지 않는다.

## 지역에서 올해 기획안으로

```mermaid
flowchart LR
  A["SCR-FC-001 우리 지역 지도"] -->|주변·과거 조회| B["SCR-FC-002 축제 비교"]
  A -->|자료 담기| C["SCR-FC-003 기획 근거"]
  B -->|사례 담기| C
  C -->|선택 근거 연결| D["SCR-FC-004 기획 후보"]
  D -->|두 후보 준비 규모| E["SCR-FC-005 예산·준비"]
  E -->|선택 이유와 미확인 사항| F["SCR-FC-006 기획안"]
  F -->|행사 종료 후| G["SCR-FC-007 결과·다음 회차"]
  G -->|개인 과거 사례| B
  G -->|새 기획에 재확인| D
  D -->|추가 조사| A
```

## 자료가 부족하거나 지역을 바꾸는 경우

```mermaid
flowchart TD
  A["SCR-FC-001 지역·기간 변경"] --> B{"자료 상태"}
  B -->|정상 또는 일부 누락| C["지도·목록·차트 같은 조건 적용"]
  B -->|미수집 또는 오류| D["자료 없음·재시도·목록 탐색"]
  C --> E["출처·단위 확인"]
  D --> E
  E -->|가용 자료만 선택| F["SCR-FC-003 근거 담기"]
  F --> G["SCR-FC-004 담당 지역과 관련성 확인"]
  G -->|다른 지역 참고 사례| H["기획안의 지역은 유지"]
```

## 확정 당시 자료와 수정안

```mermaid
stateDiagram-v2
  [*] --> Draft: 후보·근거 입력
  Draft --> Ready: 두 후보와 비교 근거 확인
  Ready --> Snapshot: 선택 이유를 남겨 기획안 보관
  Snapshot --> Draft: 새 버전으로 수정
  Snapshot --> Outcome: 동일 정의의 실측 기록
  Outcome --> Next: 다음 회차 초안 복사
  Next --> Draft: 일정·근거·견적 재확인
```

SCR-FC-006의 보관본은 기존 값을 덮지 않는다. SCR-FC-007에서 기준 보관본을 명시한다.
입력 중 자료가 갱신돼도 보관본은 유지하며, 새 버전을 만들 때만 새 자료 선택을 허용한다.
위 '보관'은 개인 결정 기록이며 조직의 공식 승인 상태가 아니다.
