# 전국 탐색과 근거 중심 시각화

## 사용자 결정과 구현 상태

2026-09-08 사용자는 첫 화면을 전국지도로 시작하고 지역을 좁혀 가며, 비교에는 그래프·파이차트 등 시각자료를 적극 사용하도록 요청했다.
이번 문서는 그 요청을 반영한 개발 전 설계다. 지자체 담당자의 자기 지역 정보 수요는 유지하되, 첫 화면을 특정 지자체로 고정하지 않는다.
실제 자료의 확인 범위는 [과거 자료 점검](../../research/2026-09-historical-comparison-review.md), 객체·계산 정본은 [자료 계약](../1-analysis/data-contract.md)을 따른다.

## 전국 → 시도 → 시군구

1. 기본 진입은 제주와 도서 지역을 포함한 전국지도다. 위치 권한·담당 지역·사업 정보 입력을 요구하지 않는다.
2. 시도 클릭 또는 동일한 지역 목록 선택으로 좁히고, 시군구를 선택하면 그 지역의 자원·등록 축제·방문 추세를 표시한다.
3. 상단 경로 `전국 > 충청남도 > 논산시`에서 상위 지역으로 돌아갈 수 있다. 지역 변경에도 연도·기간·자료 종류는 유지한다.
4. '우리 지역 바로가기'와 '이전 탐색 이어보기'는 사용자가 누를 때만 이동한다. 일반 재방문도 전국이 기본이며 명시적 회차 링크는 해당 상세로 진입한다.
5. 전국·시도에서는 지역 요약과 자료 보유 상태, 확대 후에는 확인된 좌표의 자원·행사 마커를 제시한다. 배경 지도 범위와 통계 확보 범위는 별개다.
6. 지도 이동은 표시 범위만 변경한다. '이 영역 조회'를 누른 경우에만 공간 필터를 적용하고 해제할 수 있게 한다. 계층 지역 선택은 즉시 공통 필터에 반영한다.

지도 경계는 제공처·기준 연도·좌표계·지역 코드 대응을 확인한 범위에서 사용한다. 시안의 해안선은 개념도이며 실제 경계 자료가 아니다.
`미확보`, `부분 확보`, `조회 오류`, `확인된 0`은 글자·무늬로 구분한다. 자료 없음에 수치 0을 넣거나 논산 값을 다른 지역에 재사용하지 않는다.
시군구 통계를 합쳐 전국 또는 시도 고유 방문객을 만들지 않는다. 상위 지역은 그 집계 수준의 원자료를 따로 확인한 경우에만 표시한다.
첫 페이지만 조회한 축제 건수는 전국 총수가 아니다. 전 페이지 조회·중복 정리·조회 기간과 완료 여부를 표시한 뒤에도 '조회된 등록 축제'로 명명한다.

## 비교 화면의 읽는 순서

SCR-FC-002는 필터·회차 선택 → 자료 확보 현황 → 주요 그래프 → 선택 수치·출처 → 근거 담기 순서다.
2~3개 회차를 선택한다. 예산이 없더라도 회차를 제외하지 않고 방문 추세 등 비교 가능한 지표를 남긴다.
숫자를 못 그리는 이유는 해당 차트 자리에서 설명한다. 비교 보류 자료는 원문 카드로 읽을 수 있다.

| 질문 | 기본 시각자료 | 표시·비교 기준 |
|---|---|---|
| 개최 전후 방문 흐름이 어땠나? | 일별 선그래프 | 같은 지역·방문 유형·단위·방법. 실제 날짜 또는 행사 시작일 D0 기준. 행사 구간과 개최 일수 표시 |
| 어떤 기간의 자료가 있는가? | 회차×지표 현황표 | 자료 확보·부분 확보·원문만 확인·미확보. 보유 기간·누락·확인일과 연결 |
| 주변 행사가 언제 겹치나? | 실제 날짜 타임라인 | 일정 상태·변경·취소·날짜 미확인 구분. 상대 날짜 축으로 일정 겹침을 판정하지 않음 |
| 같은 기준의 비용은 얼마나 다른가? | 수평 막대그래프 | 금액 단계·전체/부분 범위·단위·VAT·부서·재원이 비교 가능한 경우. 연도 차이는 명시하고 명목 금액으로 표시 |
| 한 축제의 돈은 어떻게 구성됐나? | 파이 또는 도넛차트 | 재원 구성과 지출 구성을 별도 표시. 전체가 확인되고 중복 없는 비음수 항목의 합=분모>0인 경우 |
| 여러 축제의 구성비가 어떻게 다른가? | 100% 누적 막대 + 실제 총액 | 같은 항목 분류와 완전한 분모. 작은 비중 차이는 수치 표로 확인 |
| 계획과 결과가 얼마나 달랐나? | 계획·결과 나란한 막대 | 같은 대상·단위·측정 방법·범위. 계획 0일 때 증감률 없음. 실측 미확인은 막대 없음 |

월별 조회는 공급자가 제공한 월 통계를 우선한다. 일별 값을 합치거나 평균내는 경우 집계 방식과 누락 처리·분모 일수를 드러내고 월 고유 방문객으로 명명하지 않는다.
차트 종류·기간 기본값은 검수 가능한 제안이다. 방문 추세 선의 상승을 축제 효과·순방문객 증가·흥행 성공으로 단정하지 않는다.
파이는 전체의 구성, 막대는 항목 간 비교에 적합하다는 [영국 통계청 설명](https://digitalblog.ons.gov.uk/2017/01/26/the-humble-pie-chart/)을 참고했다.

## 차트 공통 계약

- 선그래프는 실제 값으로 좌표를 계산한다. 결측 사이를 이어 그리거나 보간하지 않는다. 비교하는 선들은 공통 축·단위를 쓰고 서로 다른 방문 유형을 한 합계로 만들지 않는다.
- 막대는 0부터 시작한다. 이중 축·3D·면적 왜곡은 사용하지 않는다. 각 회차는 색 외에 선 모양·기호·직접 라벨로 식별한다.
- 파이·도넛은 최대 5개 주요 항목과 '기타'를 제안한다. 기타의 세부 항목을 펼칠 수 있어야 하며 단위·금액·분모·비율을 함께 제공한다.
- 미산정·겹친 범위·알 수 없는 분모가 있으면 전체 구성비를 그리지 않는다. 부분 소계는 금액 막대와 '총액 미확정'으로 표시한다. 총액 0이면 빈 상태와 0원 표를 제공한다.
- 확정/예정 재원은 다른 상태다. 계획 재원 구성을 그려도 확보액은 별도 표시한다. 재원과 지출을 한 파이에 합치지 않는다.
- 현지인·외지인·외국인은 제공·집계 방법을 확인하지 않은 채 파이의 한 전체로 묶지 않는다. 지역별 방문 추정치를 전국 방문객 점유율 파이로 만들지 않는다.
- 모든 차트에서 지표명·단위·지역·실제 기간·원자료 확인일·자료 성격을 보인다. '수치 표 보기'와 '출처·비교 기준 보기'는 항상 접근할 수 있다.
- 선택한 점·막대·기간을 '기획 근거에 담기'로 저장한다. 마우스 드래그와 같은 일을 키보드로 날짜/항목 선택해 수행할 수 있어야 한다.
- 저장 대상은 그림만이 아니라 선택 당시 값·누락 상태·필터·회차·원문 참조·집계 방식·선택 범위다. 새 조회 결과는 기존 근거를 덮지 않는다.
- 390px에서는 그래프를 한 열로 배치한다. 축 라벨을 줄여도 원래 날짜·값·단위는 표에서 확인한다. hover 전용 설명을 만들지 않는다.
- 출력에는 선택된 그래프와 대응 표·출처·기간·미확인 상태를 함께 담는다. 흑백에서도 구분 가능해야 한다.
