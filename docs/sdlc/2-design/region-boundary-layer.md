# 기준일이 있는 행정경계 지도

## 구현 범위

공식 한국행정구역분류 2025-04-01·2026-07-10 연계표를 확보했다.
현재 관광조회 269개 단위 모두를 법정동 코드·시도명·시군구명으로 공식 항목과 대조할 수 있다.
2025 경계 코드와 같은 항목은 직접 222개, 일반시 합성 12개이며, 개편된 35개 단위는 연결하지 않는다.
세종 `(36110,36110)`은 공식 법정동 코드 `3611000000`과 명칭을 함께 검증하는 명시적 예외다.

이는 **해당 조회 지역에 연결한 2025-06-30 기준 참고 경계**다. 최신 법정 경계·토지 소유·장소 사용 가능 여부의 인증이 아니다.
과거/현재 코드 일치로 토지 경계가 불변이라고 단정하지 않는다. 경계는 시각적 위치 확인과 지역 선택에 사용하고 관광자료 포함 판정·통계 배분에는 사용하지 않는다.

## 화면과 자료 계약

- 전국은 시도 경계와 기존 시도 표식에서 선택한다. 전남광주 통합 지역은 옛 두 시도를 임의 합성하지 않고 표식·목록을 제공한다.
- 시도 선택 뒤 시군구 경계에서 자료를 조회한다. 일반시와 하위 행정구를 겹쳐 채우지 않으며, 일반시 합성 경계는 해당 일반시 선택 시만 강조한다.
- 지도 범례와 켜기/끄기 도구에 `2025년 참고 경계`를 표시하고 정확한 기준일·출처·현재 구역과 다를 수 있음을 안내한다.
- 개편 지역은 경계 확인 중으로 표시한다. 경계 자료 로딩·실패·간단 지도 전환에서도 지역 목록과 자원 조회를 유지한다.
- 전국 파일과 선택 시도의 파일을 분리해 필요할 때만 읽는다. 바뀐 지역의 늦은 응답이 현재 경계·근거를 덮어쓰지 않는다.
- 선택한 시군구 경계가 실제 표시된 상태에서 관광자원을 담으면 경계 제공자·기준일·자료 버전·코드를 근거에 보관한다. 과거 근거는 바꾸지 않는다.
- 기존 사각 영역 필터는 조회된 자료 좌표를 좁히는 기능으로 유지하고 경계 내 통계로 바꾸지 않는다.

## 검증 기준

원본 해시·좌표계·코드 연계·개편 거부, 도형 유효성·공유 경계·섬/구멍 보존·면적 오차와 결과 파일 크기를 기록한다.
전국→시도→시군구, 일반시, 개편 지역, 경계 숨김·로딩 실패, 응답 순서, 근거 보존과 이전 파일 호환을 검사한다.
브라우저는 headless로 실행하고 OSM 타일은 시험 응답으로 대체한다. 전체 기존 흐름도 회귀 검증한다.
