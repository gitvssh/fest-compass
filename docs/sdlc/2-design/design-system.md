# 공통 표현과 스타일 근거

현재 코드 apps/web/app/globals.css의 값만 아래에 옮겼다.
와이어프레임은 배치 검수용 회색조이며 아래 값이 최종 신규 화면 디자인으로 승인된 것은 아니다.

| 토큰 | 값 | 근거 |
|---|---|---|
| background | #f6f7f4 | html, body background |
| text | #10233d | html, body color |
| print-background | #ffffff | @media print html, body |

| 공통 요소 | 사용자에게 필요한 규칙 |
|---|---|
| 데이터 배지 | 관측·가정·계산·실측을 글자로 구분 |
| 결측 표시 | 미수집·조회 오류·미산정·명시적 0을 서로 구분 |
| 선택 상세 | 지역·기간·단위·출처·확인일을 함께 제공 |
| 저장 상태 | 브라우저 저장 성공·실패·충돌을 표시하고 복구 행동 제공 |
| 지도 선택 | 마커와 목록의 선택 상태 일치, 키보드 대체 경로 |
| 비용 | 원금액·수량 단위·세금 기준·출처와 미산정 표시 |
| 초점·상태 | 색만으로 선택/오류를 표현하지 않음 |

타이포·간격·지도 색상 팔레트는 고충실도 디자인 단계에서 현재 Tailwind 설정과 접근성 검증을 바탕으로 확정한다.
