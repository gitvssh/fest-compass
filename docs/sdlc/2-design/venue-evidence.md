# 관광자료를 후보 장소 입력으로 연결

지도에서 선택해 담은 관광지·문화시설 자료의 이름과 주소를 후보 장소에 옮긴다. 원문 좌표·조회 조건·수집 시각은 기존 근거 사본에 남긴다. 담당자가 선택한 기획 후보와 담당 지역은 구분한다.

## 화면과 처리 순서

1. 관광지도에서 자료 한 건 선택 → 근거에 담기 → 해당 근거로 후보 기획.
2. 후보 작성의 근거 선택 아래에 **관광자료로 장소 입력**을 표시한다. 관광지(12)·문화시설(14)의 자원 선택 근거만 대상이다. 행사 등록·방문 추세·비교 자료는 일반 근거 연결을 사용한다.
3. 현재 장소, 가져올 이름·주소, 주소/좌표 미확인, 조회 지역, 수집 시각, 원문 링크를 확인한다. 판단 이유는 별도로 입력한다.
4. `이 자료로 장소 입력` 또는 `현재 장소를 이 자료로 바꾸기`를 명시적으로 누르면 장소 입력과 장소 근거 사본 연결을 한 번에 처리한다. 선택만으로 기존 입력을 바꾸지 않는다. 주소 없는 자료는 이름만 옮기고 주소 미확인을 표시한다.
5. 초안 저장 후 후보 비교·기획 출력·보관본에서 장소와 당시 근거를 확인한다. 보관함 삭제·새 조회로 원본 사본이 갱신되지 않는다.

```text
관광자료로 장소 입력
현재 장소: [기존 담당자 입력 또는 미입력]
가져올 장소: [공공자료 이름] · [주소 또는 주소 미확인]
조회 지역 / 수집 시각 / 좌표 / 원문
관광정보 등록은 대관·안전·수용 인원 확인이 아닙니다.
[현재 장소를 이 자료로 바꾸기]
```

## 저장과 확인 경계

기존 기획 파일 형식을 유지한다. 장소는 편집 가능한 담당자 입력이며 연결 자료는 참고 근거다. 둘을 현재 시설의 인증된 식별자로 취급하지 않는다. 장소 문구가 바뀌면 기존 장소·준비·예산의 조건 비교에 따라 재확인이 필요해진다. 과거 확인 기록을 삭제하거나 새 장소 승인으로 복제하지 않는다. 같은 장소 문구이면 입력 버튼을 비활성화하고 일반 근거 연결을 안내한다.

기존 동일 근거의 장소 연결이 있으면 그 판단 이유를 보존하며 중복 링크를 만들지 않는다. 동일 식별자에 다른 원문이 있으면 전체 동작을 거부한다. 누락된 선택 자원·잘못된 형식·너무 긴 장소명도 부분 적용하지 않는다. 주소를 좌표에서 추정하지 않는다.

## 인수 기준

UC-FC-004 AC7: 관광자원 근거의 장소 입력 미리보기와 명시적 적용, 출처 사본과 판단 분리, 담당 지역·보관본 보존, 변경 후 확인 재검토. TS-FC-004에 실패·복구 과제를 추가한다. 검증 결과는 [31번 기록](../../validation/31-venue-evidence.md)에 남긴다.
