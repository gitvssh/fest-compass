## 인수 기준과 확인할 증거

| 기준 | 검증 |
|---|---|
| AC1 | 두 후보·선택 이유·공공 근거·비용·준비 기록을 한 기획안으로 보관 |
| AC2 | P2의 자료·비용 수정 후 P1 JSON과 출력 값 보존 |
| AC3 | 미산정·출처·버전·시각 표시와 공식 승인으로 오해하지 않는 문구 |
| AC4 | 같은 P1의 사업설명 자료/준비 목록, 접힌 상세·출처의 PDF 포함 |
| AC5 | P1의 미확인·미산정 보존, P2 확인 기록 분리 |
| AC6 | 실제 논산 D0·조회 조건·선택 범위·표·출처 고정과 시각화·인쇄 검수 |

단위 검증의 100/120 값은 시험용 사본이다. 브라우저의 후보·예산·기관도 가상이며 논산 방문 자료와 구분한다.
실무자 관찰이나 전체 업무 인수, 정형 TypedSpec/Run 연결을 통과로 환산하지 않는다.

PDF는 실제 파일의 문자 추출과 페이지 렌더로 확인했다. 새 브라우저 오류·앱 쓰기 요청 0, 390px 문서 가로 넘침 0. 보관한 자료의 본문은 한 번만 출력하고 비용 행에서는 해당 근거 이름을 참조한다. 기존 모델·겨울 고정 코드 14개·DB 구조를 변경하지 않았다.

흑백 A4 검수에서 재원 도넛의 번호·금액 표, 방문 추세의 실선/점선·기호·D0 수치, 세로 페이지 분할 뒤의 표를 확인했다. 검수용 사업설명 자료는 중복 근거 제거 후 15쪽이다. 문서 추적 린트와 내부 상대 링크 누락은 0이며 API/Spec/Run/티켓 미선언은 미평가로 남겼다.

추가 headless 검수에서는 기존 실제 논산 자료의 2023/2024/2025 회차 각 15일(총 45값)과 2025 지역 이력 15일을 새 기획안으로 가져왔다. 선택 D-7~D+7, 비교 표 15행·세 회차, 지역 그래프 15점, 출처 링크 11개와 PDF를 확인했다. 원래 D0 기획안은 별도 버전으로 유지한다.

## 최초 공개 확인과 최종 게시 증거

[공개 기획안](https://kto.damecasol.com/planning/proposal)에서 사용 가능하다. 최초 소스 `00432323f58feedfb5781535526f79158d996804`의 [전용 CI](https://github.com/gitvssh/fest-compass/actions/runs/34298035619)가 성공했고, 원격 검증 이미지 `sha256:4f0df90a7ed0b7695c63bd32384f3b5d781035abf59b7420ffa28cb0db4542bd`를 선언 `1e63741279f7170b430fee07f30945c0f1f35c0a`로 정상 반영했다.

공개 브라우저에서 두 기획안을 파일로 가져오고 P1을 사업설명 자료·준비 목록 PDF로 각각 출력했다. P1에서 새 초안을 만들어 제약 메모를 수정·보관해도 P1 JSON과 출력이 그대로였다. 공개 화면의 콘솔 오류·앱 쓰기 요청 0, 390px 넘침 0, 12개 경로 HTTP 200·기획안 사이트맵을 확인했다.

후속 자료 확보 문구 수정본은 원격 이미지 검증까지 통과했지만, 첫 이미지 표식 승격 뒤 배포 선언이 아직 이전 이미지를 가리켜 후속 승격이 중단됐다. 검증된 첫 이미지를 먼저 정상 반영해 순서를 맞췄다. 이미지를 임의로 삭제하거나 용량·권한·검사 규칙을 바꾸지 않았다.

최종 문구 수정본의 실제 이미지·배포 결과, 기존 예측 값의 전후 대조, 내부 Traceboard 게시 이미지·접근성·실제 파일 일치는 `docs/validation/evidence/2026-09-09-planning-proposal-production.json`에 최종 기록한다. 이 최초 검수 결과는 이후 게시와 구분해 유지한다.
