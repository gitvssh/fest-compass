# 임실 축제 회차별 방문자 특성 비교

## 사용자 목표와 현재 상태

기존 축제 담당자가 이전 회차와 비교해 방문자의 성·연령 구성, 외지인 비율, 검색된 목적지의 변화를 살펴본다.
이 정보는 프로그램·관광 연계를 검토하는 근거이며 변화의 원인이나 성공 여부를 자동으로 확정하지 않는다.
기록 없이 기존 회차 선택에서 한 해 또는 두 해를 고른다. 사용자 승인 범위는 임실 이전 회차 확보와 두 회차 비교다.

자료 확인·구현·로컬 검증을 마쳤으며 공개 반영은 진행 중이다. 기존 2025년 단일 회차 기능은 [기록38](38-visitor-profile.md)을 따른다.

## 설계와 위임 검수

실제 Claude Opus 5.5에 설계를 위임하고 직접 검토했다. 기존 회차 선택은 최대 세 개다. 세 해의 방문 추이는 유지하고,
방문자 특성은 선택한 자료 중 최근 두 회차를 비교한다. 화면 제목에 실제 비교 연도를 표시하며 다른 조합은 기존 회차 선택으로 고른다.
세 회차를 선택하면 짧은 `최근 두 회차` 표시와 회차 선택으로 돌아가는 링크를 둔다. 세 회차의 원 방문 추이는 유지한다.
두 해 막대에는 연도와 비율을 각각 표시하고, 설명 없는 차이 숫자를 두지 않는다. 내부 수집·검사 판단은 화면과 응답에 싣지 않는다.
데이터 생성·서버 계산·화면/인수 시험·기능 문서 작업은 담당 파일을 나누어 같은 모델에 위임하며 최종 검수는 주 담당자가 맡는다.

[기능 상세 §11](../sdlc/2-design/functional-spec.md#11-두-회차-방문자-특성-비교)이 기본 레이아웃과 디자인 작업 입력이다.
기존 방문 구성에는 일평균과 외지인 비율 변화, 아래 방문자 특성에는 두 해 성·연령 막대와 목적지 순위를 둔다.
한쪽 목록에 없는 목적지의 순위·변화는 `—`다. 신규 방문·0건으로 해석하지 않는다. 최종 시각 디자인은 후속이다.

## 대조 기준

- 2024→2025년 30대 남성 6.7→7.3%, 여성 6.9→7.6%: 각각 +0.6%p, +0.7%p.
- 같은 비교의 50대 여성 13.0→11.3%: −1.7%p. 비율은 매년 내국인 방문자 전체를 분모로 한다.
- 외지인 목적지 성수산 5→3위는 2위 상승, 상이암 4→5위는 1위 하락이다. 수월제·소충사는 한쪽에만 있어 변화량을 만들지 않는다.
- 개최기간이 달라 방문 합계의 증감을 전면에 두지 않는다. 방문 구성은 하루 평균과 외지인 비율을 비교하며 이 분모에는 외국인도 포함된다.
- 자료 갱신은 새 후보 수집→검사→생성 순서다. 검사 실패 시 검증된 기존 파일을 유지한다. 주기적 자동 실행은 이번 범위가 아니다.
- 2023년 원문 16개 비율의 합계는 100.1%다. 반올림을 이유로 비율을 재정규화하지 않았고 모든 원문 값과 순위를 직접 대조했다.
