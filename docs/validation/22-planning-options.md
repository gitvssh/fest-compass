# 올해 기획 후보 검증

사용자의 다음 작업 요청에 따라 M3를 구현한다. 정본 요구는 FR-EVD-5/6, FR-PLN-1/2/3,
UC-FC-003/004와 SCR-FC-003/004다. 전용 worktree에서 수정하고 브라우저 검증은 headless로 수행한다.

## 구현 범위

`/planning/options`에서 담당 지역·사업·복수 수행 관계, 최대 6개 후보, 근거 연결,
같은 항목 비교·공통 날짜 일정 그래프·준비 과제 개수, 설치/행사/철거 확인과 준비 과제를 기록한다.
최대 20개 불변 보관본·파일 복원·다른 창 충돌 방어를 개인 브라우저 저장 경계에서 제공한다.
M4 예산 산출·M5 완성 기획안·공식 승인·공동 저장을 완료했다고 표시하지 않는다.

구현 설명: [기획 후보 검수 안내](../sdlc/2-design/planning-options-implementation.md).

| 기존 + 신규 브라우저 | `npm run test:e2e` | 기존 편집/운영/지도/비교와 신규 기획 27개 흐름 통과 |

Node 24.20.0 / npm 11.19.0. 단위 시험의 비교 근거는 기존 검토된 논산 3회차 D0 실제 값
48,296.5 / 56,252 / 52,671.5와 원문 출처를 사용한다. 후보·담당 역할·확인 메모·장소·일정은 시험 입력이다.
자동화는 외부 기관에 연락하거나 장소 사용을 확인하지 않는다.
원주 지원사업 집행 35,118,200원·재원 합계·세금 미확인과 가상 지역 자원의 좌표 결측이 기획 사본에서도 유지됨을 확인했다.
브라우저 오류와 앱 쓰기 요청은 0건이고, 비교표 내부 스크롤을 유지하면서 390px 문서 가로 넘침은 0이다.
선택창에 명시적 접근성 이름을 추가했고 같은 자료가 두 후보에 보이는 검증 선택자를 한 후보로 한정한 뒤 전체 회귀를 다시 실행했다.
실제 로컬 화면 4개는 구현 검수 안내에 연결했다. 개인 자료의 서버 전송·기관 승인·전체 MVP 완료를 뜻하지 않는다.

## 확인할 주요 반례

- 담당 지역과 다른 지역의 근거를 연결해도 담당 지역과 자료의 공간 단위를 바꾸지 않음.
- 같은 근거/판단 중복, 원천이나 초안 수정 후 이전 보관본 보존, 파일 복원의 양쪽 이력 보존.
- 행사 구간만 확인한 장소가 설치·철거에도 사용 가능으로 표시되지 않음.
- 종료일 역전 거부, 기간 일부 중첩 허용, 기간 변경 시 이전 확인 보존·준비 재확인.
- 참조 추가만으로 완료·외부 확인되지 않음. 해당 없음의 사유/판단일, 자기·순환·타 후보 의존 거부.
- 후보 복사 시 선택·외부 확인·기한/진행 초기화. 선행 미완료 시 예외 이유 요구.
- 손상 파일·공간 부족·다른 창 변경에서 저장값과 미저장 입력 보존.

## 공개 확인

공개 앱·내부 Traceboard 게시 후 대상 커밋·이미지·실제 동선과 기존 예측 자료 보존을 기록한다.
진행 중인 검증이나 실무자 관찰을 통과로 표시하지 않는다.
