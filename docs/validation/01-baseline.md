| 기본 사례 | 가상 봄꽃축제 예시 | 실제 축제와 연도별 자료를 선정·연결해야 함 |
| 지역 방문자 | 광역 일별 배경선 구현 | 기초 지역 범위와 자료 지연·연도 비교 가능성 확인 |

| 집중률·연관 관광지 | 실호출 기록·수집 계층 있음 | 공급자 예측의 30일 범위, 장소 일치와 연결 가능성 확인 |
| 운영안 계산 | 공통 점유율을 자원 대안에 표시 | 셔틀·인력 변경 효과를 계산한다고 해석할 수 없음. 비용·처리량 모델 검증 필요 |
| 자체 예측 | 개발 필요 | 대상 지표·단위·기간·정답자료·시간 순서 비교실험부터 설계 |
| 현장 효용·재사용 | 미검증 | 실무 자료와 과제 수행 관찰 필요 |

## 먼저 확인할 가설

| ID | 질문 | 증거·실험 | 실패 시 조치 |
|---|---|---|---|
| H-01 | 과거와 현재 자료 비교가 실제 계획에 도움이 되는가 | 계획서의 판단 2~3건과 필요한 자료 역추적 | 비교 지표·업무 재선정 |
| H-02 | 관광데이터가 축제 단위 예측에 기여하는가 | 정의가 같은 실측 확보, 단순 기준과 시간 순서 비교 | 데이터 확보 또는 예측 대상·범위 조정 |
| H-03 | 자원 대안의 효과를 근거 있게 비교할 수 있는가 | 운영자료와 수기 계산·제품 계산 대조 | 설명 가능한 변수부터 축소 구현 |
| H-04 | 기록과 보고가 반복 업무를 줄이는가 | 기존 방식과 같은 과제의 시간·누락 비교 | 입력·보고 기능 축소 또는 재설계 |
| H-05 | 사용자가 지표·예측·가정을 구분하는가 | 실제 화면의 의미 이해와 행동 관찰 | 문구·정보구조 수정 |
