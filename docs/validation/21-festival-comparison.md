# 전국 표기와 축제 비교 검증

대상: M1 이후 사용자 후속 요청. 지도 UI의 '남한 전국'을 **전국**으로 변경하고 M2 첫 기능을 구현한다.
수정은 전용 worktree/브랜치에서 수행하며 모든 브라우저 자동 검증은 headless다.
모델 정확도 연구·겨울 시험·데이터베이스 구조는 변경하지 않는다.

## 확인한 자료

- `apps/web/data/festival-editions.json`: 논산 3·임실 3·공주 1·원주 1의 8개 독립 회차.
- 논산 방문값 45개를 기존 보관본 SHA-256 및 날짜별 `values["2"]`와 전수 대조했다. D0 2025-03-27은 52,671.5명이다.
- 원주 계획 35,000,000원, 집행 35,118,200원은 각각 보조금+자부담 합계와 일치한다. 전체 축제 예산이나 VAT 확인값으로 확대하지 않는다.
- 이번 공식 원문 링크 9개 직접 조회는 모두 HTTP 200이다. 논산 용역 PDF·공주 결산 PDF·원주 HWP·임실 2023 HTML은 기존 검토 해시와 일치했다. 나머지 동적 HTML은 바이트가 달라 기존 확인일·확인본 식별을 유지한다.
- 현재 API는 별도 조회다. 검색 결과가 없다고 과거 회차를 없애거나 취소·미개최를 추정하지 않는다.

## 구현과 검증 명령

| 검사 | 명령·범위 | 결과 |
|---|---|---|
| 자료·계산·보관 반례 | `tsx --tsconfig tsconfig.test.json --test lib/comparison/comparison.test.ts` | 8개 통과 |
| 기존 포함 단위 검사 | `npm test` | TypeScript 142개 + SQLite 1개, 합계 143개 통과 |
| 타입·제품 빌드 | `npm run typecheck`, `npm run build` | 통과. 기존 겨울 고정 코드 검사 포함 |
| 운영 의존성 검사 | `npm audit --omit=dev --omit=optional --audit-level=high` | 취약점 0 |
| 기존 + 신규 브라우저 | `npm run test:e2e` | 기존 편집·개인 작업·지역 흐름과 신규 비교 21개 흐름 통과. 브라우저 오류·앱 쓰기 0 |
| 배포 선언 검사 | `python -m unittest discover -s infra/scripts -p 'test_*.py'`, `python infra/scripts/validate_argocd_registration.py` | 40개 통과, 기존 digest의 17개 리소스 확인 |

Node 24.20.0 / npm 11.19.0, 격리된 SQLite 및 브라우저 저장 환경을 사용한다.
신규 단위 검사는 원값 대조, 기간 겹침·동명 별개 ID, 결측/0, 지표 정의 차이, 비용 범위/VAT/분모,
현재·과거 식별, 선택 당시 사본·버전, 손상 파일 보존을 검증한다.
신규 E2E의 현재 등록 행사는 명시적 가상 응답이고 과거 일정·방문·원주 비용은 제품의 실제 자료다.
외부 기관 인터뷰나 실제 현장 효과 검증을 대신하지 않는다.

첫 회귀 실행은 기존 작업 오류·파일 가져오기 선택자가 새 요소까지 함께 선택해 실패했다.
정확한 오류 문구와 지역 파일 이름으로 범위를 고쳐 전체 회귀를 재실행해 통과했다.
신규 SVG 제목을 단일 문자열로 고쳐 첫 표시의 서버/브라우저 불일치를 해소했고 최종 브라우저 오류는 0이다.
390px 비교/보관 화면의 가로 넘침 0, 인쇄 시 선택 그래프·표·원문 출처 표시와 입력 버튼 숨김을 확인했다.
실제 로컬 운영 화면 3개는 [구현 검수 안내](../sdlc/2-design/festival-comparison-implementation.md)에 연결한다.

## 제공 범위와 남은 작업

전국 과거 기록 전수 조회, 이전에 시작한 현재 장기 행사의 완전한 기간 겹침 검색,
거리순 검색, 공식 취소/변경의 지속 수집, 다른 지자체 연속 방문 이력, 공통 정의 비용 증감은 후속이다.
TS-FC-002의 전체 인수 시나리오 및 실제 공무원 관찰 완료로 표시하지 않는다.
다음 제품 단계는 M3 아이템·장소·시기 후보와 보관 근거 연결이다.
