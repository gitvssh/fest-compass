# 방문 분석 동의 배너

상태: **사용 가능 — 공개 반영, 공개 검사에서 찾은 두 문제 보완(아래 '공개 배포').** [설계26](../design/26-consent-banner.md)과
[인수 기준 TS-FC-023](../sdlc/3-testing/scenarios/TS-FC-023.md)에 따른 변경이다. 2026-10-04 사용자 요청("pickDday도 같은 방식으로 진행해줘").

## 사용자에게 달라지는 점

- 처음 오면 첫 화면을 덮고 흐리던 `쿠키 설정` 창 대신, 화면 아래 작은 카드에서 `거부`·`허용`만 고른다. 고르기 전에도 검색·소개 영상 등 모든 기능을 바로 쓴다.
- 이미 고른 사람에게는 다시 묻지 않는다. 모든 화면 아래(바닥글)와 개인정보·분석 안내의 `분석 동의 다시 보기`에서 언제든 선택을 바꾼다.
- 첫 방문 소개 영상 안내는 동의 배너가 닫힌 뒤 2초에 나타나고, 배너가 다시 열리면 비켜선다. 두 카드가 겹치지 않는다.
- 개인정보·분석 안내의 `선택 분석과 동의 경계` 문단이 작은 안내와 다시 보기 경로를 설명한다. 안내 페이지에 시행일 표기는 없으며 고지·시행일 갱신 여부는 소유자가 판단한다.

## 구현

- `apps/web/lib/analytics/consent.ts`: Zaraz 동의 API 연동. 준비(`APIReady`/`zarazConsentAPIReady`) 뒤 50ms 간격·최대 6초로 기본 창 열림(`modal === true`)을 지켜보다 창을 닫고 배너를 띄운다.
  그동안만 `<html data-consent-takeover>`로 기본 창(`.cf_modal_container`)을 숨기고(`globals.css`), 창이 열리지 않으면 숨김을 거둔다.
  선택 처리 순서: 배너 숨김·표식 제거 → 열려 있을 때만 기본 창 닫기 → `setAll(허용 여부)` → 허용이면 `sendQueuedEvents`. purpose ID·쿠키·저장소 없음(단위 시험이 소스에서 확인).
- `apps/web/components/ConsentBanner.tsx`(앱 틀에 1개), `ConsentSettingsButton.tsx`(바닥글·개인정보 안내), `ConsentPreference.tsx`(개인정보 안내의 단추로 축소).
  `IntroVideo.tsx`는 사이트가 묻는 동안(`isSiteConsentOpen`: 배너 요소 또는 숨김 표식)과 예비로 기본 창이 열린 동안(최대 120초) 기다리고, 배너가 다시 열리면 안내를 거둔다.
- 바닥글 글자색을 `#65738a`(바탕 `#f6f7f4`에서 4.46:1)에서 메뉴와 같은 `#43536a`(7.28:1)로 바꿨다. 새 바닥글 단추가 같은 색을 쓰기 때문이며, 기존 `개인정보·분석` 링크의 대비도 함께 올라간다.
- CSP·분석 전송 경계·`appDefinesCmpPurposeId: false`는 그대로다. 인라인 스크립트 없음. Cloudflare·Zaraz 콘솔 설정은 바꾸지 않았다.

## 공개 화면 사전 확인(변경 전, 읽기만)

2026-10-04 headless Chromium으로 https://pickday.damecasol.com/ 을 열어 실제 Zaraz를 관찰했다: `zarazConsentAPIReady`가 접속 약 1.0초 뒤 발생하고 같은 순간 `zaraz.consent.modal === true`,
`.cf_modal_container`(높이 0인 호스트) 안 그림자 DOM의 `dialog[open]`이 `쿠키 설정 · analytics — Anonymous page and feature usage analytics.` 창을 전면에 그린다(배경 흐림 3px).
`zaraz.consent`에는 `modal`·`setAll`·`sendQueuedEvents`·`get`·`getAll`·`set`이 있고 `APIReady`는 열거되지 않는 속성으로 `true`였다. 선택 전 쿠키 이름은 `cf_zaraz_client` 하나다.
대체 스크립트(`scripts/consent-banner-e2e.mjs`)는 이 관찰과 2026-10-01 포트폴리오 실측(닫힌 창에 `false`를 넣으면 예외)을 그대로 흉내 낸다.

## 남은 것·한계

- 기본 창은 페이지 첫 화면부터 숨는다. 화면 스크립트가 아예 실행되지 않는 브라우저에서는 기본 창도 배너도 없이 분석이 꺼진 채로 남는다(동의 없음과 같음).
- Zaraz 콘솔의 기본 창은 켜 둔다(끄면 미선택 신호가 없어 배너도 뜨지 않음).
- 화면 낭독기 실사용과 실제 사용자 관찰은 미평가다.
