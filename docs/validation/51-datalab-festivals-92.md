# 데이터랩 문화관광축제 92곳

상태: **사용 가능 — 공개 반영·공개 화면 검증 완료(아래 '공개 배포').** [설계29](../design/29-datalab-festivals-92.md)와 [인수 기준 TS-FC-026](../sdlc/3-testing/scenarios/TS-FC-026.md)에 따른 변경이다.

## 사용자에게 달라지는 점

- `축제별 방문 자료`와 `문화관광축제 방문 규모`가 26곳에서 **92곳**이 됐다(새 66곳: 강경젓갈축제·논산딸기축제·보령머드축제·진주남강유등축제 …).
- 축제마다 **지역**(예: 강경젓갈축제 `충남 논산시`)이 보이고, `논산`처럼 지역 이름으로도 찾는다.
- 방문 규모는 상위 20곳 다음 `N곳 모두 보기`, **시도별 순위**(예: 2025년 충남 6곳), 그해 자료 없는 축제는 접어서 `N곳`으로 보인다.
- 기존 축제 `방문 흐름`에서 **논산딸기축제 2024·2025 회차**의 축제가 열린 읍·면·동 방문 구성(현지인·외지인·외국인)이 보인다.
- 대구약령시한방문화축제·평창효석문화제는 개최지(대구 중구·평창군) 관광 소비·외지인 방문객 카드가 함께 보인다.

| ZIP 항목 367개 | 직접 풀어 크기·CRC-32를 확인했고 풀어 둔 CSV와 바이트까지 같다. 소유자 폴더의 `CSV/`는 콜론을 밑줄로 바꾼 사본이라 쓰지 않았다 |
| 처음 가져오기와 겹치는 26곳 | 표 104개 중 101개 같음, 3개(수원화성문화제·인천펜타포트음악축제·화성뱃놀이축제 목적지 검색순위)는 같은 순위 안 행 순서만 다름. 앱은 처음 가져오기를 그대로 쓴다 |

| 측정 없는 해 | 방문 추이가 없는 축제·연도 24개는 방문 지표가 모두 0. 부천국제만화축제 2018은 검색량·소비만 값이 있음 |
| 관광 소비액·지역 표 | 이 묶음에 없음(소비액은 공식 단추에서도 계약상 제한). 지역 카드는 처음 가져오기 26곳만 |

## 구현

- 보관 `docs/research/imported/datalab-festivals-2026-10/`(ZIP 92·CSV 367·목록·안내, [설명](../research/imported/datalab-festivals-2026-10/README.md)).
  `scripts/datalab-owner-import.mjs`가 목록을 만들고, 검증은 파일에서 목록을 다시 만들어 저장본과 같은지 본다. ZIP은 `scripts/datalab-zip.mjs`로 직접 푼다.
- 생성: `build-datalab-festival-trend.mjs`의 `festivalSources()`가 두 가져오기를 함께 검증하고 ID 표(v2, 축제마다 `import`)로 표를 찾는다.
  추이는 92곳·447행과 지역 표시(`placeOf`, 10% 규칙), 프로필은 측정 없는 해·정의를 넘는 해를 이유와 함께 빼고 순위 없는 축제는 `null`로 둔다(스키마 v2).
- 화면: `/compare/annual`은 목록(이름·지역·연도 수, 14KB)만 싣고 축제를 고르면 `GET /api/datalab/festival?festival=<ID>`로 그 축제 자료를 받는다.
  `/compare/scale`은 해마다 값만(57KB) 받는다. 방문 규모에 상위 20곳·모두 보기·시도 고르기(`province`)·접힌 자료 없음.
- 연결: `datalab-festival-links.json`에 논산딸기축제(2024·2025), `datalab-region-ids.json`에 대구약령시한방문화축제(27110)·평창효석문화제(51760).

## 검증

- `npm test` 488개 통과(47+395+46). 처음 올린 커밋은 논산딸기축제 연결 뒤 전체 단위 시험을 다시 돌리지 않아, 기존 축제 흐름 시험의
  '논산은 개최지 방문 구성 없음' 기대값이 남아 있었다. 발행 작업의 사전 검증이 이를 잡아 이미지를 만들지 않았고(실행 37224710034),
  기대값을 '2024·2025만, 2023 없음, 공주 없음'으로 고친 뒤 발행 검증 순서(audit·test·typecheck·build·인프라 시험·등록 검사)를 로컬에서 모두 통과했다. 생성 시험: ZIP·CSV·목록 변조, 목록 밖 파일, 겹침 사용 표시 변경, 가져오기 바꾸기, ID 표 버전·이름·지역 검토 값
  거부, 92곳·447행·연도별 행 수, 측정 없는 해 24개·정의를 넘는 해 2개 정확히, 지역 표시 규칙. 읽기 시험: v2 스키마·지역 검색·시도 순위·
  가벼운 순위 입력·논산 연결(2023 제외)·지역 연결 27곳.
- 모든 생성 결과 `--verify` 통과(추이·프로필·지역 프로필·지역 연간·방문자 특성).
- headless(로컬 운영 빌드, 공개 읽기 전용 서버): `annual-trend-e2e`에 첫 화면 크기·가나다 목록 92곳·지역 검색(`논산` 2곳)·고를 때만 받기·받은 뒤
  제목 초점·지역 줄·정의를 넘는 해·세종 순위 없음·새 축제의 지역 카드·받기 실패와 다시 불러오기·논산 공유 주소(원문 링크·내려받은 날)를 더했다.
  `festival-discovery-e2e`는 상위 20곳·모두 보기·접힌 자료 없음·시도 순위와 주소 복원·모르는 시도 값, `visitor-context-e2e`는 논산딸기축제
  2024·2025 개최지 방문 구성(기대값은 원문 CSV에서 직접 읽음)과 2023 미표시를 본다.
- 처음 묶음에서 `annual-trend-e2e`가 축제를 고른 직후 표를 읽어 실패했다. 불러오는 중 카드가 축제 이름을 같은 수준의 제목으로 달고 있어 자료가 온 것처럼
  보였기 때문이라, 그 이름을 제목이 아닌 글로 바꿨다(화면 낭독기에서도 제목이 겹치지 않음).
- 첫 화면 크기: `/compare/annual` 63.5KB(축제 목록 14KB만, 목적지 순위 없음), `/compare/scale` 143KB. 축제 한 곳 자료 3.8~14KB.
- 전체 headless 32종 통과(최종 빌드, 새 시험용 DB: 편집 서버 2종·공개 서버 30종, 길잡이 그림 미리 변환). 앞선 재실행에서 같은 시험용 DB를
  다시 쓰자 편집 모드 `demo-e2e`가 실패했는데, 편집 시험이 DB의 예시 축제를 바꾸기 때문이었다(새 DB로 통과). 실행마다 DB를 새로 만든다.
- 커밋된 파일만 `git archive`로 풀어 다시 만들어도 추이·프로필·지역 프로필이 한 글자까지 같다. 저장소의 `* text=auto`가 소유자 목록 두 파일의
  Windows 줄바꿈을 바꿀 뻔해, 보관 폴더에 `original/** -text`를 두고 커밋된 461개 파일의 SHA-256이 목록과 같음을 확인했다.

## 공개 배포

- 이미지 저장소: 2026-10-04 하루 동안 쌓인 이미지로 사용량이 1.88GB/2GiB라 새 이미지(약 280MB)가 들어갈 자리가 없었다. 이미지 삭제는 하지 않고
  정해진 매일 정리(03:30 KST, 현재·직전 배포만 남김)를 기다렸다. 정리 뒤 0.62GB, 발행 뒤 0.84GB.
- 발행: `release.yml` 첫 실행 37224710034는 사전 검증에서 위의 낡은 기대값 시험 1개로 멈췄다(이미지 없음). 고친 커밋 `40e285a`로 다시 실행한
  37224952497이 `sha256:beed519c27ab062387ff2340d6c946a0cea96549f28214719eb95547f0283e89`를 발행하고 보존 표식을 옮겼다.
- 배포 선언 `0073ec5`(운영 overlay 두 곳, 등록 검사 17개 자원·인프라 시험 41건 통과) → Synced·Healthy·Succeeded, 세대 50.
- 보존: 배포 전후 Deployment·PVC 식별자와 업무 9테이블 20행 해시가 같다([전](evidence/2026-10-05-datalab-92-before.json)·[후](evidence/2026-10-05-datalab-92-after.json)).
  `/health/livez`·`/health/readyz` 200, `GET /api/datalab/festival?festival=nonsan-strawberry` 200.
- 공개 화면 headless 9항목 통과, 브라우저 오류 0([기록](evidence/2026-10-05-datalab-92-live.json)): 92곳 목록, `논산` 지역 검색 2곳, 고를 때만 받기,
  논산딸기축제 공유 주소 값과 원문 CSV 링크(GitHub 200), 방문 규모 상위 20곳·62곳 모두 보기·충남 6곳, 기존 축제 논산 2024·2025 개최지 방문 구성,
  390px 넘침 없음. `festival-discovery-live` 7항목도 통과. 점검 스크립트가 화면이 준비되기 전(약 1.7초)에 입력해 처음 두 번은 검색이 반영되지 않았고,
  준비를 기다린 뒤 통과했다(제품 동작 문제 아님).
