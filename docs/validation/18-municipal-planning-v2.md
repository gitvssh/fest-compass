# 지자체 축제 기획 문서·화면 v2 검증

2026-09-08 KST. 사용자 후속 승인에 따라 [공개 사례 보완안](../research/2026-09-municipal-requirement-proposals.md)을
기획·업무 흐름·자료 정의·SRS·UC/TS와 화면 설계에 반영했다.
지역 지도 → 주변/과거 비교 → 근거 → 두 후보 → 예산/준비 → 기획안 → 결과/다음 회차 순서를 유지한다.

## 대상과 범위

| 항목 | 대상 |
|---|---|
| 개정 전 문서 | 3f92397 |
| v2 문서·화면 원천 | 74c3faf363b4cf59ede3d991da340466202ee26d |
| FEST 변경 | 문서 29개와 7개 v2 Excalidraw/SVG 쌍, 총 43개 파일 |
| 기존 시안 보존 | v1 소스·SVG 14개 바이트 동일. v2에서 기존 요소 ID 전부 유지 |
| 제품 경계 | apps·infra·.github·모델·기존 수집 코드 변경 없음. 공개 서버 읽기 전용·개인 브라우저 저장 유지 |
| traceboard | 기존 내부 FEST 검수 사이트 갱신. 공개 목록·권한·경로 등록 변경 없음 |

이 문서와 프로젝트 상태 기록은 게시 결과를 남기는 후속 기록이며 위 43개 원천 변경 수에 포함하지 않는다.
문서 버전 v2는 실제 저장 파일 스키마 버전이나 기능 사용 가능 상태가 아니다.

## 보완 내용과 인수 기준

기존 FR 23·NFR 6·UC 8·TS 8·화면 7개 ID를 유지했다. 기존 AC 번호를 재사용하지 않고 18개를 추가해 총 44개다.
기존 TS의 과제→인수 기준 대응도 실제 판정 내용과 맞췄다.

| 보완 방향 | 반영한 내용 | 대표 인수 기준 |
|---|---|---|
| 1. 사업 정보 | 회계연도·부서·목적·신규/계속·복수 수행 관계 | UC-FC-004 AC4 |
| 2. 장소·일정 | 관광시설 등록과 사용 확인 분리, 설치/행사/철거·시설 조건, 기간 변경 재확인 | UC-FC-001 AC5, UC-FC-004 AC5 |
| 3. 비용 비교 | 전체/부분 업무·문서 단계·연도·부서·재원·단위·VAT·원문 확인 수준 | UC-FC-002 AC5~6, UC-FC-003 AC4 |
| 4. 재원·지출 | 확정/예정 분리, 기간 포함 산출, 단계별 금액 보존, 연도별 분류 재확인 | UC-FC-005 AC4~5·7 |
| 5. 증감 설명 | 이전 기준 버전과 수량/단가/기간/범위 변경 사유·관련 부서 포함 범위 | UC-FC-005 AC6 |
| 6. 준비 과제 | 담당·기한·선행 과제·적용 여부·자료 참조·외부 확인 분리 | UC-FC-004 AC6 |
| 7. 결과·개선 | 재원별 실제 사용·잔액/반납/이자·증빙 확인, 문제→조치→차기 예산/준비 | UC-FC-007 AC4~6 |
| 8. 업무용 출력 | 같은 기획 버전의 사업설명/준비 목록, 기획+결과 버전의 결과 출력 | UC-FC-006 AC4~5, UC-FC-007 AC7 |
| 공통 복원 | 신규 참조·금액 단계·상태·과제 순환·미지원 버전 검사 | UC-FC-008 AC4 |

기관 양식에 옮겨 쓸 검토 자료를 설계했다. 전자결재·입찰·지급·정산 승인·증빙 원본 저장소는 추가하지 않았다.
사업·예산 입력은 지도 탐색의 선행 조건이 아니다. 실제 단가·법정 기한·계정 코드를 근거 없이 자동 제안하지 않는다.

## 로컬 검증

| 검사 | 결과·한계 |
|---|---|
| 문서 구조 | `.dev-standard/check_compliance.py --json`: 위반 0. 원천 커밋의 사전 검사도 통과 |
| 요구 추적 | `trace_build.py` → `trace_lint.py`: FR 23/NFR 6/UC 8/AC 44/TS 8, 누락 0. R3·R4·R5·R6 미평가 4 |
| AC 정합성 | YAML 기준과 본문 기준 문장 44개 일치, 기존 26개 ID와 순서 유지 |
| 편집 소스 | `validate.mjs`: 7개 파일의 필수 필드·참조 검사 통과 |
| SVG 재생성 | `render.mjs`를 최종 소스에서 두 번 실행, SVG SHA-256 7/7 동일 |
| 흐름도 | `validate-mermaid.mjs`: 화면 흐름 4, 연결 구조 1, 업무 흐름 1, 마일스톤 1, 총 7블록 파싱 |
| 문서 사이트 | `trace_site.py --no-remote`: 문서 33·그림 7, 상대 링크 누락 0 |
| 시각 확인 | 7개 SVG를 브라우저에서 열어 배치 확인. 지도와 예산의 390px 모바일 시안 포함. 연도·기준 버전·최소 초과액 문구 보완 |
| 브라우저 확인 | 화면 문서 v2 그림 7/7 로딩, 화면 흐름 4/4 렌더. 검수 안내 390px에서 문서 폭 375px, 페이지 가로 넘침 없음 |

브라우저 확인은 문서·시안 표시 검사다. 아직 구현하지 않은 제품 화면의 키보드·저장·계산·반응형 시험 통과로 환산하지 않는다.
앱 코드 변경이 없어 기존 앱 테스트·빌드는 재실행하지 않았다. 신규 TS 8개와 관련 비기능 제품 검증은 미실행이다.
