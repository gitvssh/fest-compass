# 실제 축제 후보와 첫 데이터 조사

조사일: 2026-09-07. [구조화된 조회 증거](evidence/2026-09-07-kto-profile.json).
운영에 연결된 기존 공용 키로 28회 읽기 전용 요청을 실행했다. 비어 있지 않은 정상 표본 16건,
인가된 빈 응답 12건, 오류 0건이며 CLI 종료코드 0이다. 키·응답 원문은 보고서에 없다.
이 결과는 데이터 표본 조사이며 최종 축제 선정·자체 예측 성능·실무 검증은 완료되지 않았다.

## 후보 비교

KTO 검색 첫 결과의 공통정보·축제 상세가 동일 contentId로 결합되고 일정·법정동 코드가 확인됐다.
행사 일정은 이 조회 시점 값이며 이후 변경 가능하다.

|---|---|---|---|---|
| 임실N치즈축제 | 2031318 | 2026-10-08~10-11 | 52/52750 | 기존 기획 사례와 연결 가능. 과거 운영 자료 확인 필요 |
| 백제문화제 | 952988 | 2026-10-03~10-11 | 44/44760 | 이번 응답의 부여 지역 기준. 여러 개최지·운영주체 구분 필요 |
| 논산딸기축제 | 525292 | 2026-03-26~03-29 | 44/44230 | 종료된 회차로 과거 재현 가능성 조사. 공식 사후 자료·측정 정의 필요 |

집중률 표본의 날짜는 세 지역 모두 2026-09-07~10-06이다. 따라서 이번 조회만으로
임실의 행사기간 전망을 제공할 수 없고, 백제문화제의 전체 기간도 덮지 않는다.
이미 끝난 논산딸기축제의 과거 혼잡 실측으로도 사용할 수 없다.
공식 서비스 정의의 향후 30일 상대 예측과 일치하며, 자체 예측·지역 방문자·실측과 분리해야 한다.

## 다음 작업

1. 후보의 최근 2~3회차 공식 일정·결과보고서·방문객 측정방식·운영자료 공개 여부를 비교한다.
2. 핵심 후보의 시군구 방문자와 다년 기간 데이터, 관광지 ID·좌표 연결을 확인한다.
3. 수요 API의 다른 월과 공식 가이드의 제공 범위를 대조해 empty 원인을 좁힌다.
4. 자료가 가장 잘 확보되는 후보 한 곳을 선정하고, 예측 대상·시점·정답 지표를 정한다.

## 환경 검증과 자격 연결

Windows 기존 키의 첫 요청은 403/code 30으로 거부됐다. 저장소 선언이 참조하는 기존 앱 runtime
Secret에서 TOUR_API_KEY만 읽어 WSL 로컬 설정을 비출력 경로로 동기화한 뒤 정상 응답을 확인했다.
이는 기존 자격 연결이며 외부 제공자 신규 발급·회전·폐기나 클러스터 변경이 아니다.

앱의 자동 테스트, 타입 검사, 빌드, 별도 DB 기반 브라우저 검증을 WSL에서 수행했다.
명령·최종 결과는 [WSL 이전 검증](04-wsl-validation.md)에 기록한다.
