# 달력 효과 후보 개발과 겨울 사전 시험

작성일: 2026-09-07. [앞선 계획](12-calendar-model-plan.md)의 후속 구현이다.
예측 대상은 논산시 일별 외지인 추정치다. 행사장 입장객이나 고유 방문자 수가 아니다.

## 결과를 계산하기 전에 고정한 개발 규칙

- 자료: 보존된 2023~2026 관측의 최신 수집본을 합친 개발 자료. 2023년은 초기 학습,
  2024년·2025년·2026년 확보 구간은 연도별 시간순 확장 학습 비교다.
  매주 목~일을 한 창으로 하고 D-28/D-7을 각각 비교한다. 불완전한 마지막 창은 제외한다.
- 네 후보: 기존 v1, 공휴일 추가, 축제 추가, 두 효과 추가. 규제 강도 100·입력 지연 가정 35일을 유지한다.
  기존 v1의 계산과 보관 예측을 바꾸지 않는다. 계수는 실제 관측으로 학습한다.
- 공휴일 입력: 일요일을 제외한 전국 공휴일 여부, 설/추석 연휴 여부, 전날/다음날 공휴일 여부.
  일요일 효과는 기존 요일 입력이 담당한다. 공휴일이 일요일과 겹치면 공휴일 입력도 1이다.
  지방 공휴일과 2025년까지의 근로자의 날을 전국 관공서 공휴일로 간주하지 않는다.
- 축제 입력: 논산딸기축제 여부, 행사일 순서/행사 기간, 축제와 주말의 상호작용.
  해당 연도의 일정 발표 근거가 아직 없으면 unknown이며 축제 입력 후보의 해당 예측을 보류한다.
  확인한 연도·발표된 일정의 바깥 날짜에만 축제 입력 0을 쓴다. 2027년 엑스포는 다른 행사로 남긴다.
- 날짜만 표시된 공식 게시물은 다음 날 00시 한국시각부터 알려진 것으로 계산한다.
  추가·임시 공휴일은 연초로 소급하지 않는다. 과거 학습 행의 달력도 그 행의 가상 발행일을 기준으로 만든다.
  이는 현재 직접 확보한 게시물의 날짜로 재구성한 개발 실험이며 당시 원본 수집본을 확보한 엄격한 재현은 아니다.
- 예측 시점 이전 관측만 사용하며 학습 정답은 입력 마감일 이전으로 제한한다.
  자료 수집 당시의 개정값을 사용하는 한계와 달력 미확보 때문에 빠진 학습·평가일을 공개한다.
- 같은 날짜에서 B1·B2·네 후보의 공통 MAE/WAPE/편향, 후보별 제공일 수, 연도별 결과,
  공휴일 포함 창·축제일·나머지 날짜, 주별 오차를 기록한다. 두 선행기간을 독립 표본으로 합치지 않는다.
- 축제 계수는 표준화 전의 입력 1단위당 추정 인원으로 표시한다. 학습에서 2023/2024/2025/2026년
  축제 정답 행을 하나씩 제외한 민감도를 기록한다. 최근 방문 입력에서 행사 효과까지 제거하는 인과 실험은 아니다.
- 겨울 사전 시험에 필요한 모든 날짜의 달력 입력이 확인된 추가 입력 후보만 시험 후보가 될 수 있다.
  그 후보들과 v1·B1·B2의 동일 날짜 비교에서 선행기간별 최저 MAE 후보와 최저 MAE 기준을 선택한다.
  개선 여부와 관계없이 선택 결과를 기록하며 실제 채택은 향후 미열람 관측으로 별도 판단한다.

## 등록·결과 고정 구현

[고정 시험 목록](../../apps/web/data/calendar-trial-plan.json)에 달력 전체, 개발 보고서 해시,
선행기간별 공휴일 후보·v1 기준, 26건의 날짜, 계산·처리 코드 14개 해시를 담았다.
빌드는 등록된 코드·달력·선택 결과가 바뀌면 실패한다. 최초 실제 운영 등록은 10/8 09시 이전만 허용한다.
등록 이후 계획 파일을 바꾸면 기존 활성 계획과 충돌하며, 기존 등록·예측·결과를 덮어쓰지 않는다.

매일 수집 뒤 시험도 처리한다. 같은 날짜의 수집 완료 후 새 버전을 배포해도 API를 재호출하지 않고 시험 등록을 수행한다.
수집 실패일에는 새 예측을 발행하지 않는다. 저장 공간 제한도 적용한다. 시험만 실패하면 기존 v1 기록을 보존하고
공개 화면에 별도 오류를 표시하며, 30초 후 저장된 처리만 재시도한다.

60일/90일 후 **해당 한국 날짜의 09시 이후 첫 실행**을 결과 확인 시점으로 고정한다.
그날 실행을 놓쳤다면 `missed-check`, 정상 조회에 값이 없다면 `missing`으로 보존한다.
수집 실패일에도 그 시각까지 이미 보관한 관측은 사용할 수 있으나 새 관측을 만들어내지 않는다.
60일 결과를 90일 관측으로 보완·교체하지 않는다. 모든 기록은 원본 수집본으로 다시 계산해 검증한다.
첫 60일 결과 확인은 2027-01-04, 마지막은 2027-04-01, 마지막 90일 확인은 2027-05-01이다.
52일 전체 공통 결과가 없으면 채택 판단을 보류하는 보수적인 완결 기준을 추가했다.
