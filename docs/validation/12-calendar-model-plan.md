# 축제·공휴일 효과 모델의 다음 평가 계획

작성일: 2026-09-07. **자동 수집은 v1의 실제 사전 검증 자료를 쌓고, 다음 모델은 개발 필요 상태다.**
이번 작업은 추가 입력의 근거와 평가 규칙을 정한다. 아직 달력 효과로 오차가 개선됐다고 주장하지 않는다.

우주항공청 본문은 직접 열람했다. 논산시·재단은 검색에 색인된 공식 본문을 확인했으며 일부 URL의 직접
열람은 실패했다. 따라서 위 자료만으로 과거 발행 시점의 원본·변경 이력을 모두 확보했다고 주장하지 않는다.
일정은 바뀔 수 있으므로 실제 발행 등록 전에 최신 공식 공지와 동일성·취소 여부를 다시 확인한다.
연휴 사실과 방문 효과는 별개다. 달력만 확인됐다는 이유로 행사 유입 계수나 성능을 만들지 않는다.

## 개발 데이터와 후보

2023~2025년과 2026년 현재 확보 구간은 이미 열람했거나 재학습에 사용한 **개발 자료**다.
연도 단위 시간순 교차 검증으로 후보를 선택할 수 있지만 새 미열람 시험으로 소개하지 않는다.
2023~2026 전체 공휴일·임시/대체 공휴일, 각 축제 일정의 당시 공개 근거를 채우는 작업이 선행된다.
각 달력 자료에 출처 URL·게시일의 정밀도·직접 확인 시각·효력 기간·버전 해시를 둔다.
날짜만 공개돼 있으면 시각을 00:00으로 꾸미지 않고, 과거 사용 가능성 판정에는 보수적으로 다음 날을 쓴다.

후보는 기존 v1, v1+공휴일/연휴 전후, v1+축제 여부/행사일 순서/주말 상호작용,
두 효과를 합친 회귀의 네 종류로 제한한다. 후보별 입력 부족과 예측 실패도 보고한다.
행사장 입장객·발표 총계·사후 프로그램 성과를 과거 지역 방문 예측 입력으로 사용하지 않는다.
행사 관측일 수가 적으므로 복잡한 모델로 확대하기 전에 후보별 계수 안정성과 회차 제외 민감도를 점검한다.

## 새 사전 평가의 고정 규칙

- 목표는 논산시 일별 외지인 추정치, 기준은 B1·B2와 기존 v1이다. 지수·단위와 입력 시점 규칙은 유지한다.
- 첫 예정 시험은 **2026-11-05~2027-01-31 사이 매주 목~일, 13개 창·52일**이다.
  크리스마스(12/25)와 신정(1/1)을 포함하는 두 창을 확보한다. 공휴일 표본은 작으므로 별도 한계를 보고한다.
  각 창을 시작 28일/7일 전에 발행한다. 최초 D-28은 2026-10-08이다.
  후보 선택·평가 코드·등록 목록은 그 날짜 전에 고정하고 버전과 발행 기록을 남긴다.
  이 문서는 향후 시험의 계획이며 아직 해당 예측이나 v2 모델을 발행한 것이 아니다.
- 기한을 놓치면 지난 날짜를 실험 발행처럼 만들지 않는다. 결과를 열람하기 전에 새 계획을 기록하고
  첫 사전 발행 가능한 새 기간으로 옮기며, 원래 계획·변경 이유를 남긴다.
- 같은 선행기간·같은 날짜의 MAE/WAPE/편향을 비교한다. 예측 실패·공통 비교 가능일·미도착 정답을 함께 공개한다.
  두 선행기간의 같은 날짜를 독립 표본으로 합하지 않는다. 주 단위 오차도 별도로 기록한다.
- 각 대상일의 **60일 후 첫 정기 확인 시각까지 확보된 관측 버전**을 1차 정답으로 고정한다.
  그때 없으면 미확보로 남긴다. 90일 후 확보 여부·개정 차이는 별도 민감도 결과로 보고한다.
  60일이면 반드시 제공된다는 가정은 아니다. 사후 최신값으로 1차 정답을 덮어쓰지 않는다.
- 전체와 공휴일 포함/비포함 창을 구분한다. 이 겨울 지역 시험만으로 축제 급증 예측력을 입증하지 않는다.
  2027년 엑스포는 기존 4일 축제와 다른 조건의 별도 평가 설계·대상 계약이 필요하다.
- 채택 기준은 개발 단계에서 선택한 기준 대비 공통 날짜 MAE 10% 이상 감소,
  예측 제공일 비율 비악화, 공휴일 포함 창에서 과소예측 편향 비악화다.
  작은 하위 집단의 개선을 일반적인 행사 효과로 확대하지 않는다. 미충족이면 v1 유지 또는 제공 범위 축소다.
- 이번 사전 시험은 점예측 비교다. 80% 구간은 이 시험의 정답으로 보정한 뒤 같은 시험에서 검증하지 않는다.
  구간 재보정과 포함률 검증은 별도의 뒤쪽 기간을 먼저 고정한 후 수행한다.
