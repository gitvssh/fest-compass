# 매일 수집·사전 발행·결과 확인 연결

검증일: 2026-09-07. 매일 한국시각 09시에 최근 90일의 논산 방문 자료를 수집하고,
등록된 예측 발행과 결과 확인을 실행하는 기능을 운영 서비스에 연결했다. **사용 가능** 상태다.
기존 예측 2건은 원본 그대로 보존했고 운영 서버의 첫 실제 처리와 공개 화면을 확인했다.
동작·호출 상한·실패 처리·복구 확인은 [운영 문서](../ops/forecast-automation.md)를 따른다.

## 변경 범위

- 기존 단일 Deployment·RWO PVC·API 자격 범위 안에서 별도 처리 컨테이너를 실행한다.
  처리 컨테이너는 예측 하위 디렉터리만 마운트하며 SQLite 파일에 접근하지 않는다.
- 날짜별 요청 시도를 먼저 보존하고 하루 20회 상한을 둔다. 재시작·중복 실행에서 같은 날 요청을 반복하지 않는다.
  정상 누락과 호출 실패를 구분하며 누락을 0으로 바꾸지 않는다.
- 공개 `/forecast/records`는 실행 상태·최신 자료·누락·예측·사후 결과·다음 발행 일정을 파일에서 읽는다.
  새 자료를 보여 주기 위해 앱을 다시 빌드할 필요가 없다. 처리 중단·요약 오류는 화면에 표시한다.
- 2026-09-28에 10월 5~8일 대상의 D-7 예측을 발행하도록 등록했다.
  지나간 날짜는 소급하지 않으며, 기존 D-7·D-28 기록은 새 수집본으로 덮어쓰지 않는다.
- 공휴일·축제 입력과 향후 시험 기준은 [다음 모델 계획](12-calendar-model-plan.md)에 정리했다.
  모델 v2나 새 정확도는 아직 제공하지 않는다.
