# M1 전국→지역 조회와 기획 근거 보관 검증

기준일: 2026-09-08. 사용자가 v3 검토 후 시도→시군구 확장을 UI에 표현하고 다음 작업을 진행하도록 지시했다.
전용 worktree `fest-compass-region-explorer`에서 첫 M1 기능을 구현했다. 브라우저는 모두 headless로 실행했다.
화면과 실제 제공 범위는 [첫 구현 검수](../sdlc/2-design/region-explorer-implementation.md)에 정리한다.

## 구현·검증 범위

- `/regions`: 남한 전국, 시도 표식/목록, 선택 후 펼쳐지는 시군구, 상위 경로, 명시적 우리 지역 바로가기.
- 현재 관광지·문화시설·기간 내 시작 행사 조회. 100행씩 최대 6페이지 전체 확인, 누락·중복·건수 변경·다른 지역 응답은 폐기.
- 지도/목록 상세, 공간 필터, 좌표 없는 항목 유지. 새 조건이 이전 응답에 덮이지 않도록 요청 취소·순서 검사.
- 기존 논산 보관 이력의 일별 선그래프/수치 표. 최신 보관본 우선, 누락을 0으로 바꾸거나 연결하지 않음.
- `/evidence`: 선택 당시 값·조건·출처·누락·공간 필터·메모 보관, 중복 방지, 2MB 파일 보관/복원, 기존 작업공간 연결.
- 신규 공개 API는 GET만 제공하고 DB·예측 저장소에 쓰지 않는다. API 키·요청 원문 URL은 응답에 포함하지 않는다.
- 서버 조회 예산: 프로세스당 10분 100호출, 동시 4호출, 성공 1시간·실패 30초 캐시, 최대 100조건. 기존 매일 수집과 모델 코드는 유지.

## 실자료 확인

공식 API의 지역 목록 전체 269행·16시도 그룹을 확인했다. 광주/전남 기존 17시도 표와 달리 현행 API에는
전남광주통합특별시와 인천의 개편 구가 있어 별도 현행 목록을 사용한다. 과거 예측용 코드표는 변경하지 않는다.
세종은 API의 `36110/36110`을 보존하고 54개 관광지를 확인했다. `36/110`의 빈 결과와 구분했다.
새 조회 API를 통한 논산 관광지 61건·2026년 시작 행사 4건, 세종 관광지 54건이 전체 조회로 반환됐다.
논산 2025년 3월 31개 일별 값과 3/27의 52,671.5를 보관 원천에 대조했다.

## 로컬 검증

환경: SH-HOME, Node 24.20.0, npm 11.19.0, 개인 DB와 브라우저 컨텍스트 사용.

- `npm test`: 기존+신규 134건 및 SQLite 이전 1건, 총 135건 통과. 신규 8건은 코드 체계, 날짜 범위,
  좌표 결측, 전체 페이지, 실패/중복/다른 지역 폐기, 실제 값·지역 격리, 결측·실제 0·그래프 단절, 당시 근거 보존을 검증한다.
- `npm run typecheck`, `npm run build`: 통과. 겨울 시험의 코드 14개 고정 해시 유지.
- `npm run test:e2e`: 기존 편집 흐름, 공개 개인 작업, 신규 지역 탐색 14항목 통과. 신규 브라우저 오류·앱 쓰기 요청 0.
- 신규 지역 E2E에는 실제 보관 방문값과 명시적 가상 관광자원 2건을 함께 사용했다. 실 API 확인과 구분한다.
- 첫 신규 E2E는 모바일 선택자의 중복 일치로 실패했다. select 역할을 명시한 뒤 전체 재실행 통과.
- 지도 이동만으로 조회 조건이 바뀌지 않고 ‘이 영역의 자료 보기’ 뒤 공간 조건이 근거에 남는지 추가 확인했다.
- 배포 선언 검사 및 infra 단위검사 40건 통과. production 의존성 audit 취약점 0.

`TS-FC-001`의 지역 탐색·자료 격리와 `TS-FC-003`의 개인 사본/중복/조건 보관을 구현 범위에서 검증했다.
원래 TS의 모든 가상 자료 조합, 기획 후보 연결·기획안 버전 보존과 비용 원문 해석까지 완료한 것은 아니다.
Traceboard 정형 API/Spec/Run 연결과 실제 담당자 과제 관찰은 후속이다.

## 공개 반영

제품 이미지 발행과 공개 주소 검증을 진행한 뒤 대상 커밋·이미지·확인 결과를 이 절에 추가한다.

## 남은 범위

도로·필지/정식 행정경계 지도, 지역 통계 색상 지도, 전국 시군구 방문 이력, 지역 목록 자동 갱신과
새 지역 코드의 과거 통계 연결은 후속이다. 현재 API 조회 단위의 일반시/행정구를 합산하지 않는다.
M2 독립 과거 회차 비교검색 → M3 아이템·장소·시기 후보 → M4~M6 근거 연결을 이어간다.
