# 홈 1분 소개 영상

상태: **구현·로컬 검증 완료, 공개 반영은 아래 배포 절에 기록.** [설계23](../design/23-intro-video.md)과
[인수 기준 TS-FC-020](../sdlc/3-testing/scenarios/TS-FC-020.md)에 따른 변경이다.

## 사용자에게 달라지는 점

- 홈 제목 옆 `1분 소개 영상`으로 누구나 언제든 소개 영상을 본다.
- 처음 온 브라우저에는 동의 창이 닫힌 뒤 화면 아래에 닫을 수 있는 안내가 한 번 나타난다. 휴대폰에서는 한 줄 막대다.
- 재생 창은 한국어 자막과 대본을 제공하고, 끝나면 `기존 축제 찾기` `지역부터 살펴보기`로 잇는다.
- `/?intro=play` 링크는 제출 서류·발표·QR에서 바로 재생 창을 연다.

## 구현·검증

- `npm test`: 406개 통과(42+334+30). 새 단위 시험9개: 봤음/닫음 저장, 알 수 없는 값, 저장 차단 시 예외 없음·안내 반복 없음,
  `intro=play` 판별과 주소 정리, 자막=대본 일치, 공개 파일 존재·영상 12MB 미만, 동의 창 열림 판별.
- `npm run typecheck`, 전체 `npm run build`, `validate_argocd_registration.py`(운영17개) 통과.
- headless 소개 영상 시험 9항목([결과](evidence/2026-10-03-intro-video-local.json)): 영상 범위 요청206·자막 제공,
  첫 방문 안내(초점 이동 없음·재생 전 영상 요청0), 닫기 후 재방문 미표시, 재생 창 자막·대본·ESC 정지·초점 복귀,
  실제 영상 끝까지 재생한 뒤 끝 화면 이동, `?intro=play`(재방문자·다른 주소값 보존), 1초 늦게 나타나는 동의 창 대기,
  390px(안내 높이74px)·1440·1920px 가로 넘침 없음. 최종 코드에서 3회 연속 통과.
- 전체 headless 묶음(run-demo-e2e와 같은 순서·편집/공개 두 모드)이 통과했다. 기존 홈 시험은 목적 이미지 2개를
  홈 상단 전체 이미지로 세고 있어 진입점 썸네일 추가로 실패했다. 의도(목적 카드의 이미지 2개)에 맞게 카드 안 이미지로 좁혔다.
- 첫 발행 작업에서 배포 전 보안 점검이 Next.js 16.3.3의 새 critical 공지(GHSA-vcvr-r3jv-pc5j, `next/og` 원격 코드 실행)로 멈췄다.
  이 기능과 무관한 기존 의존성 문제다. 고정 버전을 패치판 16.3.8로 올린 뒤 운영 의존성 감사0건,
  단위406·타입·전체 빌드·전체 headless 묶음을 다시 통과했다.
- 이 세션의 에이전트 실행에서는 Prisma가 시험 DB `--force-reset`을 차단해 같은 절차를 새 시험 DB 파일 생성(`db push`)으로 실행했다.
  저장소의 `npm run test:e2e` 스크립트는 바꾸지 않았다.
- 검수 중 발견해 고친 결함: 재생 직후 창을 닫으면 늦게 시작된 재생이 계속 소리 나던 문제(닫힌 상태의 재생 시작 즉시 정지),
  늦게 주입되는 실제 동의 창과 안내가 겹칠 수 있던 문제(동의 창이 2초 연속 없을 때만 표시), 휴대폰에서 안내가 주 행동을 가리던 문제.

## 제품 경험 판정

| 항목 | 결과 | 확인 범위 |
|---|---|---|
| 목표·흐름 | 충족 | 업무를 막지 않는 진입점·한 번의 안내, 끝 화면에서 두 흐름으로 연결, 공유 링크 |
| 시각적 위계 | 충족 | 홈 제목·목적 카드가 주, 진입점은 보조. 안내는 모서리 카드/휴대폰 한 줄 |
| 문구 경계 | 충족 | 웹용 영상에서 제작 검증 카드를 사용자 관점 문구로 교체. 화면에 내부 절차 노출 없음 |
| 상태·복구 | 충족 | 저장 차단, 자동 재생 거부 시 컨트롤 유지, 늦은 재생 정지, 동의 창 대기 |
| 키보드·반응형 | 충족 | 네이티브 모달 초점·ESC·초점 복귀, 390/1440/1920px |
| 출처·고지 | 충족 | 개인정보 안내에 저장 항목 추가, 자막·대본 제공 |

화면 낭독기 실제 사용, Windows·Safari 직접 재생, 실제 사용자 관찰은 미평가다.
