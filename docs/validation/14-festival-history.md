# 2022년 선행 이력 확보와 축제 학습 비교

작성일: 2026-09-07. [달력 모델 개발](13-calendar-experiment.md)에서 발견한
2023년 축제 학습 누락을 보완한다. 대상은 논산시 일별 외지인 추정치다.

## 결과 계산 전에 고정한 규칙

- 새로 수집한 2022-01-01~12-31의 365일을 기존 2023~2026년 자료 앞에 붙인다.
  원래 수집본·달력·평가 보고서·겨울 시험 계획과 운영 저장소는 유지한다.
- 2022년 행사는 2/23~27의 비대면 중심 행사다. 현장 판매·수확 체험 안내도 있으므로
  오프라인 활동이 전혀 없었다고 단정하지 않는다. 현장 축제와 비교 가능한 정답으로 넣지 않는다.
  [서울시 지역상생교류사업단 2022-02-17 안내](https://sangsaeng.seoul.go.kr/boardType1/mobile.new_pages.information.area_view/updateView.do?grpId=MYAREA_BASIC&selectedId=4469&userView=Y)가 근거다.
- 기존 달력을 그대로 사용한다. 2022년에는 해당 후보에 필요한 달력이 없으므로
  2022년 정답 행은 학습에서 제외된다. 그해 방문 이력은 2023년 정답 행의 과거 입력으로만 쓰인다.
- 비교 방법은 기존 v1, 기존 공휴일·축제 결합 모델, 선행 이력을 보강한 결합 모델,
  보강 후 2023년 축제 정답 5일만 제외한 결합 모델의 네 가지다.
  마지막 비교는 최근 입력에서 행사 영향까지 제거하는 인과 실험이 아니다.
- 원래 평가 보고서의 2024~2026년 목~일 135개 창·540일과 실제 값·발행일·입력 마감일을 그대로 쓴다.
  D-28과 D-7을 별도로 평가하고 규제 강도 100·공개 지연 가정 35일을 유지한다.
  결과에 따라 날짜나 설정을 바꾸지 않는다.
- 네 방법 모두 제공한 같은 날짜의 MAE·WAPE·편향, 제공일 수, 연도별·축제일·공휴일 포함 창·
  나머지 날짜·주별 결과를 보존한다. 각 회차 첫 예측의 학습 가능한 축제 정답 수와 계수도 기록한다.
- 현재 개정 자료를 이용한 개발 비교다. 자료 추가가 정확도 개선을 보장하지 않으며
  2023년 한 회차에 대한 민감도를 향후 축제 성능으로 해석하지 않는다.
  겨울 사전 시험의 후보·입력 수집 경로·발행 코드는 이 연구로 바꾸지 않는다.

## 자료 확보

[2022년 수집본](evidence/2026-09-07-nonsan-2022-history.json)은 월별 전국 페이지를 끝까지 확인한
36회 API 조회 결과다. 논산시 365일 모두 정상이며 누락·오류는 0일이다.
원문 공개 시각은 제공되지 않으므로 수집 시각을 과거 공개 시각으로 간주하지 않는다.
2022년 행사 근거의 주소·게시일·직접 수집 시각·바이트 해시는 별도 정형 자료에 보존한다.

## 계산·검증 결과

기존 1,316일에 365일을 추가해 2022-01-01~2026-08-08의 1,681일을 확보했다.
새 수집본 ID는 `7354ef8097c494e8acf912d820fcc3424e2ad98c6cebfa6c0af7e2ae968ddadb`,
수집 완료는 2026-09-07T13:04:15.703Z다. 기존 2023년 이후 자료와 평가 정답은 바뀌지 않았다.

[전체 결과](evidence/2026-09-07-nonsan-festival-history.json.gz)에 보강·2023년 제외 모델 540개와
입력·정답 ID·계수·모든 예측·주별 결과를 보존했다. 이전 모델은 원래 보고서의 해시로 참조한다.
새 보고서 해시는 `771dc7b4977b4dcdcf03550109ff18afd810681733d8c08cc9408fb26891cf15`다.
[화면 요약](../../apps/web/data/nonsan-festival-history-summary.json)과
[2022년 행사 근거](../../apps/web/data/nonsan-history-sources.json)를 별도로 보존한다.

각 2024/2025/2026년 첫 축제 예측에서 학습 가능한 축제 정답 수는 **0/4/8일 → 5/9/13일**로 바뀌었다.
두 선행기간 모두 전체 학습 정답은 53일 늘었고, 이 중 5일이 2023년 축제다.
2023년 축제만 제외하면 늘어난 일반 날짜 48일과 과거 입력은 남는다.
2022년 정답은 어느 보강 모델에도 포함하지 않았다.

| 선행기간 | 네 방법 공통일 | 기존 v1 MAE | 기존 결합 MAE | 보강 결합 MAE | 보강 후 2023 축제 제외 MAE | 기존 결합 대비 감소 |
|---|---:|---:|---:|---:|---:|---:|
| D-28 | 436/540 | 6,896.25 | 5,869.99 | 5,655.26 | 5,780.26 | 3.66% |
| D-7 | 472/540 | 6,943.62 | 5,919.50 | 5,582.22 | 5,720.49 | 5.70% |

제공일은 기존 결합과 동일하다. v1은 540일 모두, 나머지는 D-28 436일·D-7 472일을 제공했다.
과거 이력을 늘려도 당시 일정 발표 전에 빠졌던 예측일까지 채워지지는 않는다.

**평균 개선은 2024년의 큰 개선에 집중된다. 최근 두 축제에서는 악화됐다.**
아래는 각 회차 4일의 MAE이며 두 선행기간의 날짜를 독립 표본으로 합치지 않는다.

| 회차 | D-28 보강 전 → 후 | D-7 보강 전 → 후 |
|---|---:|---:|
| 2024 | 45,004.94 → 21,789.78 | 46,812.15 → 20,557.16 |
| 2025 | 2,995.59 → 4,941.22 | 2,319.27 → 6,234.70 |
| 2026 | 5,034.32 → 8,740.03 | 4,484.27 → 8,363.61 |

축제 12일 전체 MAE는 D-28 17,678.28 → 11,823.68, D-7 17,871.90 → 11,718.49다.
보강 후에도 편향은 -11,504.71/-11,264.06으로 과소예측한다.
2023년 축제 정답을 제외하면 축제일 MAE는 17,428.50/17,281.67로 돌아간다.
이는 한 회차에 대한 민감도이지 반복 가능한 새 회차 성능이나 인과 효과가 아니다.
2026년 전체 공통 날짜 MAE도 D-28 5,420.61 → 5,587.55, D-7 5,201.96 → 5,410.36으로 커졌다.

따라서 이번 결과는 **개발 비교 사용 가능·축제 운영 채택은 검증 필요**로 분류한다.
겨울 후보를 새 결합 모델로 교체하지 않는다. 기존 달력·시험 코드 14개·계획·운영 입력 저장소를 유지한다.

## 재현과 후속 작업

`apps/web`에서 실행한다. 생성은 기존 증거를 덮어쓰지 않으며 `--verify`는 전체를 다시 계산한다.

```bash
npm run forecast:history -- --verify
npm run forecast:trial:verify
npm run forecast:records -- verify --store ../../docs/validation/evidence/prospective
npm test
npm run typecheck
npm run build
npm run test:e2e
```

선행 입력과 정답의 역할 분리, 2023년 5일 포함/제외, 미래 정답 불변성, 누락을 보존한 공통 비교를 테스트한다.
원래 보고서·달력이 달라지면 비교를 거부한다. 회차별 악화·선행기간 전환·모바일 표를 화면에서도 확인한다.
실제 검증·게시 결과는 아래 운영 절에 기록한다.

로컬 전체 테스트 120건, 타입 검사·빌드, 기존 예측 2건·사후 기록 2건 검증이 통과했다.
새 보고서 전체 재계산과 요약이 일치했고 겨울 계획·달력·코드 14개 해시도 그대로였다.
별도 SQLite E2E에서 D-28/D-7 수치, 2025·2026년 악화 표시, 학습 축제일 수와 기존 작업 흐름이 통과했다.
390px 모바일에서 문서 가로 넘침과 브라우저 오류가 없었으며 데스크톱·모바일 화면을 직접 확인했다.
배포 계약 17개 리소스·40개 테스트 및 운영 의존성 감사(취약점 0건)가 통과했다.

다음 독립 작업은 2023년 회차 추가가 2025·2026년 오차를 키운 원인을 행사 기간·요일·
발표 시점·방문 증가 형태별로 분석하고, 비교 가능한 다른 축제의 연속 자료 확보 가능성을 점검하는 것이다.
2027년 24일 엑스포는 별도 계약 대상이다. 실제 사전 시험 결과와 실무자·현장 운영 자료는 계속 기다려야 한다.
