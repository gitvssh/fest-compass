# 축제별 방문 자료 — 축제 기간과 평소·성·연령·목적지 검색순위

상태: **사용 가능 — 공개 반영·공개 화면 검증 완료(아래 '공개 배포').** [설계27](../design/27-datalab-festival-profile.md) 1차와 [인수 기준 TS-FC-024](../sdlc/3-testing/scenarios/TS-FC-024.md)에 따른 변경이다.
자료 사용 근거는 [ADR-0004](../decisions/0004-use-kto-datalab-data.md).

## 사용자에게 달라지는 점

- `개최연도별 방문 흐름`(`/compare/annual`)이 `축제별 방문 자료`가 됐다. 축제를 고르면 해마다 방문 아래에 세 카드가 생긴다.
  - **축제 기간과 평소 비교:** 외지인 방문·현지인 방문·내비게이션 검색·관광 소비·축제지 집중률을 축제기간과 앞뒤 4주(평소)로 견준다.
    값은 그해 최댓값을 100으로 본 수치이고 차이를 함께 적는다. 연도를 고를 수 있고 가장 크게 오른 지표와 낮았던 지표를 한 줄로 알려 준다.
    예: 서산해미읍성축제 2025년 외지인 방문 66.3(평소 41.9, +24.4), 관광 소비 54.4(평소 56.4, −2.0).
  - **방문객 성·연령:** 2018~2025년 축제기간을 합친 내국인 방문자의 남성·여성 비율과 가장 많은 연령대, 여덟 연령대 막대(서산: 남성 55.0%·여성 45.1%·50~59세 21.5%).
  - **축제 기간 목적지 검색순위:** 축제가 열린 행정동에서 외지인·현지인·전체가 내비게이션으로 많이 찾은 곳 상위 10곳과 `N곳 모두 보기`(4~74곳).
- 축제 이름 아래 세 카드 바로가기. 방문 규모 화면의 연결 이름도 `축제별 방문 자료`로 바뀌었다.
- 모든 화면 하단에 `관광 자료 출처: ⓒ한국관광공사 (한국관광콘텐츠랩·한국관광 데이터랩)`(한국관광콘텐츠랩 이용 안내의 출처 표기 형식).

## 자료와 기간 확인

- 원문: 저장소에 바이트 그대로 있던 26곳×3표 = 78개 CSV. 목록(`manifest.json`)은 원본 커밋(`f362e65`)의 Git blob과 다시 대조해 만들었고,
  바뀐 것은 이 78개의 `use`(보관 → 사용)와 `consumed` 수(27 → 105)뿐이다. 방문 추이·임실 지역 추이 생성 파일은 목록 해시 한 줄만 바뀌었다.
- 주요 지표: 연도 열이 있다. 값 = 기간 평균 ÷ 그해 최댓값(0~1), 방문·검색은 개최 행정동, 소비는 시군구, 집중률은 행정동 ÷ 시군구, 평소 = 전후 4주
  (데이터랩 데이터 해석 유의사항, 가져온 `02-results.md` 인용). 154개 축제·연도 중 열 개 값이 모두 0인 7개(보성 2022·부평 2019·안성 2019·영암 2022·
  평창 2018·2022·포항 2022)는 방문 추이에도 없는 해와 정확히 같아 `값 없음`으로 둔다. 일부만 0인 해는 없다(있으면 생성이 멈춘다).
- 성·연령·목적지 순위는 연도 열이 없다. 다음 근거로 `내려받기 범위(2018~2025, 고령·영암 2018~2024) 축제기간 합산`으로 판단했다.
  1. 같은 폴더의 방문 추이가 그 범위의 해들을 담고 있고, 데이터랩 화면은 한 번 고른 연도 범위를 모든 표에 쓴다(임실 화면 자료의 요청 값이 연도 범위 두 개).
  2. 임실 성·연령은 2023·2024·2025 화면 자료 어느 해와도 다르고, 세 해를 인원으로 합친 값과도 다르다(70세 이상 남성 3.8% — 각 해 4.3~4.6%).
  3. 임실 목적지 목록에 2024년에만 있던 `수월제`와 2025년에만 있던 `소충사`가 함께 있다.
  4. 같은 방식으로 받은 지역 표는 히트맵의 자기 지역 값이 2018~2025 연도별 합계와 26곳 모두 일치하고, 업종별 비율도 그 합계의 비율과 같다.
  미확인: 합산 방식(인원 가중인지)은 공개되지 않았다. 화면은 `합친`·`합산`까지만 말한다.
- 목적지 순위: 같은 값은 같은 순위(예: 임실 7위 셋). 이름·주소가 같고 분류·순위가 다른 줄 12개(강릉·화성·안성)는 원문 그대로 둔다. 음식점·숙박 분류는 없다.

  `AppShell` 하단 출처. 쪽 크기: 서산 화면 HTML 511KB, 전송(gzip) 58KB.
